# Elevator flight-dynamics investigation: reproducible harness

2026-10-12/13. Scripts and reduced results behind [docs/research/flight-dynamics/elevator-repair-2026-10-13.md](../../../docs/research/flight-dynamics/elevator-repair-2026-10-13.md). Diagnosis only: nothing under `app/` is modified by these scripts; every variant edits a loaded model in memory, and the oracle-only counterfactual ran on a disposable copy of `app/`.

## Scripts

| File | What it does | Run from the repository root |
| --- | --- | --- |
| `elev_static.gd` | For the four catalog aircraft: derived mass/CG/inertia, tail law, trims at the start speed and 1.4×, central-difference pitch derivatives (Cmα, Cmq, CLq, Cmδe, CLδe) of the attached oracle (`Aero._global_loads`), the local strip/tail model (`Aero._local_loads`) and the production blend, the regime weight over α and elevator, and the elevator sweep at trim. | `$(app/get-godot.sh) --headless --path app --audio-driver Dummy --script "$PWD/research/flight-dynamics/elevator-repair/elev_static.gd"` |
| `elev_static_freetail.gd` | The same derivatives for the Extra, P-51 and Avanti with each generator's own dε/dα injected as `aero.surfaces.horizontal.downwash_gradient` (the loader then derives the E0a2 free-tail law). | `… --script "$PWD/research/flight-dynamics/elevator-repair/elev_static_freetail.gd"` |
| `elev_steps.gd` | Elevator step responses through the real `FlightSession` loop (servos, rpm, downwash lag, RK4): ±25/50/100 % pitch command held 1.5 s from 0.5 s, 5 s total, calm air, 300 m, at the start speed and 1.4×; variants `prod`, `local`, `oracle_linear`, `freetail`; options `--only=<aircraft>`, `--variants=a,b`, `--tag=<suffix>`, `--hz=480`, `--out=/abs/dir/`. One CSV per run with per-tick command, servo, surface angle, air data, attitude, rates, load factor, regime weight, aerodynamic/propulsion/gyroscopic pitch moments and the lagged wing CL. | `… --script "$PWD/research/flight-dynamics/elevator-repair/elev_steps.gd" -- --variants=prod,local,oracle_linear,freetail` |
| `analyze_steps.py` | Reduces the CSVs to per-run metrics (peaks, timing, reversals, induced roll/yaw, speed range, recovery). | `OPENRC_ELEVATOR_STEPS=/tmp/openrc-elevator-steps python3 -I research/flight-dynamics/elevator-repair/analyze_steps.py [filter]` |

The oracle-with-stall counterfactual (`prod_oracleStall` rows) was produced by copying `app/` to a disposable directory, inserting `return 0.0` as the first statement of `Aero.local_flow_weight` in that copy, and running `elev_steps.gd` with `--path <copy> --variants=prod --tag=_oracleStall`. Do not apply that edit to `app/`.

## Limits

Software evidence only. The variants are diagnostic counterfactuals, not candidate production settings; the free-tail values use each generator's estimated dε/dα. No physical measurement of any of the four aircraft is involved.
