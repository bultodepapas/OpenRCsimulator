# Third-party notices

The E0b6p native smooth-wake experiment reuses the Gate P implementation adapting the double-precision `wrapf` behavior in Godot Engine 4.7.2's `core/math/math_funcs.h`. It does not copy that source file. The binding library `godot-cpp` is pinned at commit `507ed9d840c01a3c5b2a39af8bb4000bfac30bf5` and statically linked into the local experimental shared library. Source URLs, revision IDs, and SHA-256 values are in [the pinned source manifest](../../../native-slipstream/sources.json).
