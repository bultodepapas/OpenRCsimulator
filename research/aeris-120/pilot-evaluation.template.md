# AERIS-120 pilot evaluation record — unfilled template

**Status: planned observation, not evidence.** Copy for each pilot/configuration/task comparison. Use an existing [A120-C card](../../docs/research/aeris-120/controls-and-validation.md#maneuver-cards); retain the original observations and every attempted run. This form borrows task/performance/compensation distinctions, not formal certification or a validated RC rating scale. [Research rationale](../../docs/research/aeris-120/evidence-update-2026-11-15.md#4-handling-evaluation-is-a-defined-pilot-task).

Do not turn these qualitative fields into a single realism percentage. Same-tape candidate replay is a separate open-loop comparison and does not replace this pilot/input assessment. Formal pass/fail and promotion remain with the [A120 plan](../../docs/plans/aeris-120-3d-gas.md).
