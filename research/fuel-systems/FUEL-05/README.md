# FUEL-05-R1: current mass and balance report

Checked 2026-10-19. The current reproducible snapshot is [`../mass_balance_current.json`](../mass_balance_current.json), generated by [`../mass_balance_report.py`](../mass_balance_report.py). This is the present-tree report; dated FUEL-00 audits are historical and their fleet counts do not describe this snapshot.

The report independently evaluates the authored inventory state, an empty state with liquid items removed, and a full state with each bound tank filled to registry capacity at blend density. It checks the declared balance state against `plan_cg`, tests an authored range there when present, and reports neutral-point static margins as estimates. It recursively covers airplane data under `app/data/aircraft`, includes catalog battery-data paths, and reports non-catalog variants separately. It excludes rotorcraft and does not establish physical validation.

The checked snapshot contains 15 airplane configurations: 9 catalog data paths are covered and 6 additional variants are reported. All registered static margins are positive. Extra is the only configuration with a declared CG range (`within`); 14 rows have no declared range. Four synthetic electric fixtures have no neutral-point estimate. Ordinary report checks pass with those estimates absent; `--qualify` explicitly fails those four rows instead of inventing neutral points. Resolve missing CG ranges and neutral points with defensible source evidence or retain their explicit missing state.

## Reproduce

From the repository root:

```sh
python research/fuel-systems/test_mass_balance_report.py
python research/fuel-systems/mass_balance_report.py --check research/fuel-systems/mass_balance_current.json --fail-on-drift
python research/fuel-systems/mass_balance_report.py --qualify
```

`--fail-on-drift` makes any change from the stored report fatal. Without it, `--check` preserves the tool's established exit behavior: balance/coverage failures are fatal and report drift is advisory. `--qualify` is an additional opt-in gate and currently exits nonzero for the four synthetic donors missing longitudinal neutral-point estimates.
