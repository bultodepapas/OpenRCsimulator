# Fuentes de assets y recursos para el simulador RC en Godot

Antes de modelar, programar o crear un recurso desde cero, revisar estas fuentes. El objetivo es reutilizar assets y sistemas existentes siempre que su calidad y licencia sean adecuadas.

## ⭐ Prioridad máxima — seguros y muy útiles para un proyecto open source

### 1. Poly Haven

**Qué descargar:**
- árboles
- vegetación
- rocas
- troncos
- modelos 3D
- texturas PBR
- HDRI / cielos
- superficies naturales

**Calidad:** muy alta / realista.  
**Licencia:** CC0. Los assets pueden incluirse y redistribuirse dentro del proyecto.

[Poly Haven — descargar assets](https://polyhaven.com/?utm_source=chatgpt.com)

Especialmente útil para buscar:

`tree`, `grass`, `rock`, `forest`, `ground`, `dirt`, `sky`, `cloud`, `wood`.

## 🔧 Plugins, código y sistemas completos para Godot

### 7. Godot Asset Store

Es la nueva tienda/repositorio oficial de assets de Godot.

Hay:

- plugins
- sistemas de terreno
- cámaras
- shaders
- herramientas
- física
- networking
- controladores
- modelos
- efectos
- UI
- proyectos completos

El Asset Store oficial fue lanzado en 2026 y es el sucesor de Asset Library.

[Godot Asset Store](https://store.godotengine.org/?utm_source=chatgpt.com)

**Buscar aquí ANTES de programar un sistema nuevo.**

Preferir:

`MIT`, `Apache-2.0`, `BSD`.

# Orden recomendado para buscar

Cuando necesitemos un recurso, seguir aproximadamente este orden:

**Modelos y naturaleza**

`Poly Haven → Kenney → KayKit → Poly Pizza → itch.io CC0 → OpenGameArt CC0`

**Texturas**

`ambientCG → Poly Haven → cgbookcase`

**Godot/plugins**

`Godot Asset Store → Godot Asset Library → GitHub`

**Shaders/VFX**

`Godot Shaders → Asset Store → GitHub`

**Sonidos**

`Freesound CC0 → OpenGameArt CC0 → Kenney`

**Animaciones**

`CMU Mocap → KayKit → Mixamo`

---

# Regla para el desarrollo

Antes de crear algo desde cero, buscar si ya existe.

Ejemplo:

> “Necesitamos árboles.”

No modelarlos inmediatamente.

Buscar primero:

`Poly Haven → Kenney → KayKit → Poly Pizza`.

> “Necesitamos agua.”

Buscar primero:

`Godot Asset Store → Godot Shaders → GitHub`.

> “Necesitamos joystick RC.”

Buscar:

`Godot Asset Store → Asset Library → GitHub`.

> “Necesitamos una animación de una persona caminando.”

Buscar:

`CMU Mocap → KayKit → Mixamo`.

> “Necesitamos sonidos de motor eléctrico.”

Buscar:

`Freesound CC0 → OpenGameArt`.

La meta es **no gastar tiempo desarrollando recursos genéricos que ya existen**. El desarrollo propio debería concentrarse principalmente en lo que hace único al proyecto: simulación RC, aerodinámica, comportamiento del avión, transmisores, configuración, telemetría y experiencia de vuelo.
