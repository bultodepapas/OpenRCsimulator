## Generated loops and references

[`recorded_powertrains.py`](../../../../tools/audio/recorded_powertrains.py) deterministically decodes the pinned previews with NumPy 2.4.6 and miniaudio 1.71. It downmixes to mono, keeps each preview's decoded sample rate (44.1 or 48 kHz), removes DC, trims the listed material, crossfades the loop boundary, applies gentle frequency shaping, and writes signed 16-bit PCM WAV. It does not upsample or synthesize extra detail. The crossfade is correlation-aware: a constant-amplitude curve is used for correlated endpoints and equal-power weights otherwise. The WAV imports set `compress/mode=0`; the `--check` path verifies those settings as well as source identities, generated bytes, and wrap metrics because QOA compression changes sample values used by the seam guard.

RMS and peak columns are linear full-scale values. The normalization target is 0.10 RMS (about −20 dBFS), with a 0.398107 peak ceiling (−8 dBFS); transient-heavy cuts stop at the peak ceiling, so their final RMS is lower. The wrap test measures `abs(x[-1] - x[0])` after PCM16 quantization and requires it to be no more than `max(1.5 * p99(abs(diff(x))), 0.002)`. Every listed loop passes. Actual file hashes and sample counts are in the manifest. The output loop duration is source-window duration less the crossfade overlap; short source material is not repeated to inflate a loop.

The 6,960 electric reference comes from a strongest spectral line near 232.1 Hz in the selected quadcopter segment, converted as `60 * 232.1 / 2` under a two-blade-pass-events-per-revolution assumption and rounded to 10 RPM. The toy-helicopter segments have strongest lines near 75.5 and 88.2 Hz; the same assumption yields about 2,270 and 2,650 RPM. These are acoustic pitch estimates, not tachometer readings. The gasoline RPM values are low/high runtime mapping anchors only; the source provides no calibrated RPM. The synthetic turbine's 80,000 RPM is also only a runtime mapping anchor.

## Source-fit limits

This bank does not include a verified .55/.61 glow two-stroke or .64 glow four-stroke recording; those profiles should continue using the existing procedural fallback until a source with matching provenance and license is accepted. The 120cc takeoff supports a broad gasoline-class sound only: its page does not identify cycle/fuel, the recording is short, and neither layer is a calibrated steady-RPM bench capture. The electric source is an onboard quadcopter recording, not a fixed-wing three-blade propeller. The rotor source is a toy helicopter fly-around, not a .60 glow helicopter; it contains some source-motion pitch/level change and no isolated tail-rotor layer. The turbine layer is explicitly designed audio rather than a field recording. These proxies should not be treated as exact engine-model captures.

python tools/audio/recorded_powertrains.py --check
