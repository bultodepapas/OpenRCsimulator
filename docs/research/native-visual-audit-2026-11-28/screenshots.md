# Matched screenshot gallery

Every linked review image places the baseline on the left and its stated candidate on the right. The native captures are 1920×1080; these preserved JPEG comparisons display each side at 640×360. The [manifest](evidence/image-gallery-manifest.json) records the original PNG/pixel hashes, archive identities and exact source revision. Pixel counts describe differences, not image quality. The [art review](visual-review.md) explains the observed effects and limits.

All final views use `1e91cb28`, including both corrections identified during independent native-image review. Earlier rejected results retain separate dated receipts and images.

The repository preserves these review JPEGs, selected lossless regression crops, the original image hashes and the numerical replay archive. The linked original artifacts contain full 1920×1080 PNGs and complete capture logs; the workflow configures 14-day artifact retention.
