## Numerical model decisions

The section force uses the local velocity projected into its chord/normal plane. Its lift is perpendicular to that projected velocity, its drag opposes it, and both vanish continuously as the plane speed tends to zero. A component parallel to a section's span does not supply pressure to that section law. This avoids an arbitrary lift direction at pure spanwise flow; it does not add a validated fuselage/spanwise drag model.

The wing's induced map retains its diagonal term. Each off-diagonal source is weighted by `(Vp/Vref)*(1-stall_weight)`, where `Vref` is the largest local three-dimensional strip speed. An exactly stagnant or fully separated source cannot export an undefined angle to a loaded neighbor. Equal-speed, attached planar flow retains the historical map. The zero-flow branch is exact rather than an epsilon denominator.

The transported wing driver is the equal-area mean `U = mean(Vp*CL)`, in m/s, from the same force-producing section coefficients, including an admitted polar and ground effect. Tail downwash is `atan2(gain*U, Vp_tail)`. Free and washed tail evaluations use the same driver, achieved control angles and application point. `wing_lift_coefficient` remains a diagnostic coefficient; it is not the transported state. The global attached model retains its empirical derivatives and receives bounded wake/ground-effect increments. A rate-flow guard routes strongly rotating cases into the local model.

The solver identity is `section-plane-source-weighted-wake-velocity-v2`. Historical coefficients cannot be interpreted as velocity by keeping their old array bytes. Checkpoints and configuration identities reject the old law. The baseline reader/source remains available for exact historical replay. An explicit new-law scenario may start from the same baseline body, RPM, achieved servos and command tape with a newly settled wake; that is a new scenario, not an arbitrary checkpoint migration.

The turbine's captured-air term is `-mdot*v_intake` on both sides of zero axial speed. The net scalar thrust is the signed axial projection of the same vector result. The admitted empirical positive-flow ram map is retained; the full-vector extension removes the demonstrated jump without pretending to identify a real reverse-incidence intake. The intake point uses `v_CG + omega × r_intake`, with the same structural-to-body arm as its force moment. The law identity is `turbine-capture-vector-signed-axial-local-intake-v3`.

Runway Newton residuals use explicit length/gravity scaling and bounded finite differences, iterations and backtracking. Acceptance still requires the original unscaled residual, compression/friction feasibility and placement limits. `numerical_unresolved` is distinct from invalid input and from a proven infeasible problem. Preparation does not publish a reset or erase the current valid flight; commit is the publication boundary. The historical `reset_on_runway` helper explicitly records its separate airborne fallback.

## Verification interpretation

The first stable native batch passed 44 of 48 suites. It exposed four failures: the preset list's insertion order, an old dimensionless wake in the independent gyro comparison, a static tail assertion that assumed the superseded linear-angle law, and three modal regression bands. Preset order now preserves the old indices. The gyro comparison now holds the same dimensional wake as the analyzed system. The tail test calculates lift, drag and their moment arms independently with the bounded angle; its tolerance is stricter than before. [Those three suites pass](r02-r09-regression-fixes/verification.json). An [independent derivative/Jacobian and SciPy eigensolve](R02-modes/README.md) confirmed the three changed modal centers before their update; all 42 checks pass with the original 3% tolerance.

Frozen H4/H12/H13 tests name the domain they actually compare. H12 preserves byte parity only for the unchanged attached, planar, forward-flow law. H13 compares a geometrically projected independent section oracle with a declared floating-point reduction tolerance; its comparator negative control exercises that actual tolerance. Neither test claims that the intentionally changed three-dimensional law is byte-identical to the old law. The unmodified attached-flow oracle remains a separate regression.

The original audit manifest, planning amendment manifest, raw logs and baseline recordings are historical evidence. Failed first-pass and negative-control logs are retained with their outcomes; they are not passing gates. A source-changing run is not accepted as a stable regression result. Concurrent helicopter, ground-vehicle and P-51 work is preserved and must be distinguished by working-tree manifests rather than a Git commit label alone.

## Remaining completion gates

R05-B requires an explicitly derived open-system control volume and complete contact/event mass sampling; a box inertia helper cannot close it. R06 requires matched shaft/propeller data, stationary/windmilling treatment, stopped/reverse wake semantics and a supported Glow/wash composition. R07 requires usable fuel and supply accounting, a causal rundown law, nonnegative localized depletion, full-tick event continuation and all live-mass consumers. R08 requires the shared schema/achieved-state path and applicable flap-dependent data before implementation can be physically promoted.

R09 covers a dry reference column only. It does not model observed soundings, local component-to-component atmospheric gradients, Reynolds-dependent polars or an identified corrected turbine map. R10's missing measurements remain explicit; neither generated curves nor tests are substitutes. R11 still requires the complete release gates and declared target-machine cost checks. No release, deployment or catalog promotion is implied by this report.
