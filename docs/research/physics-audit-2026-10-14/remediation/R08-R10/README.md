# R08–R10 readiness: flaps and physical identification

**Date:** 2026-10-14. This is a source and implementation-readiness review, not a physical validation. The owning plan remains the [physics audit](../../README.md); it records the wider acceptance sequence.

## Finding

The manufacturer references already available for Timber and the Ventage Jet describe setup positions and radio compensation. They do not provide flap-on aerodynamic polars. The repository contains no model-specific flap table with `CL`, `CD`, and `CM` over angle of attack, achieved flap deflection, and Reynolds number. The existing “flap effectiveness” factors and clean-wing polar cannot supply that missing data. Keep both aircraft’s flaps physically disabled until the flap data and linkage measurements are qualified.

### Flap data search and reuse decision

Checked the Timber TT-07 inputs/derivation, A200 AV-06 inputs/generator and reference sheet, AV-17-R2 polar builder/transcription, generated aircraft JSON, current model guides, and the repository’s flap/polar-named files. **No usable Timber- or A200-specific flap-on polar/calibration file was found.** The older AV-06 reference sheet does contain (a) generic DATCOM estimates and a summary of a full-span, sealed plain-flap NACA 23012/AR-6 experiment at Re ≈ 6.1×10⁵, and (b) area/sweep-scaled A200 point estimates. It states the A200 blockout geometry is estimated, the airfoil is unknown, and its NACA 23012 flap case is not the Avanti’s partial-span, gapped, swept installation. Its scaled estimates include flap `CLmax` increments of about +0.16–0.20 at 20° and +0.30–0.37 at 50°, wing `CM` increments at selected conditions, and drag estimates whose Raymer cross-check is explicitly quoted from memory. The later physics model’s rounded `+0.18/+0.33` and `+0.016/+0.070` values therefore remain estimates, not calibration. The local sheet provides useful comparison/sensitivity bounds, but not a complete A200 `CL/CD/CM` table over angle of attack, deflection, and Reynolds number. Keep it out of production aircraft data.

There is existing polar code and a clean-wing Avanti proxy, but these are not a complete flap implementation path: no runtime table is indexed by flap deflection or Reynolds number, and no applicable flap-dependent moment/downwash table is present. The Sandia/NACA 0015 rows are a different airfoil and include hybrid/synthesized values. The NACA 23012 experiment is a distinct, sealed-flap configuration. Do not relabel either as Timber or A200 measurements.

The freely available primary manuals are useful now for identifying target setup positions, model revision, and radio mixes. They are not substitutes for wind-tunnel, aircraft-identification, or independently supported aerodynamic data. For Timber, confirm that the local aircraft corresponds to the manual’s B revision before adopting its setup. For Avanti, keep the A200 manual separate from Mini/XS/Freewing variants.
