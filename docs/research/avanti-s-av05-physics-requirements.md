# Avanti S: what the flight model needs (AV-05/AV-06 audit)

2026-10-06 · AV-05/AV-06 preparation · **Audit of the repository before research: which parameters the simulator uses, what the Avanti S has, what is missing and what the simulator cannot represent.**

Scope: the SebArt Avanti S Jet 2.2m ARF (A200, 2.00 m span) with a JetCat P100-RX, catalog ID `sebart-avanti-s-a200-p100rx`. Before this audit it had a visual model only ([AV-03](../AVANTI-S-PLAN.md)); no physics file, no turbine propulsion.

## 1. What the simulator uses to fly an aircraft

One JSON file per aircraft (`openrc-aircraft v1`, [aircraft_data.gd](../../app/physics/aircraft_data.gd)); every number is `{value, unit, kind, source}`. Generated by a per-aircraft `derive_physics.py` (pattern: [P-51](../../research/p51/p51-05/derive_physics.py), [Extra](../../research/extra-300/ex05/derive_physics.py)).

| Group | Parameters | Used by |
| --- | --- | --- |
| Reference | S, b, c_ref = S/b (not the MAC), root/tip chord (tapered), aero reference point (ARP) | coefficient scaling, wing strips |
| Start | `level_speed` | trimmed in-air start |
| Mass | inventory of parts (mass, position, box size) → mass, CG, inertia tensor; declared flight CG must match within `cg_tolerance` | rigid body |
| Aero, attached | 33 derivatives (CL0, CLa, CLq, CLadot, CLde, CD0, k, CL_minD, CY/Cl/Cn β-p-r-δ, Cm0, Cma, Cmq, Cmde, control drag) | empirical oracle, \|α\| < attached limit |
| Aero, envelope | CL_max, CL_min, stall blend width, CD90, sideslip blend | stall, post-stall |
| Aero, local | tail areas, positions, lift slopes, control effectiveness, incidence; aileron effectiveness; tail stall limits; optional per-strip incidence (washout) | high α, spins, large rates |
| Propulsion | glow: rpm lag or shaft balance, Ct(J)/Cp(J), rotor inertia, thrust line/angles, slipstream; **turbine: added by AV-05** | thrust, gyro, trim |
| Controls | max throw aileron/elevator/rudder (one symmetric value each), servo full-throw time | surfaces |
| Ground | crash hull points; optional landing gear (spring-damper contacts, tyre friction, nose steering) | crash / taxi |

## 3. What the simulator could not represent (and what AV-05 changes)

| Limitation | Effect on the Avanti | Resolution |
| --- | --- | --- |
| Propulsion was propeller-only (Ct/Cp, prop torque, prop gyro, slipstream) | a turbine cannot be expressed honestly | **AV-05:** `propulsion.kind = "turbine"` ([turbine.gd](../../app/physics/turbine.gd)): ECU throttle map, accel/decel-limited spool with governor lag, bench thrust table, momentum ram drag and inlet normal force at the intakes, spool gyro; no reaction torque, no propwash |
| No flap command or flap aerodynamics | takeoff/landing at 20°/50° flaps cannot be flown; approach speeds are clean-wing | shared change (input channel + aero state): AV-09 |
| No retract state; gear contacts are always present | gear up in flight and gear down on the ground cannot both be true | first flight starts in the air, gear up (crash hull only, as the Extra and P-51); AV-09 |
| One symmetric aileron throw | the manual's 30°/25° differential cannot be set | shared `Commands` change, see the AV-06 report |
| No fuel burn | mass/CG fixed at a declared fuel state | AV-10 (G4) |
| No in-flight engine stop, start sequence or flameout | glide starts with the engine stopped instantly | G2 |
| No ground effect, no altitude/temperature (ρ = 1.225) | flare and hot-day performance not represented | shared physics |
| Cnb equals the fin term (fuselage destabilization omitted, v1 contract) | weathercock stability overestimated | shared, as for all aircraft |
| CL-dependent cross derivatives frozen at one CL | adverse yaw, Clr, Cnp exact only near the start condition | shared |
| Two-stroke engine sound | wrong sound for a turbine | AV-08 (render track) |

## 4. Data the research must deliver

Only what the model reads: wing/stab/fin areas and planform; airfoil family and CL_max (clean); flying mass with fuel and tank position; P100-RX thrust vs rpm, mass flow vs rpm, throttle map, spool-up/down times, installed (tube) loss, rotor inertia and sense; servo speed; observed speeds (stall, takeoff, approach, cruise, maximum); stall behaviour. Reports: [turbine dynamics](avanti-s-av05-turbine-dynamics.md), [airframe data](avanti-s-av06-airframe-data.md), [aero references](avanti-s-av06-aero-references.md).
