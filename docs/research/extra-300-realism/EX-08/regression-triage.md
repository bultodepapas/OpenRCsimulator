# EX-08 regression triage: shared atmosphere, UI, and field failures

Status: baseline failure triage complete; final coverage and the Extra-specific fixture repair are recorded in the [verification summary](verification-summary.json). The isolated after-build UI rerun completed 16 tests and reported the same seven failing UI files. No production files were changed by this triage. Prefix: EX-08.

## Captured scope

The initial run (`full-suite.log`, `full-suite.exit`) stopped at `test_atmosphere.gd`: 46 checks, one failure, process exit 1. The saved continuation (`full-suite-continuation.log` and `.json`) executed every downstream entry. The final combined evidence covers all 199 unit files and 27 downstream sections, with 13 remaining failed unit files listed below. The suite is not green. The Extra-specific E5a fixture failure in the original continuation was repaired and its complete rerun passes; see the [combined report](../README.md).

Each listed failure was reproduced against `.tools/extra-realism-baseline/app`. UI and world tests ran on pinned Linux Godot 4.7.2, each with a unique `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, and `XDG_CACHE_HOME`; the exact commands and paths are recorded in their logs. The three field tests used the pinned Windows console binary. The root's separate after-build UI subset used fresh per-test XDG directories and completed all 16 tests with the same seven failing UI test files; see [isolated UI log](isolated-ui.log) and [isolated UI result JSON](isolated-ui.json). The earlier non-isolated `baseline-test_ui_atmosphere.log` may have shared user data with the main UI suite and is superseded by `baseline-test_ui_atmosphere-hermetic.log`.
