# Recursos locales del Ugly Stik .61

Recopilación: 2026-10-05. [Plan de modelado](../UGLY-STIK-PLAN.md) · [Diez investigaciones](ugly-stik-investigations/README.md).

El objetivo es **Jensen de 60 in con motor nitro de clase .61**. Mini y gigante quedan para después. El manual O.S. 61FX es una referencia dimensional provisional: la marca y el modelo concreto del motor no están elegidos.

Se guardaron **16 archivos nuevos** en `references/ugly-stik/downloads/`: ocho PDF, cuatro JPEG, tres páginas HTML de procedencia y un instalador de referencia que no se ejecutó. Los archivos anteriores siguen en `references/ugly-stick/` (con `ck`). Toda la carpeta `references/` está excluida de Git por la configuración actual del proyecto; los documentos, fuentes, hashes y experimentos propios sí quedan en el repo.

Las fotos son **miniaturas de 640 × 480**, suficientes para leer grandes formas y colores, no para medir contornos. Las dos construcciones no establecen una única geometría de tren. También se guardaron las páginas de [Outerzone oz1253](../../references/ugly-stik/downloads/components/outerzone-oz1253-plan-page.html) y [descargas del autor REFLEX](../../references/ugly-stik/downloads/components/ustik-author-download-page.html), como constancia de atribuciones y enlaces; los HTML no son copias completas de sus sitios.

Estos originales de terceros se conservan para consulta local, con atribuciones y notas de uso en los manifiestos. La documentación pública de un avión o un modelo de otro simulador no acredita una licencia para distribuir sus fotos, texturas o mallas con el juego.
