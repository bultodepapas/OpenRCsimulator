# VQ-02a-R1 — roof map import correction

2026-10-21. First demonstrated VQ-02a import correction. Godot 4.7.2 Compatibility, NVIDIA GeForce RTX 3090, default Club field. Source `6a0f146b`.

## Defect

The six [LU-33 roof maps](../../../../../app/assets/landscape/building-roofs/LICENSES.md) (slate and clay: color, OpenGL normal, AO/roughness/metal) were imported with Godot's 2D defaults: **Lossless, no mipmaps**. The [roof shader](../../../../../app/scenery/building_roofs.gdshader) samples all three with `filter_linear_mipmap_anisotropic`, and [LU-33](../../../landscape-upgrade/LU-33/README.md) states mipmapped, anisotropic sampling. Without mips, the sampler reads level 0 at every distance. Slate courses break into a dot grid and salt-and-pepper noise from the air, and into moiré bands at the pilot's grazing angle.

Cause: Godot switches a texture to VRAM compression with mipmaps only when the editor sees it used in 3D ([Detect 3D](https://docs.godotengine.org/en/4.7/tutorials/assets_pipeline/importing_images.html)). [`building_roofs.gd`](../../../../../app/scenery/building_roofs.gd) binds the maps from script to a runtime `ShaderMaterial`, so detection never fires.

## Change

Only the six `.import` sidecars change. They now match the `corrugated_iron_02` maps that already share this material: `compress/mode=2` (VRAM), `mipmaps/generate=true`, `detect_3d/compress_to=0`. The two normal maps use `compress/normal_map=2`. The shader reads `.rgb` without `hint_normal`, so RGTC would discard the blue channel it needs. Source images, shader, UVs, tint, roughness floor and geometry are unchanged. The sidecars were regenerated by the pinned engine in a disposable snapshot, not edited by hand.

[`check_building_roofs.gd`](../../../../../tools/landscape/check_building_roofs.gd) now fails when any bound roof map lacks mipmaps.

## Evidence

Both cases were imported from `git archive` snapshots of the same commit. The only differences between them are the six sidecars. Scripts: [`roof_texture_probe.gd`](../../../../../research/visual-quality/roof-mipmaps/roof_texture_probe.gd) and [`roof_compare.py`](../../../../../research/visual-quality/roof-mipmaps/roof_compare.py).

## Limits

These are static captures. A moving comparison, lower-end GPU frame cost, resident VRAM and independent visual review remain open. The candidate import logged three `get_multiple_md5` errors on unrelated textures during a full reimport of a copied cache; the baseline import logged none, and every probe, capture and check exited zero.

Other script-bound 3D textures may share this import pattern (for example airfield detail, timing cabinet, population and some vegetation maps). Each needs review against its own consumer before any correction.
