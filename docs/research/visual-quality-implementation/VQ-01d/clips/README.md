# Numbered motion references

Open each animated PNG in an APNG-capable browser at its native **1280 × 720**
size, without image scaling. Each two-second clip loops. Filenames hide the
prescribed attitude; keep the adjacent checks/answer-key.json closed until review.

[01](01.png) · [02](02.png) · [03](03.png) · [04](04.png)

Record an orientation in [responses.csv](responses.csv): `level`, `inverted`,
`knife_left`, `knife_right`, `climb`, `dive`, or `uncertain`.
Knife-left/right follows the existing L6c belly-direction convention.
Confidence is an optional 1–5 subjective rating. Keep a copy of the blank worksheet
and record the viewer, display scale and whether the clip was replayed.

This is a qualitative reference check, not a timed reaction experiment. Automatic
animation start, looping and browser scheduling do not measure response latency.
No pass/fail threshold is assigned to this four-clip subset. Return to the
[evidence report](../README.md) for limitations and remaining acceptance work.
