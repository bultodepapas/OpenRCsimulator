Changes made for OpenRCsimulator: the supplied LOD0 parts were consolidated
into one glTF mesh with their original positions baked into the mesh, then
exported from Blender 5.2.2 LTS as glTF 2.0. The supplied polygons, 5,303
triangles, UV coordinates and diffuse/alpha atlas were retained; no geometry
was modeled, decimated, or replaced. The original diffuse and alpha channels
were connected to a core glTF PBR material (metallic factor 0, scalar roughness
factor 1, alphaMode BLEND, double-sided). Roughness 1 is a reviewed scalar
legacy-material adaptation to remove strong leaf/trunk highlights; the source
has no authored roughness texture, and no roughness map was added.

The original legacy material has specular intensity 0.0. Core glTF metallic-
roughness does not encode that scalar. The standard KHR_materials_specular
extension was tested, but Godot 4.7.2 imports it as its default StandardMaterial3D
specular value 0.5, so this Godot-facing asset omits the unsupported extension
and no runtime workaround is used. The scalar specular mismatch is documented
in CONVERSION-PROOF-LOD0.json.

The `gltf/lod0/` folder contains the adapted LOD0 glTF, binary buffer, atlas,
and deterministic conversion proof.
