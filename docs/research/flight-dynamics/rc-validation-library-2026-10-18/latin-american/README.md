# Latin American RC and small-aircraft flight-dynamics evidence

Research snapshot: 2026-10-19. This collection records Portuguese- and Spanish-language primary studies relevant to model-aircraft dynamics, flight identification, small-aircraft wind-tunnel data and flying-wing behavior. It separates measured-flight or tunnel evidence from simulation-only results. Third-party originals are stored only in the ignored local `references/` tree; source metadata and limitations are tracked in [sources.json](sources.json).

Source-specific findings and access notes will follow after the repository records and original files have been verified.
