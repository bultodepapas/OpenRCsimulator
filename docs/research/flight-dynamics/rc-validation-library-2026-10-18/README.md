# RC flight-dynamics validation source library

Research snapshot: **2026-10-18, Bogotá**, expanded to additional RC aircraft, jets, helicopters and sailplanes on **2026-10-19 UTC**. This collection supports the existing VAL-/DATA- physics work and the separate rotorcraft research with published studies and experimental datasets; it does not change the simulator or declare physical validation.

Start with the topic guides below. The searchable [CSV catalogue](catalog.csv) and [BibTeX bibliography](catalog.bib) combine their detailed `sources.json` manifests. [Inventory and file-check results](inventory.json) record the collection size and verification outcome. These files are regenerated by [catalog.py](../../../../research/reference-library/catalog.py); each topic manifest remains the authoritative source record.

The CSV preserves records under each topic. BibTeX collapses matching explicit DOIs, byte-identical local originals and repeated link-only URLs; separately identified dataset files and metadata records can remain separate entries. Neither a file count nor a topic-record count is a count of independent physical experiments.

Verified holdings at completion: **348 topic records, 335 BibTeX entries and 263 distinct local files** (251 originals under this collection and 12 reused from existing references). The files comprise **210 PDFs, 15 ZIP archives and 38 data/telemetry/text artifacts**, totaling 2,076,518,644 bytes (about 2.08 GB). 75 records have no local original and describe metadata-only inspection, online full-text access or retrieval limits. All catalogued local hashes/sizes, PDF parsing and ZIP CRC checks passed; no byte-identical local copies remain. See the inventory for the UTC check timestamp.

## Original documents and private copies

New third-party originals live in `references/rc-validation-library-2026-10-18/` inside this repository. They are **local-only and ignored by Git**, following the repository's reference policy. Existing originals may be reused from `references/rc-aero-data/`; every `local_path` is relative to the repository root. The tracked guides and manifests preserve source URLs, download URLs, titles, dates, hashes, file sizes, access outcomes and study limitations.

No authentication bypass or paywall circumvention was used. A public download is not assumed to grant redistribution permission. Dataset licenses, paper copyrights and source-page terms may differ. The UIUC data terms and ZIP notices are retained; metadata-only and unavailable records are explicitly labeled. Copying this repository through Git alone does not transfer the ignored originals.

## Choosing evidence for a comparison

| Evidence | Useful comparison | Required boundary |
| --- | --- | --- |
| Exact configuration, instrumented flight | Time response, trim, modes and maneuver envelopes | Match geometry, mass/inertia, CG, controls, environment and instrumentation |
| Related RC airframe, instrumented flight | Plausibility ranges and sensitivity trends | Ultra Stick and Big Stik are not interchangeable with Jensen Ugly Stik 60 |
| Whole-aircraft tunnel tests | Static coefficients, control/rate derivatives, stall trends | Respect reference axes/areas, Reynolds number, support corrections and test motion |
| Section or finite-wing experiment | Polar shape, transition, flap response, stall mechanisms | Section, isolated wing and whole-aircraft coefficients are different quantities |
| Rotor stand, PIV or ground-effect rig | Thrust/torque, wake structure and inflow/clearance trends | Match rotor, hub, RPM, pitch and installation; isolated-rotor measurements do not establish full helicopter response |
| Turbine or EDF bench/tunnel test | Thrust/power curves, installation effects and spool response | Match inlet/outlet, airspeed, voltage or fuel system and control state; static thrust alone does not identify flight thrust |
| CFD, analytical or simulator study | Model-form hypotheses and independent implementations | A numerical prediction is not a flight measurement |
| Paper plots without raw logs | Digitizable curves and reported aggregate values | Retain plot-reading uncertainty; do not describe the paper as a raw dataset |
| Repository metadata or blocked lead | A route to future acquisition | It does not establish that the underlying document or measurement was downloaded |

Before using any coefficients, check force/moment signs, body/wind axes, degree/radian conventions, nondimensional rates, moment reference point and reference geometry. Compare equivalent Reynolds number, lift coefficient and control configuration where possible. Separate measured sensor outputs from estimator states and commanded controls from measured surface positions. Closed-loop mission tracking alone cannot identify an open-loop airframe.

Helicopter comparisons additionally require rotor geometry, RPM, collective/cyclic conventions, flybar/flybarless configuration, actuator behavior, inflow state and flight regime. A rotor-rig measurement, a closed-loop helicopter flight and a fixed-wing polar establish different quantities. Yamaha R-50/RMAX studies are explicitly larger analogues; subscale transport/fighter jets also have configuration and scaling limits.

For fixed-wing simulation candidate runs, use the existing [flight logging workflow](../../../FLIGHT-LOGGING.md) and [flight-test tools](../../../../research/flight-test/README.md). Rotorcraft retain their own validation gates in the [helicopter guide](../../../HELICOPTER.md). Literature collection and software replay are separate from experimental validation. No coefficients were imported into production by this research task.

## Recheck the collection

From the repository root, with Python 3 and the existing free `pdftotext` utility installed:

```bash
python3 research/reference-library/catalog.py
python3 research/reference-library/catalog.py --write
```

The first command checks the manifests, local file sizes and SHA-256 hashes, PDF signatures within the first 1024 bytes (including legacy NTRS ingestion prefixes), text parsing, ZIP CRCs and reused-file metadata. It does not execute downloaded code, extract archives or deserialize flight-data pickles. The second additionally regenerates the catalogue and inventory after a deliberate manifest update. It does not download missing originals. For direct files, restore from the record's `download_url` into its `local_path`, then verify the pinned hash. For a retained member of a larger dataset archive, follow the record's archive/member retrieval notes; the local member's hash is not the full archive's hash. An upstream file revision needs a new dated source record rather than silently replacing a historical hash.

The topic notes retain representative query strings and inspection limits. This is broad source triage with verified downloads, not an exhaustive systematic review or a full reproduction of every experiment.
