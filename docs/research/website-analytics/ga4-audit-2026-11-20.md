# GA4 website analytics audit, 2026-11-20

Dated evidence for the [website analytics plan](../../plans/website-analytics.md). Scope: the public website's GA4 property (web stream `G-4Z11DSB2BV`, through GTM `GTM-N4G2K5K7`), its tagging in `site/`, and the operator dashboard's [Website tab](../../../tools/telemetry/README.md#website-ga4).

**Method.** Property settings were read through the GA4 Admin API (`analytics.readonly`). Traffic was read through the Data API for 2026-10-28 (first collected day) to 2026-11-20. Site code was read in `site/` and `README.md`, and the published GTM container was read up to about 100 kB of 551 kB. Owner-only traffic is reported as ratios. Nothing was changed in GA4, GTM or the site.

## Property configuration

| Setting | Found | Assessment |
| --- | --- | --- |
| Event data retention | 2 months (default) | Explorations cannot look back further than two months. Raise to 14 months. Standard reports are unaffected. |
| Key events | only the auto-created `purchase` | The site never sends `purchase`. `download_request`, the real goal, is not a key event. |
| Custom dimensions and metrics | none registered | `download_platform`, `release_version`, `download_source`, `download_method`, `metric_name`, `metric_rating` and `metric_value` are sent but are not reportable. Registration applies only to new data. |
| Google signals | disabled | Appropriate: no ads use, less personal data. |
| Web streams | one, default URI = production site | Correct |
| Reporting time zone | America/Bogota | The dashboard follows it. Install `tzdata` on Windows. |

## Data quality

- **Development traffic is collected.** Host `127.0.0.1` produced about 4% of page views (five users) from local previews. `downloads.js` has no production-host guard; `vitals.js` has one. GTM loads on every host. No `download_request` from localhost was observed, but nothing prevents it.
- **Bot-like sessions.** One country contributed a cluster of direct desktop sessions with zero engagement. Several data-center cities appear. Sessions with a `(not set)` landing page are about 7% of sessions, with almost no engagement. Engagement rate is about 50% overall. Use engaged sessions, not raw users, as the headline traffic KPI.
- **Three overlapping download signals.** Custom `download_request` (automatic and manual, the intended source of truth) is joined by enhanced-measurement `file_download` and `click` events with `link_domain = github.com` (manual clicks only). Their counts must never be summed.
- **Repeated download requests on mobile.** Overall about 1.4 `download_request` events per requesting user. iOS shows about 7–8 per user: README download links reopened on a phone keep requesting a desktop ZIP that iOS cannot use. There is no deduplication beyond `history.state`.
- **Web Vitals are sampled.** They are sent for about 10% of page views (`vitals.js`); counts are not totals.
- **URL variants.** `page_location` carries `?download=…&release=…&utm_*` and `fbclid`. Landing-page reports fragment into many rows for the same page.

## Audience and conversion (ratios)

- Desktop is 57% of users and mobile 43%. The simulator is desktop-only.
- About 32% of users send a `download_request`: about 49% on desktop and about 9% on mobile.
- By source, README visitors (`utm_campaign=readme`) convert at about 94%, Reddit referrals at about 38% and direct traffic at about 14% (direct includes the bot-like sessions).
- Reddit is the largest referral source, but its posts carry no UTMs, so it is not measured per post. `chatgpt.com` appears as an AI-assistant source.
- About 41% of users have a non-English browser language (Spanish, German, Chinese, French, Dutch …). Localized pages other than the root and `en.html` receive about 4% of page views. The root page is the Spanish source; whether visitors find their language is not measured (there is no language-switch event).

## Tagging, consent and attribution

- **Consent: none.** No banner, Consent Mode default, privacy notice or footer link exists in `site/` or on the live page. The container shows no explicit consent default in the part read. GA4 loads unconditionally for EEA/UK/CH visitors, which make up a large share of traffic. This is a compliance risk to resolve; it is not legal advice.
- The container also runs Google's automatic redaction and user-provided-data detection tags. [site/README.md](../../../site/README.md#website-analytics-web-12) describes the 2026-10-28 container only.
- README links carry consistent `utm_source=github&utm_medium=referral&utm_campaign=readme` with per-link `utm_content`. Other launch channels (Reddit, forums, release notes, trailer, social) have no campaign scheme.
- No engagement events exist beyond enhanced measurement. Aircraft selection, the 3D inspector, language switching and the donation link are not measured.

## Dashboard (operator tool)

The Website tab reads the property correctly. Gaps:
- It does not exclude non-production hosts.
- It shows no funnel or conversion by source, device or OS.
- It has no key-event or registration-status view other than per-panel notes.
- It gives no warning when the OAuth consent screen is in testing mode, where refresh tokens expire after seven days.
