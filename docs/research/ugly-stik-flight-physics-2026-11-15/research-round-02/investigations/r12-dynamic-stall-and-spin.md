# R12 — Dynamic stall, hysteresis and spin validation

**Decision: prototype/measure first; defer stock dynamic-stall adoption.** A lagged separation state is a plausible hypothesis, but it is neither sufficient for spin nor identified for this Jensen. Static review at baseline `08f0c08348395c0d6d9f7e224f66460828f59a7f`, 2026-11-15; no new simulation or flight tests.

## Existing model and evidence

`app/physics/aero.gd::stall_weight()` is a smooth algebraic function of current angle; the attached whole-aircraft branch blends to six local strips and a separated/flat-plate law. There is no dynamic stall-memory state. Jensen data define estimated `CL_max=1.1`, `CL_min=-0.8` and blend width; they contain no target-measured `wing_polar`. The optional wing polar exists for other aircraft but an Extra polar is a different geometry and installation. Previous repository experiments against the different FASER Ultra Stick 120 showed a tradeoff: better analog lift/damping fits did not preserve a developed model spin. This is a model warning, not measured Jensen validation or proof that spinning is necessarily correct.

[DTU's S826 finite-span measurements](https://www.mdpi.com/1996-1073/11/6/1418) [PHY-S21] found static up/down hysteresis in selected tests below Re 100,000, over a 40,000–400,000 test program. Static path dependence must not be mislabeled dynamic stall; that section and geometry differ from Jensen. [NASA's 2012 FASER forced-oscillation tests](https://ntrs.nasa.gov/citations/20120014506) [PHY-S20] show damping depends chiefly on angle and can depend on nondimensional rate/reduced frequency in stall/post-stall; [NASA's 2016 rotary-balance campaign](https://ntrs.nasa.gov/citations/20160010112) [PHY-S24] provides a distinct way to study steady spins. FASER's configuration is not the target and one maneuver or sign agreement cannot establish fidelity.

## Model hierarchy and important caveats

Start with the current quasi-steady law, quantify its error and operating coverage, then compare an opt-in stateful separation/reattachment model, and only then consider more elaborate vortex/unsteady attached-flow models. [QBlade's Oye implementation](https://docs.qblade.org/src/theory/aerodynamics/dynamic_stall/OYE_stall.html) [PHY-S23] explicitly models separated-flow dynamics and notes attached wake memory is separately represented by its free wake; do not assume a single lag models all unsteady aerodynamics. [OpenFAST AeroDyn guidance](https://github.com/OpenFAST/OpenFAST/blob/main/docs/source/user/aerodyn/modeling.rst) [PHY-S22] says the original discrete B–L option is not currently functional and other options require airfoil/Re/Mach-appropriate parameters; documentation follows a moving main branch. Rotor models and their calibration are starting points, not drop-in fixed-wing answers. OpenFAST declares Apache-2.0 at its [repository](https://github.com/OpenFAST/openfast) [PHY-S26]; code reuse would still require an exact revision and full license/dependency review. No source code is copied here.

## Integration and acceptance

Independently measure section geometry, CG/inertia, control throws and static lift/moment at multiple speeds. Record slow and fast pitch sweeps and reversals at controlled amplitudes and reduced frequencies, then held-out pull-ups, spin entry, developed motion and recovery in both directions, retaining airspeed, attitude/rates, control positions, fuel/pack and measurement uncertainty. Separate training and validation maneuvers by run, speed and direction. Tune no coefficient against a target trajectory before input and mass-property errors are constrained.

Prototype separation per surface as an explicit bounded state within the shared `VehicleModel` layout, evaluate its derivatives consistently at integration stages, initialize and serialize it, and preserve deterministic replay and old aircraft behavior when absent. Check equilibrium recovery, slow-motion quasi-steady limit, finite zero-speed/reverse-flow handling, timestep refinement, control reversals and both roll/yaw symmetry. Compare lift, drag, pitch, roll/yaw moments and damping together; require correct held-out stall progression and recovery uncertainty, not merely visually plausible spins. A full 3D separated wake, propeller/fuselage interaction and tail blanketing remain separate gaps.
