# R23 — Reuse, licenses and integration boundaries

**Decision: reuse documented ideas and existing local tools now; evaluate any additional tool offline with an exact version and separate license review before adoption.** No external code, data, model or new dependency was imported in this investigation. License observations below were checked against the linked upstream notices on 2026-11-15; a repository-level license does not automatically license every bundled component, model, test dataset or distribution artifact.

The upstream links for AVL's mirrored file and the branch-head license notices are moving references, not pinned versions selected for a future dependency. Obtain immutable commit/tag URLs and inspect exactly the files and binary distribution before integration. MIT/BSD/Apache terms generally require preserving specified notices, and Apache also has its own conditions; LGPL/GPL reuse requires particular attention to how and what is distributed. This table is engineering provenance, not a legal compatibility determination, and running a tool separately does not automatically resolve every licensing or data-rights question.

## Project fit and decision gates

At baseline `08f0c08348395c0d6d9f7e224f66460828f59a7f`, the application already has a shared float64 `VehicleModel` contract (`app/sim/vehicle_model.gd:1–10`), fixed-step integrator, native/reference stage backends and a flight-log comparison workflow (`docs/FLIGHT-LOGGING.md`). Existing performance capture/trace workflows live in `tools/godot/README.md` and `tools/godtest/README.md`. Importing another simulator wholesale would add coordinate/unit conversion, input/trim/propulsion semantics, data provenance, deterministic replay, packaging and ongoing support work; it would not automatically make flight physics more realistic.

Before even an offline comparison, define a single question, independently measured or authored inputs, coordinate/sign/unit conversion, output uncertainty, source/model versions and license/provenance for **all** inputs. Compare like with like over a declared domain and retain disagreements. Before runtime reuse, additionally require a maintainer-owned dependency proposal covering licenses and notices, distribution for every supported OS/architecture, release builds, CVE/update ownership, float64 semantics, no vehicle-specific kernel branches, native fallback, identity/checkpoint versioning, exact old-law replay and measured benefit. Prefer an existing project tool or a small standards-based analysis if it answers the question.

No source license reviewed here grants rights to third-party aircraft measurements or artwork by implication. The GPL notice applies to the specific examined AVL file; the full AVL dependency license was not independently inventoried. These findings are not authorization to vendor, link, redistribute, tune coefficients or ship a dependency.
