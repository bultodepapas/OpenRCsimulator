# Detached stable shaft-capacity mapping

Review-only five-path payload in `production/`; no application files were edited. This qualifies the mapping/evaluator and small motor-off capture foundation, **not powered startup or stock selection**. `manifest.json` gives exact installed prehashes and proposed payload hashes; `review-production.patch` contains the three runtime diffs.

`ContactCapacity.capture_mapping(sample,packet,rotors)` requires paired legacy capture and exact `{rotor_index,row_id}` interval mapping. It resolves a unique packet row, reuses the existing `+e_sigma`/zero-bias/independent-scalar-group validator, requires contact index−1, no normal-dependent coefficient, and the identical finite legacy source rate. Step pins semantic row/rotor/rate across actual/predictor snapshots and uses the existing finite impulse/capture solver. No reservation, solver, force, source or work/error tolerance is changed. Missing mappings preserve the old path and receipt keys. Mapping metadata is a trusted owner declaration, not authentication of an arbitrary callback.

`GroundElectric.prepare_capacity(prepared,provider,owner_identity)` binds the actual locally prepared source/mechanics and wheel packet context. `evaluate_capacity` calls the original source/aero/prop/wash/common-stage evaluator once, appends one finite internal bearing row from that returned source, and leaves every original sample/result field unchanged. The original `evaluate` API and fixed-voltage law remain available. This wrapper does not integrate battery boundaries, sample ESC state, own held-command transitions, admit moving axes, or change shaft external-wrench ownership.
