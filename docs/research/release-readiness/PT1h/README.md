## Local export failure investigation

The original macOS ZIP declared an arm64 slice of 83,309,248 bytes but contained only 70,275,776 bytes. Its signature offset therefore lay beyond the file. The template had complete slices. The root filesystem had only about 288 MB free; a second run reported failure creating `_CodeSignature`. Removing only the failed exports produced in this audit and writing the next ZIP to tmpfs restored both ad-hoc signatures. The checker was not weakened. A full fresh-clone export then passed with its output and Godot's `/tmp/OpenRC Simulator` staging directory backed by the dedicated tmpfs workspace. Python hardlink fixtures also require `TMPDIR` on the checkout's filesystem; all 195 tool tests and the dashboard freshness check pass there. Use an isolated build with sufficient output **and temporary** space; a ZIP can decompress successfully while containing a truncated executable. Native launch/trust still requires a Mac.
