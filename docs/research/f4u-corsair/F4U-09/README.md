# F4U-09: catalog registration of the F4U Corsair

Registered 2026-10-22 for the [F4U plan](../../../F4U-PLAN.md). The Corsair is an **experimental** catalog aircraft: Home, the catalog list, Quick Flight and the Workshop offer it; its physics is an unvalidated estimate (F4U-07/08).

## What changed

| Item | Change |
| --- | --- |
| [aircraft_catalog.gd](../../../../app/app_state/aircraft_catalog.gd) | Entry `f4u-corsair-250` after the P-51: "F4U-1D Corsair 1/4.5", short name "F4U Corsair", summary "Giant-scale warbird · 2.78 m · Moki 250 radial", experimental status note; data `res://data/aircraft/f4u_corsair_250.json`. The historical name follows the P-51 precedent pending the [F4U-13](../F4U-13/README.md) name decision |
| Physics data | `derive_physics.py` writes `app/data/aircraft/f4u_corsair_250.json` (the staged research copy is removed) |
| [es.po](../../../../app/i18n/es.po) | Spanish summary and status note |
| Workshop descriptor | `app/data/workshop/f4u-corsair-250.json`, generated by `build_descriptors.py` from the catalog |
| Economy | Costing route and dossier (see [F4U-11](../F4U-11/README.md)) |
| Audio | Three-blade propeller in `powertrain_audio.gd` and `flight_audio.gd`; the gasoline fuel law selects the gasoline bank (no radial recording exists) |
| Natural Random | Not added: `natural_random_v1.json` is a fixed, versioned five-aircraft list, and adding an aircraft changes every seed's draw, so it needs a v2 catalog from the scenario owner |

## Tests that enumerate the fleet

Fifty-two app tests iterate the catalog and now fly, build, crash, price or display the Corsair. On the first run 43 passed. The nine failures were fleet bookkeeping, not Corsair defects, and were updated:

| Test | Update |
| --- | --- |
| `test_aircraft_catalog` | Ten entries, nine airplane configurations, the Corsair's visual family and adapter ID (`render/airplane.gd` gains `CORSAIR_ID`) |
| `test_crash_energy` | The Corsair's expected `gasoline` energy tag |
| `test_economy_catalog` | Ten routes, six incomplete fleet dossiers |
| `test_powertrain_audio`, `test_workshop_descriptor`, `test_workshop_experiments` | Nine fixed-wing configurations |
| `test_trace_metadata` | The Corsair joins the P-51 as a gasoline shaft aircraft: coupled shaft law and tail slipstream |
| `test_aircraft_render_contract` | The imported-scene branch now keys on the manifest's `imported_glb` adapter instead of listing two IDs; the Corsair had fallen into the procedural branch |
| `test_ui_aircraft` | The Home walk visits the Corsair between the P-51 and the Ventage Jet |

After the updates and the F4U-10 presentation data, the 22 affected and presentation suites pass (customization, smoke, Workshop, Home, menu walk, render contract). Crash, pose, hull-label, gear-contact, reserve-drop, night-kit, Home-presentation and failure suites passed with the Corsair from the first run.
