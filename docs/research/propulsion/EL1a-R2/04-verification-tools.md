# EL1a-R2 — Headless checks, independent solvers, and calibration tools

2026-10-10 · **Status: primary-source review and isolated tool probes complete; integrated electric flight and physical validation remain open.** Step prefix: EL. Sources accessed 2026-10-10.

## 10 — What makes a headless or exported electric test credible?

**Verified findings.** Godot 4.7 distinguishes parsing (`--check-only --script`) from executing a script and exporting a package. `--fixed-fps` disables real-time synchronization; `--quit-after` counts iterations, not simulated seconds. Unrecognized flags may be ignored. Non-resource files such as JSON need export inclusion filters. These commands do not establish that an aircraft loaded or completed its intended flight. [G1] [G2]

**Local evidence.** [`app/test.sh`](../../../../app/test.sh) already combines bounded execution, import/parse checks, a float64 guard, and engine-error log checks. [`EL1a verify.py`](../../../../research/propulsion/el1a/verify.py) additionally requires a positive completed-check count and tests mutations in a temporary project. The new [isolated probe](../../../../research/propulsion/el1a-r2/probe_tools.py) exercises six runner cases: successful control, explicit failure, logged runtime error, missing completion, parse failure, and timeout. Only the control is accepted. The runtime-error case logs `SCRIPT ERROR`, prints a success marker, and exits zero: checking only process status or only the marker would pass a broken run. [Recorded result](tools-proof.json)

**EL1b–f action and rejecting tests.** Preserve existing runner gates; require completed nonzero checks in new isolated suites. Exercise new fixtures through the actual loader and session, then retain full regression for runtime changes. [`app/export.sh`](../../../../app/export.sh) already verifies field data from a clean package; extend that pattern to the electric model. Require packaged input SHA, active propulsion kind, and an advancing flight trace from an empty working directory. The existing default-aircraft export smoke cannot prove new electric data was included. Test the electric package with a missing dataset negative control in a disposable copy. No package or full app regression was run for this research-only change.

## 11 — How should an independent solver verify the fixed-step implementation?

**Verified findings.** SciPy 1.11.4 offers DOP853 for accurate nonstiff integration and implicit Radau for stiff equations. `t_eval` requests output times; `max_step` bounds internal steps. Event detection uses sign changes and can miss multiple crossings in one step. Per-state absolute tolerances combine with relative tolerance. `success=True` includes a terminal event, so it does not by itself prove arrival at the requested final time. [S1]

**Local experiment.** The [probe](../../../../research/propulsion/el1a-r2/probe_tools.py) compares both methods with a separately derived fixed-body, positive-speed, no-prop exponential. With `rtol=1e-11`, `atol=1e-11 rad/s`, and `max_step=0.01 s`, maximum errors are `2.18e-9` and `4.84e-10 rad/s` or less. This qualifies the smooth reference setup; it does not test the Godot session. A separate sinusoidal event fixture with 1,001 output samples misses all four roots at `max_step=1 s`. At `0.05 s`, this pinned solver reports the first endpoint root twice; `0.04 s` returns four distinct roots. Raw event times are preserved in [tools-proof.json](tools-proof.json), including the duplicate discovered while testing the experiment.

**EL1d/EL2 action and rejecting tests.** Compare actual Godot trajectories at 120/240/480/960 Hz against an independently formulated reference, with explicit units/tolerances for RPM, body rate, SOC, and polarization voltage. Refine reference tolerance and maximum step separately; compare charge, work, momentum, and event time as well as state. Define event identity, direction and re-arm policy so a repeated endpoint cannot apply cutoff twice. Reject early termination, missed/double events, frozen stage inputs, and copied production equations masquerading as independent evidence. SciPy remains an offline research dependency; the runtime stays GDScript.

**Source.** [S1] [SciPy 1.11.4 `solve_ivp`](https://docs.scipy.org/doc/scipy-1.11.4/reference/generated/scipy.integrate.solve_ivp.html), method, `t_eval`, events, tolerances, and return status. The executable synthetic fixtures and their conclusions are original project work.

## 12 — Can a successful fit still leave the powertrain unidentified?

**Verified findings.** SciPy's bounded `least_squares` supports explicit parameter scales and robust residual losses. Termination criteria concern changes in cost, parameters, or gradient. Its returned Jacobian can be modified by the chosen loss. NumPy SVD returns the matrix's singular values, which can expose dependent sensitivity columns. Neither API certifies that measurements identify a physical model. [S2] [N1]

**Local experiment.** For the original normalized fixture `speed=1−exp(−t/(0.04 Rrel Jrel))`, all speed observations depend only on the product `Rrel Jrel`. Two bounded fits return successful, zero-residual answers at `[0.5, 2]` and `[2, 0.5]`. The analytic, scaled sensitivity matrix has rank one. Adding a synthetic independent resistance observation yields rank two and recovers `[1, 1]`. The assumed observation scales and singular values are recorded in [tools-proof.json](tools-proof.json). This is a noiseless local-identifiability demonstration, not measured Timber resistance or inertia.

**EL2/EL5 action and rejecting tests.** Extend the measurement workflow with bounded fits in declared physical/logarithmic coordinates, noise-weighted residuals, and a separately evaluated physical sensitivity Jacobian. Scale parameters before inspecting SVD; account for correlated observations rather than treating filtered samples as independent. Require repeat fits from different starts, sensitivity to noise/bounds, and held-out operating points. Add independent current, torque or inertia evidence when columns remain dependent; do not conceal model discrepancy with a robust loss. Full numerical rank alone does not establish useful uncertainty or global identifiability. [`research/sensitivity/sensitivity.gd`](../../../../research/sensitivity/sensitivity.gd) presently measures aircraft parameter perturbations, not electric parameter identification. Reject an acceptance report based only on optimizer success, small training residual, or fitted inertia that absorbs unidentified ESC/sensor delay.

**Sources.** [S2] [SciPy 1.11.4 `least_squares`](https://docs.scipy.org/doc/scipy-1.11.4/reference/generated/scipy.optimize.least_squares.html), bounds, `x_scale`, loss, termination, and returned Jacobian. [N1] [NumPy 1.26 `linalg.svd`](https://numpy.org/doc/1.26/reference/generated/numpy.linalg.svd.html), Returns and Notes.
