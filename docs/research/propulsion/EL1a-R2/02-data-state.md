# EL1a-R2 — Electric data and replay investigations

2026-10-10 · **Status:** primary-source review complete; electric schema and checkpoint changes remain planned. Scope: EL1b, EL1d, EL2. Sources accessed 2026-10-10. Read with the [electric propulsion plan](../../../ELECTRIC-PROPULSION-PLAN.md).

## 04 — Can the electric branch be strict in both schema and loader?

**Decision question.** How can `electric_prop` join v1 without silently taking the glow path or accepting unsupported fields?

**Verified findings.** The [schema propulsion branch](../../../../app/data/schema/openrc-aircraft-v1.schema.json#L1237) declares Draft 2020-12 but lists only `glow_prop` and `turbine`; `if turbine / else glowPropulsion` sends other kinds to glow. Runtime [`_propulsion()`](../../../../app/physics/aircraft_data.gd#L708) likewise defaults missing kind to glow and accepts only those two. `load_file()` does not execute the schema, and this branch allows extra fields. Draft 2020-12 `oneOf` requires exactly one match; `additionalProperties` sees properties declared beside it, while `unevaluatedProperties: false` can close a composed branch. `integer` means a number with zero fractional part. Godot 4.7 parses JSON numbers into a double/`TYPE_FLOAT`; [`_q()`](../../../../app/physics/aircraft_data.gd#L79) accepts int or float for in-memory parity and rejects nonfinite or out-of-range values. [J1] [G1] [G2]

**EL1b change and rejecting test.** Add disjoint propulsion branches while preserving the missing-kind glow default; close the electric, motor, ESC, and battery objects in schema and loader. Require `{value, unit, kind, source}` with explicit units, bounds, provenance, and loader cross-field constraints. Reject unknown keys, mixed branches, wrong units, missing provenance, and invalid dimensions or ranges. Test schema with ordinary finite JSON, then separately load an overflowing serialized exponent and in-memory `INF`/`NAN`; loader finite checks must reject them. Schema validates JSON values, not host float conversion; JSON has no `INF`/`NAN` literal. Check integer semantics, legacy glow/turbine fixtures, and no electric fallthrough. Motor-loss meaning and force ordering remain loader policy. [J1] [J2] [G1] [G2]

**Sources.** [J1] [JSON Schema Draft 2020-12 Core](https://json-schema.org/draft/2020-12/json-schema-core), §§10.2.1.3 `oneOf`, 10.3.2.3 `additionalProperties`, 11.3 `unevaluatedProperties`. ## 05 — Which state may be shared by multiple aircraft sessions?

**Decision question.** Can a loaded electric model safely serve multiple active sessions without shared battery or ESC state?

**Verified findings.** [`AircraftData.load_file()`](../../../../app/physics/aircraft_data.gd#L39) reparses into plain dictionaries and packed arrays, not a `Resource`. [`FlightSession._commit_aircraft()`](../../../../app/sim/flight_session.gd#L463) assigns prepared data to the session; dynamic `aux`, `continuous`, and `modes` belong to the simulation ([`simulation.gd`](../../../../app/sim/simulation.gd#L24)). Godot 4.7 dictionaries are reference types; `duplicate(true)` copies nested containers but still shares Resources. Path-loaded Resources use a global cache, and `resource_local_to_scene` duplicates only on scene instantiation; neither automatically isolates this plain-dictionary session API. [G3] [G4]

**EL1b/EL2 change and rejecting test.** Keep normalized motor, ESC, pack, and propeller coefficients as immutable definition; keep SOC, polarization voltage, ESC mode, timers, and sample phase in each session's simulation state. Never attach runtime state to a cached definition or singleton. If caching later shares model dictionaries, enforce immutability or copy at the session boundary. Create two sessions from one data path, advance one, and assert the other's state, trace metadata, checkpoint, and continuation stay unchanged. Mutate session state after checkpointing and prove the snapshot is detached. Equal models should retain equal configuration hashes and independent state. Today each load derives separate dictionaries, but the committed model is mutable by reference, so callers must not use it for runtime state. [G3] [G5]

**Sources.** [G3] [Godot 4.7 Dictionary class reference](https://docs.godotengine.org/en/4.7/classes/class_dictionary.html), Description and `duplicate()`; [G4] [Godot 4.7 Resource class reference](https://docs.godotengine.org/en/4.7/classes/class_resource.html), Description and `resource_local_to_scene`. [G5] Local ownership seam: [`FlightSession._commit_aircraft()`](../../../../app/sim/flight_session.gd#L463), [`Simulation` state declarations](../../../../app/sim/simulation.gd#L24), and [`Simulation.checkpoint()`](../../../../app/sim/simulation.gd#L410).

## 06 — What makes an electric checkpoint identifiable and restorable?

**Decision question.** Which identity and state must survive serialization so a compatible fresh session continues the same trajectory?

**Verified findings.** Simulation checkpoint v1 snapshots tick, timestep, body, auxiliary/continuous states, inputs, modes, loads, mass, inertia, gravity, and stop tick ([`Simulation.checkpoint()`](../../../../app/sim/simulation.gd#L410)). Flight checkpoint v4 adds shaft-integrator identity; its SHA-256 digest hashes model, ground, environment, and integrator with `var_to_bytes`. Restore preflights identity/layout; tests round-trip native bytes into a fresh session. This encoding excludes Objects and Callables. [G5] [G6]

`model.data_sha256` uses default `JSON.stringify(..., full_precision=false)`; `input_identity.sha256` hashes exact file bytes. A test shows a late digit can change physics while colliding in the legacy digest, so keep identities distinct. Godot's `full_precision=true` supports exact float decoding, but JSON has one number type and converts nonfinite values specially; retain native bytes for checkpoints. [G7] [G8]

**EL1d/EL2 change and rejecting test.** Include electric law/state layout in checkpoint identity. Persist next-step state: SOC/polarization, ESC mode and timers/sample phase, RPM, tick/time, and inputs. Preserve existing RNG when stochastic weather is active, plus stochastic state introduced later. Put electric identity and initial state in trace metadata, separate from exact input-file SHA. Restore native bytes into a fresh compatible session and compare the next N ticks byte-for-byte. Reject missing or changed battery/controller state, model kind/configuration, layout/version, timestep, or discrete values. Define persistence and compatibility in an explicit format contract; the current physics API returns a dictionary and hashes configuration with `var_to_bytes`. [G5] [G6] [G7]
