# EL2a-P2 — Event-localization sources

2026-10-11 · **Status: numerical design input only; physical validation remains open. Step prefix: EL.**

## Code contract

The expensive scalar is event time h: each battery probe reruns the coupled RK4 trial, and each rotor probe reruns RK4 from the same pre-event state. Interpolation may choose h; it must never interpolate the RK state, energy, heat, body rates, or event list. Keep source laws, RK stage order, the connected zero-charge left-limit query, rotor projection, and event ordering unchanged. See [battery step](../../../../app/physics/electric_battery_step.gd), [rotor stop](../../../../app/physics/electric_stop.gd), and the [EL2a-P1 event-cost record](../EL2a-P1/README.md).

Keep an oriented sign bracket throughout localization:

- Battery: Q(lo)>0, Q(hi)<=0; return the actual high-side trial state, with |Q(hi)|<=1e-10 C and hi-lo<=1e-12 s.
- Rotor: RPM(lo)>0, RPM(hi)<=0; project the actual high-side trial state once, with |RPM(hi)|<=1e-7 RPM and hi-lo<=1e-12 s.

Require both residual and time bounds before accepting. A small residual or exact-zero high value alone does not bound the event time when the residual is flat. A time-width pass alone does not satisfy the residual bound for a steep crossing. Invalid/nonfinite trials fail; a bracket is meaningful only while the trial map remains deterministic and has a continuous sign-changing crossing. The battery path is designed for monotone depletion, not arbitrary hidden oscillatory events.

## Algorithmic choice

A low-complexity candidate is a safeguarded secant proposal with bisection fallback. For finite endpoint residuals f_l>0, f_h<=0, scale by s=max(|f_l|,|f_h|), compute w=(f_l/s)/((f_l/s)-(f_h/s)) and propose h=lo+w(hi-lo). Scaling avoids overflow in f_l-f_h. Clamp the proposal to an open interior gap such as min(0.5 TIME_TOL, 0.25(hi-lo)); verify it is still strictly representable between the endpoints. If an interpolation trial retains more than half the old bracket, force the next trial to the midpoint. This makes skewed/flat secant steps bounded: at least one halving occurs per two localization trials. For segments up to 60 s, a 1e-12 s bracket takes 46 bisections, so a 2x fallback budget fits within 128 probes; electric_stop.gd has no 60 s input cap, so derive its limit from dt or enforce the same cap. If no interior float exists and both acceptance bounds do not pass, fail boundedly.

This safeguard is an implementation choice for this code, not a physical law and not the published ITP algorithm. If a strict bisection-level worst-case call ceiling is needed, consider ITP (interpolate, truncate, project): with its zero-slack setting it preserves bisection's worst-case interval-reduction count while using secant information on regular roots. Its residual gate may still require more probes than the time-width bound, or a bounded failure for a discontinuous/too-steep trial map.

## Proof recommendations

Use exact synthetic ODEs first; count full trial evaluations separately from derivative calls.

- Linear charge: Q(t)=Q0-I t, with a non-grid root and a root exactly at an endpoint. Check the retained nonpositive upper state, charge/time bounds, energy only through exhaustion, and that ordinary roots take fewer trials than bisection.
- Flat but monotone charge crossing: Q(t)=-(t-tau)^3, generated by dQ/dt=-3(t-tau)^2. RK4 integrates this rate exactly; it exposes tiny secant slopes while keeping a known root and valid nonpositive charge rate.
- Residual stricter than time: Q(t)=1e-9-1e6 t C. A 1e-12 s bracket alone can leave a 1e-6 C residual, so the solver must keep refining for the charge bound or fail at its cap.
- Linear rotor: RPM(t)=RPM0-a t, with a non-grid root. Check the nonpositive high state is the sole projection input and the existing tilted-axis angular-momentum balance still holds.
- Keep the battery-first, rotor-first, shared-time, malformed-callback, and unsupported-reverse tests. Repeat each event case in one binary and compare event/state bytes for same-version determinism; preserve rotor-first canonical timestamps for simultaneous events.

These prove localization and numerical integration contracts, not battery accuracy or flight realism. Physical validation still needs identified pack/current data and held-out measurements under EL5/EL6.

- Brent, R. P. (1971), [“An algorithm with guaranteed convergence for finding a zero of a function”](https://doi.org/10.1093/comjnl/14.4.422), *The Computer Journal* 14(4), 422–425. Primary source for combining linear and inverse-quadratic interpolation with bisection on a sign-changing interval.
- Oliveira, I. F. D. and Takahashi, R. H. C. (2021), [“An Enhancement of the Bisection Method Average Performance Preserving Minmax Optimality”](https://doi.org/10.1145/3423597), *ACM Transactions on Mathematical Software* 47(1), 1–24. Primary source for ITP and its average/minimax guarantees.
- [SciPy brentq documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html). Implementation reference: states the continuity and opposite-sign bracket requirements and describes Brent's safeguarded interpolation/bisection combination.
