## Native findings

| ID and verdict | Source check and acceptance boundary |
| --- | --- |
| ENG-01 · Implementation limitation | Fleet admission counts stage/context coverage. Native calls can decline before the call counter, can delegate hooks, and increment the answer counter before the host commits. Dry helicopter is a native-stage route with an explicit integrated-driver refusal. Correlate per-domain answer, stage and delegated-hook counts to accepted tick ordinals before making full-tick ownership claims. [Fleet coverage](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/native-kernel/fleet.gd#L791) · [Native driver](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/native-kernel/src/nk_kernel.cpp#L3473) · [Host commit](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/app/sim/simulation.gd#L481) |
| ENG-02 · Performance opportunity | Dedicated substep current/first-slope vectors and event trial/crossing buffers still allocate on selected routes. The prior 32-double eight-piece fixture counted 2 allocations and 512 requested bytes for plain RK4, versus 25 and 6,400 on the declared clear-event route. Both took 31 additional RHS evaluations after the supplied first slope. Preserve nested-trial ownership, abort/retry behavior, event order and checkpoint bytes. Target time, peak memory and FPS require separate evidence. [Substeps](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/native-kernel/src/nk_tick.hpp#L154) · [Resource crossing](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/native-kernel/src/nk_tick.hpp#L1015) |
| ENG-03 · Performance opportunity | The eligible successful spatial blade-load and wake paths repeat identical propeller inputs; transported wake can add a third evaluation. A separate shaft-torque expression gave different bits at 1,813/4,096 finite fixture pairs. Reuse only the identical tuple within that stage and preserve branch/refusal and operation order. The hosted spatial oracle is a pre-change baseline. Machine call counts and speedup remain unmeasured. [Stage](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/native-kernel/src/nk_stage.hpp#L332) |
| ENG-04 · Performance opportunity | Each valid ground wrapper call decodes 32 required scalar fields, one optional scalar and five packed arrays. Both the binding and solver validate the model and compute corner geometry. Any prepared model must be per session and carry Nitro's live midpoint drive torque. Preserve callback order, road/wet/wall behavior, stale-model refusal and separate ground tolerance/replay gates. The two ground editor jobs do not measure a proposed cache's savings. [Binding](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/rc-monster-truck/native/src/ground_vehicle_native.cpp#L678) · [Solver](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/research/rc-monster-truck/native/src/ground_vehicle_kernel.hpp#L749) · [Nitro adapter](https://github.com/bultodepapas/OpenRCsimulator/blob/4bf5b399e5cafcb5fd101ddcfadecfcd236337cf/app/physics/ground_vehicle/nitro_dynamics.gd#L124) |
