# Prioritized native implementation plan

This plan hands work to existing simulation, native-kernel, aircraft, helicopter, drone, propulsion, battery and ground owners. The audit-local finding IDs identify evidence; they are not new production tracks. The [independent verification ledger](verification.md) controls the final classification. Each domain report gives exact baseline file/line anchors, equations, source applicability and reproductions.

The [refresh review](refresh.md) carries the audit forward to main `4bf5b399` and strengthens these acceptance gates. The original 39 classifications and run receipts remain pinned to their original sources. New equation controls are additional component evidence; they do not increase the historical production-engine assertion count.

All proposed production numerical laws are project-owned float64 C++. The existing reference implementation remains a specification, unsupported-domain fallback and recording compatibility route where required. The host owns input, display and the atomic simulation transaction. No proposed force, collision or solver delegates its physical behavior to Godot. Current engine-driven checks exercise the existing reference path; that does not change the native implementation requirement.

## Ordering and estimates

Correct internal inconsistencies with discriminating witnesses first. Measure actual native ownership before making performance claims. Improve an empirical law only when its data can distinguish the proposed model from the accepted one. Do not enable additional helicopter regimes or add EDF aircraft merely because a component fit succeeds.

Efforts below are **estimated engineering days**, including focused regression and code review, for an engineer familiar with the relevant subsystem. Measurement procurement, hardware access, platform/package promotion and pilot acceptance are additional. Overlapping adapters and tests mean these estimates should not be summed as a project quotation. Expected realism and cost effects are hypotheses to measure unless the cited receipt explicitly measures them.

## 3. Correct passive contact energy with all rotor states included

## 6. Bound the helicopter model and make its frame-dependent work consistent

**HELI-01/02/03 · 7–14 days for the in-domain frame/direction work; additional high-crossflow extension 5–10 days · HELI/NK owners.** Files: `nk_helicopter_main_rotor.hpp`, `nk_helicopter_inflow.hpp`, `nk_helicopter_stage.hpp`, mirrored reference rotor laws and model/version gates. These are distinct issues and should not be fixed by one gain adjustment.

HELI-01 is a documented simplification requiring identification, not a demonstrated net-energy-creation bug. Prioritize the confirmed ground-input contract and in-range direction discontinuity ahead of a physical power-law replacement. The ±167.8731 W disc-ledger residual is a reproducible diagnostic with an explicit model assumption.

Use a common disc frame for force work and shaft power; account for the source model's lumped drag before introducing additional loads. Accept an analytic stand power residual ≤1e−8 W for the declared closure, both tilt/thrust signs and zero-tilt controls. Add a nonzero-body-rate control using F·Uhub = F·UCG + (r×F)·ω in uniform air, with any pure hub couples accounted separately. Validate altered trim and yaw torque on measured flight/stand data before claiming a physical gain.

For ground effect, intersect the signed downstream wake with the available terrain tangent plane using normal clearance as well as wake direction; dividing vertical clearance by a normal-dot-direction alone is wrong on a slope. At vertical h/R=1.1 and V=3vh, the independent ray distances are 10.02074945R over flat ground, 2.92473740R over a plane rising 15° along the wake, and no downstream intersection over the opposite incline. The inclined cases test geometry, while NDARC's empirical construction assumes horizontal ground. The flat case has factor 1 under a finite-range rule; the current 0.887818 is the baseline witness.

Version a continuous finite-range taper if adopting the proposed three-radius support. The existing normalized Hayden factor is 0.9832958363 at 3R, so simply cutting it to one introduces a new 0.0167041637 jump. Independently check both sides of the taper joins, grazing, neutral/opposite thrust, no-hit and inclined-ground cases, reusing the sampled plane. Keep native stages, reference evaluation, diagnostics and saved-state evaluation consistent. The taper is a candidate model choice requiring physical identification, not an already validated X-Cell law.

Replace a discontinuous longitudinal sign extension with a continuous projection derived in the rotor plane. The left/right flap derivative gap must tend to zero as the longitudinal perturbation shrinks, while pure forward/backward controls remain correct. The low-RPM/high-μ pole is a separate envelope problem: either retain an explicit admission boundary or supply a bounded dimensional blade-element branch with identified data. Never enlarge the flight envelope by clamping a divergent formula without a physical rationale. Compare 240/480/960 Hz results. Benefits are continuity, consistent torque/work and a defensible terrain regime; altered trim, re-identification and rotor-stop events are the main risks.
