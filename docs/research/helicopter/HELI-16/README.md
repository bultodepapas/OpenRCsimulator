# HELI-16/17/18/19/21: playable research helicopter

**Date:** 2026-10-13. **Qualification:** software verification of an experimental X-Cell/HX-700 surrogate. Current controls and limitations belong to [HELICOPTER](../../../HELICOPTER.md); remaining steps belong to the [helicopter plan](../../../plans/helicopter.md).

## Implemented boundary

The explicit catalog ID `xcell-60-research` selects `helicopter_main.gd` and `HelicopterFlightSession` through the production Home/direct factory. It uses the existing fixed-step `Simulation` at 240 Hz. Its joint callback integrates 13 body values and six continuous values: main shaft speed, longitudinal/lateral first-harmonic flap, dimensional induced velocity, heading reference and yaw integral. Body acceleration and shaft acceleration come from the same coupled solve. No Godot rigid-body flight solver or float32 simulation vectors are involved.

Terrain-aware hover trim solves zero ground velocity and complete force, moment, shaft, flap and inflow residuals. Each live RK stage uses its current hub height, thrust and world disc normal for ground effect. Four spring/damper skid points add contact loads in those same stages. Analytic instantaneous main/tail disc ground clearance and excessive skid travel stop flight; reset rebuilds the solved hover. This does not implement temporal swept disc/scenery collision.

The dedicated `openrc-aircraft v2` rotorcraft schema uses the project's quantity conventions through a separate strict reader. It does not pretend to satisfy the airplane wing, propulsion or component-inventory schema. Missing evidence, dimensions, extra fields, bad modules, inconsistent signed shaft axes/gearing and unsupported contact stiffness prevent flight. The loader hashes the same bytes it accepted.

Native checkpoints include exact aircraft-byte identity, physical weather, all body/continuous state and controller commands/configuration. Restore validates before mutation and pauses after restore. The standalone 32-column `openrc-helicopter-trace v1` CSV separates endpoint time from the K1 load-sampling time. Decimal values preserve float64 diagnostic precision; CSV is not the exact native replay format.

## Explicit trainer estimates

The preset is generated by [derive.py](../../../../research/helicopter/xcell/derive.py). Its published reference is Gavrilets, Mettler and Feron, [*Dynamic Model for a Miniature Aerobatic Helicopter*](https://users.encs.concordia.ca/~bwgordon/mit_heli_report.pdf). Published values are marked borrowed; assumptions remain estimated or derived in the generated data. This document is the source locator for the trainer estimates, not evidence that they were measured.

| Estimate | Choice and rationale |
| --- | --- |
| Drive | 1.2 N·m torque cap, 1.8 kW power cap, 8.3 engine/main ratio, 0.9 efficiency; finite P-only governor at 167 rad/s with gain 0.08. The torque cap provides hover control reserve. [Actual-preset drive checks](../HELI-07/README.md). |
| Shaft losses/inventory | 0.08 N·m dry plus 0.001 N·m·s/rad viscous loss. Main radial-blade inertia is twice the published single-blade flap inertia; tail reflected inertia is 5% of that estimate. Signed main/tail axes are explicit; unknown engine spin inertia is excluded. [Coupled mechanics](../HELI-08/README.md). |
| Controls | Normal/idle-up five-point pitch/throttle curves, 0.22 rad collective and 0.06 rad cyclic linkage limits. Instantaneous swash response is declared; physical servo lags remain open. |
| Electronics | Tail heading/rate PI and roll/pitch trainer feedback through actual control angles. Maximum trainer tilt 0.35 rad and requested rates 1.5 rad/s; controller gains and yaw sign remain surrogate estimates. Collective has no altitude hold. |
| Wake/airframe | Tail wake efficiency 0.9, fin-tail wake fraction 0.2, 0.1 m/s transient flow floor, unit inflow loss and zero instability multiplier. Unknown fuselage CP is at CG and horizontal-tail height is zero. |
| Ground | Four source-measured visual skid corners relative to the chosen visual CG; 10,000 N/m spring, 190 N·s/m damper, friction 0.5 and 0.15 m/s regularization are estimates. Source geometry does not establish X-Cell physical gear dimensions. |

The 8.2 kg and diagonal inertia are the published instrumented configuration, used as an aggregate locked-body assumption. A measured component inventory and an identified HX-700 model remain open. The HX-700 visual is flybarless, while the reference flap law includes an effective flybar. [Blender provenance and adapter](../HELI-25/README.md).

## 2026-10-14 deep audit (HELI-09/16-R1)

The audit covered authoring/preparation, coupled flight and ground clearance, controls, configuration transactions, native replay, recording and the production presentation route. The existing X-Cell/HX-700 surrogate remains the flight configuration. No generated aircraft quantities, solver timestep, 19-value state layout or golden flights were changed.
