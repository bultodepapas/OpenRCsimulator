**2026-10-15; animation continuity updated 2026-10-16 · Windows · Godot 4.7.2-stable · Blender 5.2.2 LTS.** This work targets only the advanced articulated HX-700. The existing neutral export now has a working interactive mechanism inspector. ## Implemented mechanism

The offline extractor reads the immutable owner's `.blend` in a disposable process with automatic Python execution disabled. It records 31 object transform recipes and their explicit scalar-property dependencies, including parent-inverse frames and XYZ Euler order. A restricted arithmetic compiler emits native GDScript equations, pins the construction/source identities and exact snapshot bytes, and excludes source aerodynamic precompensation. It does not execute Blender driver strings at runtime.

The inspector drives three cyclic servo horns, tail servo, fixed/rotating swash, main/tail grips and blades, tail rod/bellcrank/slider/yoke and source transmission transforms. Grips and blades remain siblings, so feather pitch is applied once. Mast alignment, gearbox cases and the nonrotating swash/slider are preserved. Collective, cyclic and tail remain distinct inputs, with the source's phase-dependent mechanical coupling retained.

Every candidate is checked before any node transform is committed. All nine rod distances must remain within 2 µm of the neutral construction length. Each endpoint frame follows its own parent, then receives the shortest swing aligning its authored rod axis with the other ball; rod meshes retain their neutral local transforms/scales. Out-of-range/nonfinite inputs and an unreachable +100 mm rod are refused atomically. This removes the need to use Blender's Stretch To as a runtime rod-length law.

### Terminal rotation correction · 2026-10-16

The previous world-neutral orientation rule preserved endpoint positions but cancelled the carrier's rotation. Main-head sockets could differ from Blender by a half-turn, and tail sockets also failed to follow their yoke/grips. Earlier checks explicitly excluded terminal bases, so their successful position/length results did not establish correct socket orientation. The corrected rule carries the neutral local rod axis through each current parent frame before aiming it. It is evaluated from the requested pose, without previous-frame orientation or accumulated twist.

All 18 terminal bases are now included in the existing independent Blender oracle comparison. The verifier reconstructs the old orientation rule in disposable scripts: [negative-control log](world-neutral-rotation-rejected.log) must fail exactly the source-orientation and head-half-turn assertions while completing the remaining checks. [Quarter-turn head](head-quarter-turn.png) and [tail](tail-quarter-turn.png) captures expose the rotating connections.

## Scope

This is a bounded kinematic inspector, not a newly qualified flight model. The original source's two-pass swash reconstruction is accepted only for the tested input domain and only while its measured linkage residuals pass. No general convergence guarantee is claimed. Source maintenance adjustments are pinned to neutral; tail-belt shape-key tension, subtrim and rod adjustment controls are not exposed. Presentation smoothing and inspection-speed ramps do not represent actuator lag, load/voltage response or achieved flight servo state. Coning and elastic-blade dynamics remain absent.

No legacy model code, flight solver, physical coefficients, replay format or golden flight was changed. The laboratory candidate's contact provenance classification was corrected through its generator. The full application test suite and production release export were not rerun for this advanced inspection audit. `app/test.sh` includes compiler/generator freshness, source-integrity checks and the native tests; CI's existing schema environment checks the candidate contract. Flight integration, source-material baking, flight LOD/blur, distribution admission and physical/hardware qualification remain open.
