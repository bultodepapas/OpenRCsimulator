# Native component evidence, 2026-11-08

A noninstallable Linux x86-64 profile build with the pinned GCC 13.3.0 and strict floating-point flags was compared with the current GDScript reference. The [aerodynamic oracle](aero-oracle.json) matched all 352,065 comparisons, including 432 Corsair and 416 P-51 nonzero flap-offset witnesses with oblique flow. The [propeller oracle](propeller-oracle.json) matched all 34,994 comparisons, including 69 Corsair samples beyond its below-floor Ct endpoint. These are component comparisons, not native fleet or package qualification.

The [build receipt](development-build.json) binds the source, compiler, flags, binary and compilation database. [Before](inputs-before.json) and [after](inputs-after.json) manifests show unchanged native, mirrored source, harness, engine, descriptor and binary hashes; HEAD moved during the run without changing those inputs. The checked [aero](aero-checked.json) and [propeller](propeller-checked.json) receipts retain exact commands and log hashes. The aero receipt records one JSON serialization warning for intentional nonfinite test values; there were no engine errors or mismatches. Detailed temporary build files remain under `tmp/audit-corsair-runtime-20261108/native-profile/`.

The separate [stale-library check](stale-fallback-checked.json) passed 83 checks on Linux, refusing the installed library before loading because a mirrored aircraft input differed, then advancing the reference backend. The [installed identity comparison](installed-native-hashes.json) records the matching binary and stale source hashes. Native installation, fleet, package and target-hardware gates remain open.
