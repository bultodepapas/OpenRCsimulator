# Visual-quality plugin candidates: upstream check

**Checked:** 2026-10-06, against the app context in `AGENTS.md`: Godot 4.7.2, Compatibility, custom float64 flight physics without `RigidBody3D`, and deterministic shader time through `sim_clock`. This is source research only: no plugins installed, no app changes, and no candidate was tested in Godot 4.7.2. An upstream version label is not proof of compatibility with this exact build or the Win/Linux/macOS exports.

Revision links below pin the checked GitHub `main`/`master` HEADs observed with `git ls-remote` on the check date. Road Generator is pinned to its release tag. Asset Library metadata is linked separately because its published version/license fields are distinct from repository licensing. Free download does not establish that every sample asset has one shared license.

## Plan mapping

- **L11:** Simple Grass Textured is shader/editor reference only; its `TIME` and own wind globals require a port before even a visual comparison can satisfy L0d. Forest Demo inherits that issue in both grass and tree sway and its whole project targets Forward Plus, so it does not replace the planned L6 tree-source trial or L11 implementation.
- **L10:** KayKit is an optional offline prop source. Review each candidate object’s dimensions and silhouette against the field plan; no collider is established by the repository. Forest Demo assets require per-file license checks.
- **L5 / L14:** Road Generator can become relevant only if a road/taxiway need is added. Its advertised generated collision data is not evidence of equivalence with the custom simulation’s collision/surface model; current L5 explicitly protects collision behavior.
- **L18 / VQ-07:** No candidate justifies either gate by itself. Boujie water is a future water visual candidate with an unresolved Compatibility check; WaterBox is a separate RigidBody3D water-physics system. Road Generator and the forest demo target unrelated needs. VQ-07 remains the existing isolated Forward+ comparison, not a general plugin-compatibility promise.
- **L19:** No candidate implements the project’s time-of-day plan. Any adopted animation shader still has to consume the established simulation clock and preserve repeatable captures.

## Limits

No addon was installed, run, imported into the app, or tested on Windows/Linux/macOS. No claim here establishes Godot 4.7.2 Compatibility support. Recommendations classify research fit only; they do not add product commitments or change the visual roadmap.
