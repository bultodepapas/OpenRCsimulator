# P-51D Mustang quarter-scale, 120 cc class

2026-10-12 · Revision 4 · **Status: experimental aircraft implemented; source-driven realism work and owner flight review remain open.** Prefixes: `P51-` and `P51-V`. Owned paths: `assets/aircraft/p51d-mustang-120/`, `app/aircraft/p51d_*`, `app/aircraft/verify_p51.gd`, `app/aircraft/inspect_p51.gd`, generated `app/data/aircraft/p51d_mustang_120.json`, `app/tests/test_p51_handling.gd`, `app/tests/test_p51_envelope.gd`, `app/tests/test_p51_ground.gd`, `app/tests/p51_envelope_base.gd`, `research/p51/`.

The reference is an estimated quarter-scale, 120 cc-class P-51D configuration. The catalog ID is `p51d-mustang-120`. The model flies in the app, but no matched real-aircraft flight validation has been completed. Full-scale NACA reports and RC-class references inform the model; they do not certify this particular build.

## Sources and implementation

Edit [source.json](../assets/aircraft/p51d-mustang-120/source.json), then regenerate `geometry.json` and the Godot geometry with the two builders documented in the [asset README](../assets/aircraft/p51d-mustang-120/README.md). Silhouette measurements are generated from the public-domain three-view described in the [metrology method](../research/p51/p51-02/silhouette/README.md). The physics file `app/data/aircraft/p51d_mustang_120.json` is generated by [derive_physics.py](../research/p51/p51-05/derive_physics.py); never edit generated outputs by hand.

The procedural builder preserves the shared aircraft interface and stable surface hinges. It currently includes the measured-outline airframe, transparent canopy, pilot, fixed-down landing gear, four-blade propeller, control surfaces and a generic natural-metal finish. The livery uses a red spinner/nose band, olive anti-glare panel and yellow tips/rudder; it has no unit markings and is not an owner's selected scheme. See the [visual comparison](research/p51-visual-review-v2.md).

## Limits and next evidence

The geometry is scaled from a three-view and fitted against an oblique owner photo; small parts and concealed shapes remain estimated. Kit span, CG, control throws, engine and propeller configuration are estimates or borrowed class references. The existing envelope and handling tests verify numerical behavior against the model's own assumptions. They are not evidence of matching flight feel, measured inertia, actual engine/propeller output, structural limits or a validated spin envelope.

Keep the aircraft labeled experimental until source-driven corrections, a matched build's mass/CG and propulsion data, and owner flight observations are reconciled. The separate [P-51 realism plan](P51-REALISM-PLAN.md) owns P51-15…18; its [audit and results](research/p51-realism/README.md) document the paired-hardware inertia correction and remaining physical acceptance. Flaps, retracts, and any changes to shared propwash, slipstream or shaft-balance modules must be coordinated with the physics owner.
