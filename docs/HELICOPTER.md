# RC Helicopter Research Trainer

The experimental rotorcraft route uses published X-Cell .60 SE equations and the supplied HX-700 Blender visual. The visual is flybarless; the flight reference includes an effective flybar response. This pairing is a research surrogate, not an identified HX-700 flight model.

Select **RC Helicopter Research Trainer** on Home and press **Fly**. It starts in a solved airborne hover. Home removes unqualified turbulence while retaining the supported wind/gust settings and displays that restriction. Direct launch from the repository root:

```powershell
& .tools/Godot_v4.7.2-stable_win64_console.exe --path app -- --aircraft=xcell-60-research
```

The arrow keys command cyclic; Up moves the nose down and Down pulls it up. A/D command yaw. W/S change collective. R restarts the trimmed hover; P pauses/resumes; C cycles pilot/chase/orbit/close-up views; Esc opens the normal pause menu. K and Enter operate the existing radio calibration. A newly connected physical radio must report low collective to arm; return it to the hover percentage shown by the HUD before pressing P. A gamepad preserves the solved hover collective.

The default trainer applies attitude/rate feedback through cyclic and heading/rate feedback through tail pitch. Collective remains the pilot's responsibility. G selects direct cyclic, I changes the pitch/throttle curves, and H selects zero delivered drive torque. Mode changes can change collective at the same stick position. Zero-drive hold is a one-speed drive proxy; it is not a separately simulated clutch/freewheel or a qualified autorotation mode.

The state is float64: body position/velocity/quaternion/rates, main shaft speed, two disc-flap harmonics, induced velocity, heading reference and yaw integral. All body, shaft, flap, wake and controller derivatives use the same RK stages. Ground effect uses the current hub height, thrust and world disc normal. Spring/damper skid loads enter those stages; rotor ground clearance and excessive skid compression stop the flight. R recovers after a crash or numerical fault. Reduce collective as the ground-effect cushion builds during landing.

The authored quantities and rotorcraft schema are generated by `python research/helicopter/xcell/derive.py`. The dedicated v2 reader rejects missing evidence, wrong units, unsupported modules, invalid inertias and unsupported contact stiffness. Do not edit generated JSON. [HELI-25](research/helicopter/HELI-25/README.md) owns Blender provenance, measurements and the export adapter. [HELI-16 evidence](research/helicopter/HELI-16/README.md) owns the flight verification.

T records a rotorcraft trace. The CSV stores all 19 continuous values, four pilot commands and six loads, with separate endpoint and load-stage times. It uses `openrc-helicopter-trace v1`; airplane engine/servo columns do not describe this vehicle. A recording error prevents saving a misleading partial trace.

Exact replay uses native Variant `openrc-helicopter-checkpoint v2` checkpoints. Restore checks aircraft bytes, weather, exact ground surfaces and authored start position, accepted mass/gravity/inertia, sampled commands, rotor RPM projection and flight domain before committing, then pauses. Historical v1 checkpoints are refused because they lack field/start identity; record them again. A crash hold cannot be checkpointed away. Changing the model, field, weather or start before the first tick requires a new solved hover; live configuration edits are refused.

Rotor visuals accumulate phase from accepted fixed-tick shaft speeds and interpolate with the body; rendering does not evaluate the complete flight model. Phase is currently presentation state: reset/restore rebases it to zero. Exact articulated phase/servo replay still requires the planned simulation-state extension. [Audit, regressions and measured costs](research/helicopter/HELI-16/README.md#2026-10-14-deep-audit-heli-0916-r1).

Current qualification is software verification. Pilot validation, aircraft-specific drive/controller calibration, a separate engine/freewheel state, servo response states, full rotor/scenery disc contact, wake-driven environmental effects and the proposed H15 performance gate remain separate acceptance work in the [helicopter plan](plans/helicopter.md). Weather supports steady wind and deterministic gusts; unqualified turbulence is refused. The airplane flight route remains separate.
