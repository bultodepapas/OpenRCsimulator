## The scene: a hangar that keeps opening

The user's idea is a fast succession of many airplanes: distinct silhouettes, immediate changes, a feeling of abundance. Give the sequence a stable visual grammar so speed remains readable.

## Framing, rhythm and sound

- Keep each model large, at a comparable three-quarter view, with a stable visual center, neutral preview background and matched exposure. Preserve native proportions; framing may normalize screen occupancy, not imply equal physical size.
- Group the sources. Hold **PHOENIX RC · MODEL PREVIEWS** for five seconds, then **CLEARVIEW · MODEL PREVIEWS** for five seconds. The source label stays still while silhouettes change.
- Use hard cuts on an editorial percussion pattern. Exact music beats remain unmeasured. The one-second leaders establish each block before the half-second run.
- Do not ask the viewer to read 18 changing names. Candidate names below belong to production notes, not rapid title cards.
- Use actual Creator previews, including a crop of the genuine preview viewport if the label remains readable. No generated airframes, foreign-simulator footage or separately invented rendering is passed off as an OpenRC import.
- Give the final model the same orientation/skin identity in its flight payoff. Setup can occur between recorded stages; the edit does not claim conversion and flight preparation are instant.
- The preview reel has music/editorial accents, not a fabricated engine demonstration. Actual propulsion sound enters with the qualified trial.

This rapid reel contrasts with the preceding ten-second Corsair orbit and six-second lake hold. Keep the lake's final frame long enough to resolve before the import chapter begins.

## What the importer actually establishes

| Stage | Implemented route | Trailer meaning |
| --- | --- | --- |
| Phoenix source | Select a local .mod, with sibling .geo and textures; stock installation data can supply additional observations/polars. | Actual local-source import; not a promise that every community PKG or archive opens directly. |
| ClearView source | Select a compatible ZIP and, when necessary, one model root from its inventory. | Multiple roots can be discovered in an archive; conversion is still model-specific. |
| Accepted preview | Converted geometry/textures are admitted to Creator. | Appearance is demonstrated. Flight eligibility is a separate result. |
| Experimental setup | Supported Phoenix airplanes/gliders can derive an OpenRC setup partly from their source values; ClearView can use estimates or explicit stock donors. | Sizes, geometry, control throws and handling may be fitted/estimated. The original simulator's full flight physics is not preserved. |
| Eligible trial | Accepted source, configuration, placement and available start pass the trial route. | A genuine experimental test flight of that exact model may be shown. |
| Saved draft / Home | Drafts can be reopened; converted models do not become normal published Home aircraft through this source path. | Do not advertise a newly installed 300-aircraft stock fleet or universal saved-Home flight. |

Phoenix helicopter/multirotor conversions are appearance-only in the reviewed route. ClearView has labelled donor alternatives, including helicopter and flying-wing visuals on stock dynamics; those are not automatic flight fidelity. The proposed montage uses fixed-wing/glider appearances, and only the last specifically qualified model gets the flight claim.
