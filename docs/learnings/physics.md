# Physics, data, and performance lessons

**Status:** curated developer reference. These are observed failure modes and practical checks, not current feature status or physical validation. Measurements and platform behavior belong to the linked dated evidence; current contracts and runtime code take precedence. See [LEARNINGS](../LEARNINGS.md) for shared lessons, [STACK](../STACK.md#boundaries-and-data-flow) for the kernel boundary, and [AIRCRAFT_CONTRACT](../AIRCRAFT_CONTRACT.md) for aircraft data.

## Integration, state, and events

### Every coupled continuous state needs the same integration stages

A continuous wake advanced once per tick lowered the order of an RK4 body solve. Evaluate every coupled continuous state and its time-dependent loads at the same stages, and use a nonautonomous analytic oracle to catch frozen stage time. Sampled controls and discrete modes have explicit tick boundaries. The state layout can depend on the resolved start: helicopter pad friction adds states absent from another start, so declare it at start and keep it fixed through reset and restore. [H8a](../research/simulation-state/H8a/README.md), [E0b5](../research/propwash/E0b5/README.md), [SF-02](../research/simulation-foundation/SF-01/README.md).

Full-load RK4 substeps with matching inputs and boundary updates matched a finer-tick reference byte for byte in the SF-05 stiff-contact fixture. This evidence applies to that tested integration policy and setup; holding slow loads instead creates a split method that needs its own accuracy argument. A numerical stiffness bound is not a measurement of real gear. [SF-05](../research/simulation-foundation/SF-05/README.md), [H11](../research/simulation-state/H11/README.md).

Local event-bracket precision and absolute-clock rounding are different: a positive post-event remainder can still change state when `time + remainder == time`. Check local time and residual, including near-endpoint events at nonzero clocks. Detect resource crossings by strict sign comparison before applying root tolerance; multiplying subnormal endpoints can underflow and invent a crossing. A stop-locator oracle must use the locator's smooth trial continuation across zero, not a derivative kink. Qualify an adaptive reference's final status, event direction and re-arming as well as its step refinement. [EL2a-P2](../research/propulsion/EL2a-P2/README.md), [FUEL-12-R2](../research/fuel-systems/FUEL-12/HARDENING-R2.md), [SF-04](../research/simulation-foundation/SF-04/README.md), [EL1a-R2](../research/propulsion/EL1a-R2/04-verification-tools.md#11--how-should-an-independent-solver-verify-the-fixed-step-implementation).

### Restore the complete transaction

A resumable boundary includes previous and current body state, coupled lags, sampled inputs, discrete modes, RNG, tick/timestep, configuration, mass properties and stop condition where applicable. An observer that can reject a tick *after* kernel commit also needs transaction coverage; SF-03 preserved it with a pre-step checkpoint and rollback. Check a restore by advancing a fresh compatible owner, and validate derived caches before committing history. JSON is useful diagnostics, not a bit-exact state store; recorded tolerance metadata must not loosen code-owned limits. [H8](../research/simulation-state/H8/README.md), [H8-R1](../research/simulation-state/H8-R1/README.md), [H9](../research/simulation-state/H9/README.md), [SF-03](../research/simulation-foundation/SF-03/README.md), [C7-R2](../research/trace-integrity/C7-R2/README.md).

A seed alone does not make stochastic forcing replayable: stage or render queries must not advance the sampled RNG, and its exact state and filter interval must roll back together. In M5-W04a, the seed initializer and recurrence increment also differed; use the actual runtime convention in an independent replay. Preserve int64 RNG state losslessly. [M5-W04a](../research/wind-implementation/M5-W04a/README.md).

Located events in `sim.last_events` are overwritten on the next tick; consumers spanning multiple ticks need the event signal or equivalent accumulation. Conversely, repeatedly adding `1/240` fell just short of an exact half-second boundary: prefer integer tick counts for exact holds, or specify and test a sub-tick tolerance when a sampled timer must use seconds. [BAT-10](../research/battery/BAT-10/README.md#defects-found-and-fixed-during-integration), [E3c2a](../research/ground-contact/E3c2a/README.md).

### Diagnose the regime before changing tolerances

A contact refinement ratio near two can result from switched wheel contact, while a whole session can converge near first order during sampled control transients even with every wheel loaded. Inspect contact modes and event times, compare constant-control and full-session runs at three rates, retain absolute cross-rate bounds, and test formal order in a matched smooth case. A bounded hybrid result does not establish physical accuracy or converged event timing. [E2](../research/ground-friction-e2.md), [E5a](../research/ground-contact/E5a/README.md), [hybrid fixture](../../research/ground-contact/e5a/README.md).

A source equation and its independent transcription can share a sign error. Check force work against the *local* relative velocity and the equivalent wrench: aerodynamic flow is `vCG,air + ω×r − vwake`; a rigid contact point translates at `vCG + ω×r`, with wheel spin or deformation included when modeled. A CG-axis passivity assertion suitable for the tested pure-translation gear case can fail with body rotation; sum work at the relevant contact velocities instead. Moving air can do positive work on the body, so do not demand that world-frame aircraft kinetic energy always decrease. Preserve source-sign conflicts explicitly. [HELI-06b/c](../research/helicopter/HELI-06b/README.md), [SF-06](../research/simulation-foundation/SF-06/README.md).

### Scope exactness to the tested execution

Frozen reference code can establish preservation of an old bug. Compare complete states and branch decisions for intended equivalence, and retain a separate analytic or physical oracle for correctness. A changed early return can be invisible in a bit-identical trajectory; validate branch instrumentation with a mutation. Preserve operation and accumulation order when byte identity is required, including signed zero. [H12](../research/simulation-state/H12/README.md), [E4b](../research/ground-contact/E4b/README.md), [RCV-40](../research/rc-monster-truck/RCV-40/README.md).

Do not generalize bitwise identity from one build. A wind fixture differed slightly between the tested Windows and Linux math libraries; another x86/GCC native port differed in NaN sign despite matching finite values, because operand and engine-helper evaluation order differed. Capture or compare against the frozen implementation on each supported execution environment, including its engine, compiler and math backend; probe special values and helpers if they are part of the claimed contract. [M5-W05d-R1](../research/wind-implementation/M5-W05d-R1/README.md), [NK-3](../research/native-kernel/NK-3/README.md), [rounding reproduction](../research/physics-audit-2026-10-14/remediation/R11/rate-guard-rounding/README.md).

## Ground, contact, and starts

### Compare support and contacts with the built geometry

Validate a supported resting configuration against the full lower coplanar support facet, projecting the CG along gravity in the resting attitude. Testing a body-axis projection misjudges a taildragger; testing each triangle separately can put a centered CG on an artificial internal diagonal. Use the same projected reaction shares for gear stiffness when equal vertical sag is intended. A nose-over oracle must also identify the actual attitude and first contact event; penetration changes a compliant contact's lever arm. [D1-R3](../research/aircraft-validation/D1-R3/README.md), [E5a](../research/ground-contact/E5a/README.md), [E5b](../research/ground-contact/E5b/README.md).

The Stik's wheels and crash hull each drifted from the rendered model while checks re-derived positions from the same mistaken datum. Compare contact points to the *built* model through the manifest's datum transform, across attitudes, and cover legacy/fallback routes with fixtures rather than requiring shipped aircraft to use them. Model-origin, leading-edge and physics reference positions must be transformed into one frame before asserting a discrepancy. [GP-06](../research/ground-physics/GP-06/README.md), [GP-07](../research/ground-physics/GP-07/README.md), [E0b2](../research/propwash/E0b2/README.md), [corrected Stik datum](../research/aircraft-standardization/AS-00/ugly-stik-reference.md).

### Test the integrated contact law, not only its formula

A passive spring and an integrator stability bound do not establish touchdown accuracy. Check ring-down, step refinement and independent switched-contact cases. Join damping continuously with a continuous slope below the resting compression: placing its kink at rest spoils smooth-regime convergence. Integrated restitution also depends on damping ramps and non-pulling clamps, so measure bounce with the actual law and integrator. Simultaneously touching points can exceed a per-point stability bound; account for their combined rates and spacing. [E1b](../research/ground-contact/E1b/README.md), [H11](../research/simulation-state/H11/README.md), [GP-07](../research/ground-physics/GP-07/README.md).

Velocity-only rolling friction creeps under a steady parked load. In the anchor model, initialize each new per-wheel anchor unloaded, size its spring by static load share, and release on sustained elastic force instead of a damper spike. Include wheel rotational inertia `I/R²` in rolling-acceleration oracles, require small slip before acquiring an anchor, and check breakaway against independent force *and moment* balance. Breakaway factors are estimates until measured. [E3b1](../research/ground-contact/E3b1/README.md), [GP-05](../research/ground-physics/GP-05/README.md).

Query a field surface under each wheel, not only the CG, and prove that the selected field reaches the real session. Keep aircraft tyre properties distinct from field scaling. A model contact can identify tick-end penetration without locating first impact: retain detected and reconstructed timing separately, distinguish contact-point and CG speed, and leave wheel-contact speed unknown if compression velocity is unavailable. A rotating point can enter and exit between clear endpoints, so use the pose interpolation's crossing rather than interpolating endpoint depths. [E3a](../research/ground-surfaces-e3a.md), [CR-01a](../research/crash-damage-investigations/CR-01a/README.md), [CR-01b](../research/crash-damage-investigations/CR-01b/README.md).

Contact-point effective mass grades a first strike but can understate an oblique impact when the CG still carries normal energy into a second contact. Bound both contributions without counting sliding speed as normal impact energy; CR-08b's residual estimate ignores body rotation and is not a general bound for a spinning airplane. When a contact system has a capped obstacle budget, rank candidates near the actual impact: taking the first inventory entries omitted the struck object after scene geometry grew. [CR-08b](../research/crash-damage-investigations/CR-08b/README.md), [CR-17a](../research/crash-damage-investigations/CR-17a/README.md).

### Solve and verify the intended runway state

Letting an aircraft settle can leave timestep-dependent slip; a small equilibrium residual can also select the wrong support set. Seed pose from the intended contact plane, solve engine-off rest, place anchors, then solve idle with anchors fixed and world-vertical force balance including tilted thrust. Require the intended contacts to stick, and validate with the actual session. This establishes the model's equilibrium, not measured resting attitude or breakaway. [E3b2](../research/ground-contact/E3b2/README.md), [TT-11](../research/timber-integration/TT-10/README.md).

A one-dimensional takeoff integral sharing simulator thrust and aero checks ground coupling, not force fidelity; fixed attitude is an invalid comparison after the aircraft pitches. Drive it with the recorded attitude to isolate that coupling. For landing, a soft touchdown and eventual stop can hide an overrun onto rough ground: check every wheel during rollout, an idle hold inside the strip, and the real session crash detector. Keep circuit handoffs in one continuous flight with actual state bounds. [E3b3](../research/ground-contact/E3b3/README.md), [E3c1a](../research/ground-contact/E3c1a/README.md), [E3c2a](../research/ground-contact/E3c2a/README.md).

## Aerodynamics and aircraft behavior

### Check every load regime and the applied maneuver

An intact coefficient oracle can mask changes to local strips: EM-31 removed wing strips yet retained intact cruise lift and zero rolling moment. A damaged topology must bypass or rebuild the intact oracle, and partial-panel representation depends on strip resolution. More generally, a term present in only one load regime can disappear inside a smooth blend; differentiate the oracle, local law and blend over the operating range, including sideslip and stall approach, before tuning a maneuver. [EM-31](../research/failure-mode/EM-31/README.md), [D10-R5](../research/flight-dynamics/stik-roll-sideslip-2026-10-19/README.md), [D10-R3](../research/extra-300-realism/EX-14/README.md).

Matching maximum lift does not fix the post-stall slope or departure severity. Check joined curves, local strip incidence and table interpolation support, derivative magnitude, perturbation growth, actual control ramp and recovery at the maneuver speed. Refine strip count with fixed physical inputs as well as any recalibrated sweep. Quasi-steady strip fits that match static lift and onset damping have also suppressed observed spin; assess static lift, damping and a held-out maneuver together, noting that forced-oscillation damping can include sideslip-rate terms. [D8b-R2](../research/flight-robustness/D8b-R2/README.md), [experiments](../research/flight-robustness/D8b-R2/research-experiments.md), [D8b-R2d](../research/flight-robustness/D8b-R2/analog/README.md).

A controller can hide changed physics, and a failed maneuver can be the controller's fault. Record applied inputs, trims, saturation, rates, angles and altitude; establish that the pilot actually achieved the card before interpreting aircraft results. Replay applied controls with the same state/modes and crash detection when isolating physics. Re-trim a changed coefficient before judging stability, and measure oscillatory recovery over a period or mode envelope rather than one phase-dependent sample. Freeze the same app and runner inputs for baseline and candidate on a shared tree. [FT-01](../research/flight-test/FT-01/README.md), [P51-22 correction](../research/p51-realism/P51-22/README.md#resolution--2026-10-16), [E4a](../research/ground-contact/E4a/README.md), [D10-R2](../research/flight-dynamics/stik-lateral-directional-2026-10-18/README.md#6-decisions-and-adoption-d10-r2-2026-10-18), [FT-04](../research/flight-test/FT-04/README.md).

Setting a session command does not itself prove that synchronous `sim.step()` sampled it. Assert the recorded commands and resulting RPM. When reconstructing a propulsion query from a trace, use the declared sample times: the G1b1 trace combined previous-state velocity with current auxiliary RPM, so same-row velocity described a different operating point. [G1b1](../research/propulsion/G1b1/README.md).

### Derive geometry and coefficients for the target aircraft

A borrowed `Cma` carries its donor's static margin, and a visual master need not contain flight rigging angles. Derive pitch stiffness and neutral point from the target geometry, CG and downwash; source incidence and throws from the appropriate handbook, kit or measurement. F4U-12 mapped its manual's one recommended throw set to maximum travel and made the default rate too small; check the source's intended rate and derive any extra travel from evidence. Compare absolute trim as well as trim gradient at matched lift and CG. [D6e-R1](../research/flight-dynamics/climb-trim/README.md#root-cause-review-2026-10-13-d6e-r1), [F4U-07](../research/f4u-corsair/F4U-07/README.md), [F4U-12](../research/f4u-corsair/F4U-12/README.md), [P51-19](../research/p51-realism/P51-19/README.md).

Whole-aircraft balance is about the CG: reference-point coefficients acquire `r × F` moments when moved there. Check control-surface partitions against independently published areas, chords or spans; a hard-coded metrology hinge produced a plausible outline but a rudder 43% too small. A match in steady response can hide wrong mass properties because flight identifies combinations such as damping/inertia. [P51-25](../research/p51-realism/P51-25/README.md), [P51-24](../research/p51-realism/P51-24/README.md), [D11d](../research/aero-consistency/D11d/README.md).

XFOIL overpredicted a tested 23012 section's maximum lift and slope at model Reynolds numbers; calibrate the level against applicable measured sections and use modeled trends within their limits. A VLM midpoint induced-drag approximation gave implausible efficiency on a kinked Corsair quarter-chord; check the formulation against a far-wake/Trefftz-plane result and an appropriate independent planform reference. The observed near-one efficiencies of those test wings are not a universal value for every planform. Manufacturer propeller tables govern where available; transferred BEM fits carry uncertainty. [F4U-07](../research/f4u-corsair/F4U-07/README.md#method-corrections-found-while-deriving).

### Preserve physical decomposition through nonlinear consumers

Folding downwash into an effective static tail slope matched linear coefficients but distorted pitch-rate damping, control angles and stall in nonlinear flight and omitted the downwash-lag response. Emit the physical slope, control effectiveness and downwash separately; compare static and dynamic responses across every catalog aircraft and load regime. A continuous blend can still have a sharp derivative change; test its derivatives and time-domain response, including lag state. Under D11g's linear assumptions, the fin contribution `Cnr_fin = -2(l_v/b)·Cnβ_fin` also checks geometry-derived yaw damping; whole-aircraft damping includes other contributions. [E0a2c](../research/aero-consistency/E0a2c/README.md), [D11d](../research/aero-consistency/D11d/README.md), [D11g](../research/aero-consistency/D11g/README.md).

A flap's incremental lift changes pressure over the section, not solely at the flap-panel center. Use a consistent lift and quarter-chord moment relation, update induced drag and wake, and distinguish the intrinsic wing moment from the complete airplane's tail response. A ground-effect increment likewise must subtract the baseline already embedded in each oracle; align the regimes and feed the same terrain/environment inputs to static and session solves. A downwash fit for one wing and tail geometry does not automatically transfer to another. [AV-09](../research/avanti-flaps/AV-09/README.md), [M5-GE-1](../research/ground-effect/M5-GE-1/README.md), [P51-20](../research/p51-realism/P51-20/README.md).

A wash centroid or matching outline does not determine distributed tail loads. Integrate axial and swirl profiles over the real tail, splitting at profile kinks and comparing against a dense reference; evaluate washed and free loads with the same tail law and downwash state. Check source equations in the model's own variables and limiting cases: a sidewash candidate matched its target only because axial deflection was counted twice. These research comparisons are not Stik propwash calibration. [E0b3a](../research/propwash/E0b3a/README.md), [E0b3b](../research/propwash/E0b3b/README.md), [P51-26](../research/p51-realism/P51-26/README.md).

Rotorcraft source laws need the same independent checks: printed inflow tables had endpoint and crossflow-join issues, and a flap-rate transcription passed zero-rate cases despite wrong units. Test one-sided values in every parameter and isolate terms with dimensional known answers before trusting a complete oracle. Ground-effect activation also needs wake geometry, not only signed body-axis thrust. [HELI-04](../research/helicopter/HELI-04/README.md), [HELI-05](../research/helicopter/HELI-05/README.md).

## Propulsion, environment, and mass

### Preserve power and measurement boundaries

`QΩ − TV ≥ 0` does not constrain static thrust at `V = 0`. For quasi-steady positive thrust and forward inflow, also test the independent actuator-disk minimum power using the actual disk area; preserve the signed windmilling domain. Even these necessary bounds do not validate inferred blades. Anchor an engine to measured RPM on known propellers and check implied torque/power and brake mean effective pressure; catalog ratings and thrust-only fits are not installed shaft-power measurements. [NITRO-02](../research/glow-engines/NITRO-02/README.md#momentum-bound-correction), [VAL-7a](../research/validation/VAL-7a/README.md), [F4U-07](../research/f4u-corsair/F4U-07/README.md#method-corrections-found-while-deriving).

An electric motor's DC-equivalent current, battery current and BEC output current are different measurement planes; for an ideal averaged ESC, pack current from the motor is duty times equivalent motor current. Include auxiliary draw on the pack side, document Kv and phase/equivalent-port conventions, and do not infer a limiting law or cutoff preset from a family rating alone. [EL1a](../research/propulsion/EL1a/README.md), [motor/ESC source review](../research/propulsion/EL1a-R1/01-motor-esc.md), [battery/LVC review](../research/propulsion/EL1a-R1/02-battery.md).

A combustion-style cutoff below 1 RPM can prevent an electric rotor reaching rest. Localize the stop and preserve coupled body/rotor momentum; static breakaway depends on body angular acceleration, not only scalar rotor speed. An enabled source need not imply an idle rotor: validate source-specific parked, startup, depleted and restart states through the session. Use the immediately preceding parked charge as the startup baseline, so auxiliary draw alone cannot pass the check. [EL1d](../research/propulsion/EL1d/README.md), [EL2a-E1](../research/propulsion/EL2a-E1/README.md), [G2a](../research/propulsion/G2a-RK4/README.md).

With locked aircraft inertia, relative shaft acceleration couples to body acceleration along the shaft. Solve them together, use stage RPM for loads and gyro momentum, and add relative-spin reaction once alongside the existing external propeller torque. Independently check angular momentum and motor work; an algebraically plausible scalar shaft solution can omit the body-acceleration term. [G2a/G2b](../research/propulsion/G2a-RK4/README.md).

A throttle modeled as a fixed fraction of charge produced excessive idle power when an engine unloaded in flight. Model the restriction and engine breathing consistently, anchor idle and full throttle to applicable data, and test part-throttle unload in a glide or dive. Onboard fluid and accelerometer effects depend on stage-local specific force, not attitude alone: gravity accelerates both airframe and fuel. [NITRO-06](../research/glow-engines/NITRO-06/README.md), [NITRO-05](../plans/RC_NITRO_ENGINE_REALISM_PLAN.md#milestones-and-proof-register).

Thread the same field density and air-relative flow through trim, aero, propeller, wake and telemetry while retaining ground velocity. Moist aerodynamic density and oxygen-bearing engine charge are distinct; a failed environmental trim must not silently reuse a previous solution. Record source and model identities in replay. [M5-ATM-2/3](../research/atmosphere/M5-ATM-2/README.md), [wind integration](../research/wind-implementation/README.md).

### Keep mass, loading, and contact consistent

Solve balance against the stated loading condition: a fuel-loaded inventory fitted to an empty-tank CG target displaced the dry CG. For fuel sweeps, retain one hardware/ballast inventory and derive mass, CG, inertia and reported performance from each loading case. Equal mass and CG do not determine inertia: separated paired components must retain their separate centers, and full tensors require cross-inertia and principal-moment checks. [EX-06](../research/extra-300-realism/README.md), [AV-15](../research/avanti-realism/README.md), [P51-15](../research/p51-realism/P51-15/physics-audit.md).

Changing fuel must also reach contact mobility. A wet mass and CG cached for collision disagreed with the fuel-dependent flight model; sample mass, CG and inertia at the declared contact time, use the current contact arm, and retain that sample through response and rollback. An impulse proof alone does not qualify free-rotor coupling or post-impact remainder integration. [VAL-AUD-R05-B1](../research/physics-audit-2026-10-14/remediation/R05/R05-B-glow-contacts.md).

## Aircraft data, solvers, and measurement

### Validate before conversion and at the consumer

Casting can admit numeric strings and bypass provenance; nonfinite intermediate results can evade ordinary tolerance comparisons. Validate type, units, kind, source, finiteness and shape before conversion, then validate solved domains, brackets and residuals after arithmetic. A bounded bisection can converge to an endpoint without a root, a zero norm is meaningless if a callback returns the wrong number of residuals, and individually valid components can yield an unreachable inverse-calibration target. Preserve the live session when a reload is refused. [D1-R2](../research/aircraft-validation/D1-R2/README.md), [D1-R4](../research/aircraft-validation/D1-R4/README.md), [D1-R5](../research/aircraft-validation/D1-R5/README.md), [D4-R2](../research/trim-integrity/D4-R2/README.md), [E3b2-R1](../research/ground-contact/E3b2-R1/README.md), [G2-R1](../research/propulsion/G2-R1/README.md).

A replay check can pass with no executed ticks after clock arithmetic overflows, or mask a final-sample NaN when a later finite component replaces it in a `maxf` reduction. Bound loop arithmetic, validate every live sample before aggregation, align body and auxiliary checkpoints, and explicitly exercise the final boundary. [H9-R1](../research/simulation-state/H9-R1/README.md).

Check authored v2 relations before any conversion that drops their IDs: BAT-10's pack mount could never resolve against the lossy legacy representation. Compare schema and runtime acceptance in both directions, including optional absence, null, empty objects and whitespace; include structurally valid but physically inconsistent examples to expose runtime-only checks. Close configuration branches under an explicit version and distinguish reference-only values from active force consumers. [BAT-10](../research/battery/BAT-10/README.md#defects-found-and-fixed-during-integration), [DATA-4a](../research/aircraft-validation/DATA-4a/README.md), [AS-02](../research/aircraft-standardization/AS-02/README.md).

A new control topology may pass its loader while consumers still assume four surfaces, a rudder or a tractor propeller. Exercise session setup, trim, schema, rendering, traces and the flight-test battery; incompatible historical adapters must refuse the layout explicitly. A catalog-loop script error can hang instead of failing, so inspect the checked runner's errors as well as its summary. [X8-04](../research/skywalker-x8/X8-04/README.md), [P51-11](../research/p51-realism/P51-11a/README.md).

### Preserve provenance and verify the generated chain

Hash the exact source byte buffer actually parsed, separately from the derived model's checkpoint fingerprint; do not reread a mutable path at recording time. Native dictionary key types can affect model identity even when JSON values look identical. A faster native hexadecimal parser can accept signs or other inputs excluded by a canonical identity; retain the exact grammar and malformed-input checks, and do not treat unchanged file size or timestamp as proof of unchanged bytes. For a numerical failure, preserve lossless packed bytes alongside readable JSON: decimal parsing moved a sensitive GP-12 reproduction by multiple ULP. [DATA-3](../research/aircraft-validation/DATA-3/README.md), [EL2a](../research/propulsion/EL2a/README.md), [RCV-41](../research/rc-monster-truck/RCV-41/README.md), [GP-12](../research/ground-physics/GP-12/evidence/traction-acceleration/README.md).

Run freshness checks for each source → geometry → runtime data → report dependency, and ensure CI actually invokes them. A generator's `--check` can agree with its own output while rounded data violates a loader's tighter join; load the regenerated aircraft through the production consumer too. For byte-bound artifacts, generator platform drift, path ordering and checkout line endings need their own reproducibility checks; see [clean-build lessons](runtime-and-delivery.md#clean-builds-and-desktop-evidence). [DATA-1](../research/aircraft-validation/DATA-1/README.md), [EX-14h](../research/extra-300-realism/EX-14/README.md#ex-14h--post-stall-wing-polar).

A source table's repeated or backward coordinates cannot be fixed by dropping only its final row. Compare decimal coordinates before float conversion, reject conflicting repeats and conversion collisions, sort while retaining source-line identity, and distinguish nominal run labels or catalog dimensions from measured operating ranges and coefficient-reference dimensions. [G1a1](../research/propulsion/G1a1/README.md).

### Match the measured quantity and its uncertainty

Shared errors do not average away: scale gain may cancel in a CG ratio but not total mass, while a common datum error contributes once. Subtract loaded and empty swing-rig inertia about their shared pivot before shifting to the object CG, and combine signed sensitivities of reused measurements before squaring. This does not by itself resolve aerodynamic added inertia. [VAL-5a](../research/validation/VAL-5a/README.md), [VAL-6a](../research/validation/VAL-6a/README.md).

Adjacent video intervals and RPM response crossings reuse endpoints, so retain covariance and check whether noise changes the interpolation segment. A full-roll video measures a completed-cycle average; repeated silhouettes can alias at 180° and viewpoint can change phase. Resolve count, sign and actual quantity before comparing to instantaneous body rate or a damping pole. A static ideal-disc power bound is not a shaft-power measurement or propulsive efficiency. [VAL-8a](../research/validation/VAL-8a/README.md), [VAL-8b](../research/validation/VAL-8b/README.md), [VAL-7c](../research/validation/VAL-7c/README.md), [VAL-7a](../research/validation/VAL-7a/README.md).

When comparing candidate models or measured modes, retain source rows, transformations, input hashes and assumptions. An oracle that shares a force model checks coupling rather than the force's fidelity. Metamorphic symmetry, scaling and energy tests should run through actual session callbacks and ticks, with a valid baseline and targeted mutations; these properties are not universal similarity or physical-validation claims. [VAL-3](../research/validation/VAL-3/README.md), [VAL-4](../research/validation/VAL-4/README.md), [E3b3](../research/ground-contact/E3b3/README.md).

## Performance and ownership

### Measure the complete workload

A kernel timer can stop before accepted-tick observers. On one profiled Godot 4.8-beta1 headless flight, those observers accounted for roughly half the reported script time; the unprofiled estimate was lower. Measure the actual application and evolving trajectories across relevant aircraft/regimes, including observers, adapters and decoding, with hardware, engine, workload, spread and percentile definitions recorded. Cap headless frame rate when comparing process CPU: uncapped extra frames can absorb the saving. Historical shared-host timing is not target-hardware qualification. [VQ-01c](../research/visual-quality-implementation/VQ-01c/tick-observers-2026-10-27/README.md), [Gate P](../research/simulation-state/Gate-P/README.md), [E0b6p](../research/propwash/E0b6p/attribution/README.md).

Use exclusive buckets and verify expected timers and independent branch counts: a missing timer can be silently charged to residual time, while deleting an entire nested group can look like an inactive branch. Keep paired control runs and original batch lengths. A pure stage evaluation can reuse loads, continuous derivatives and spinning momentum within that stage without a persistent cache. Measure all paths, including reverse cutoff or stopped residual wake, before promoting it; fewer calls in the powered path did not establish whole-flight savings. [G2a-R1](../research/propulsion/G2a-R1/README.md), [prepared attribution](../research/propwash/E0b6p/prepared-cost/README.md), [nested attribution](../research/propwash/E0b6p/dynamics-cost/README.md), [stage-sharing experiment](../research/propwash/E0b6p/stage-sharing/README.md).

An accepted trim can still waste its entire iteration cap if the requested residual is below its numerical floor. Record iterations across the fleet and speed range; stop an already accepted solve when its residual stagnates, and compare full results before adopting the change. When an exact bisection reaches a rounded midpoint equal to an endpoint, further iterations cannot improve that bracket; prove byte parity before changing termination, and retain residual/bracketing checks. [X8-12](../research/skywalker-x8/X8-12/README.md), [DATA-2b](../research/aircraft-validation/DATA-2b/README.md).

Replacing a sampled-grid lift maximum with a continuous optimizer changes the quantity being solved and can change the stall angle even when both searches are accurate. For a behavior-preserving optimization, prune the original grid using a justified bound and compare against an exhaustive grid oracle; treat a change of objective as an intentional physics change. [DATA-2a](../research/aircraft-validation/DATA-2a/README.md).

### A prepared model needs an explicit ownership boundary

A native model copy remains isolated from later source edits, but isolation does not imply freshness; dictionary identity misses nested changes. Require rebuild after edits, invalidate generations even when preparation fails, and test rejection through the adapter so a stateless fallback cannot mask a stale handle. [E0b6p prepared model](../research/propwash/E0b6p/prepared-model/README.md).

Include mutation detection, invalidation and returned-value ownership in a cache's cost: protecting a six-entry inertia inverse cost more than recomputing it in EL2a-P3, and returning a packed array can expose cached contents to caller edits. A selected-field snapshot can also cost more than a deep copy once detachment is included. If session data can change between ticks, constrain any reuse to a boundary with explicit invalidation and make off-tick queries read current data. Measure entire paths rather than assuming fewer helper calls or a native port wins after bindings and decoding. [EL2a-P3](../../research/propulsion/el2a-p3/inertia-prototype/README.md), [RCV-42](../research/rc-monster-truck/RCV-42/README.md), [NK-2a](../research/native-kernel/NK-2a/README.md), [H13](../research/simulation-state/H13/README.md).
