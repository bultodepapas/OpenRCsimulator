# Runtime, input and delivery lessons

**Status:** curated reference. Evidence comes from the 2026-10-05–13 work on Godot 4.7.2; platform observations are scoped to those experiments. Start with [LEARNINGS](../LEARNINGS.md) for shared engineering lessons.

## Godot execution and test isolation

- **Verify display reversion against the native window, not just a Settings signal.** Manually sizing a borderless window to the monitor promoted it to fullscreen on Windows while Godot’s Window state stayed stale; the timer said it reverted but the physical window stayed at 4K. Use the Window mode state machine and verify size/mode after the real deadline. Headless signal tests cannot establish display recovery. [UI-22–26-R1](../research/menu-investigations/UI-22-26-R1/README.md#native-display-recovery).

- **A cast copies a packed array.** `(list[i] as PackedVector4Array).append(v)` appends to a temporary copy, so the original stays empty with no error; `list[i].append(v)` and a function parameter do mutate it (Godot 4.7.2). Three shader colour tables stayed zero and every bird rendered black for a whole slice while position tests passed. Append to the variable itself and test the values a consumer receives, not only that it accepts them ([SC-BIRD-08](../research/scenery-implementation/SC-BIRD-08/README.md)).

- **The headless root viewport is 64 × 64 pixels.** Anything that reads the viewport size changes behaviour under `--headless --script`: the pilot camera's auto zoom narrowed to its 6° minimum, and a camera census reported the flight-line pilots in frame 0 % of the time instead of 19 %. Put the camera in a `SubViewport` of the production size before measuring ([SC-HUM-00](../research/scenery-implementation/SC-HUM-00/README.md#camera-census-2026-10-24)).

- **Exit status alone misses engine failures.** A runtime format error printed `ERROR:` while a test exited zero; a scene parse failure left headless Godot running without anyone reaching `quit()`. Parse scripts before integration, inspect engine/script/shader error logs, and bound process lifetime. Negative loader tests need the same log checks: an `ok=false` result can hide a broken rejection diagnostic. Avoid built-in class names for constants, infer no type from an untyped Dictionary, and use `String.num_scientific()` instead of unsupported `%e`/`%g` (or `%s` for ordinary value text). [Runner](../../app/test.sh), [C7-R1](../research/trace-integrity/C7-R1/README.md), [DATA-4b](../research/aircraft-validation/DATA-4b/README.md).

- **Wait for completed work, not elapsed wall time.** A short timer expired before a radio test's first physics update. `physics_frame` fires before the tick, and UI presentation follows separately; wait for the required completed ticks and a rendered/process frame before asserting. Inject real events through `Input.parse_input_event` to test routing. [Input tests](../../app/tests/test_e2e_input.gd), [radio tests](../../app/tests/test_e2e_radio.gd).

- **Concurrent Godot runs share preferences unless isolated.** Two suites raced through the same `user://` settings because the directory follows the project name. Give concurrent suites separate `XDG_DATA_HOME` directories and UI tests their own preference paths. Freeze source for long runs: later stages can load scripts edited after the run began. [H13/H14](../research/simulation-state/H13/README.md), [language tests](../../app/tests/test_ui_language.gd).

- **A localhost line protocol is reachable from any web page.** A browser can `fetch` a POST to `127.0.0.1`; a server that skips bad lines then runs the body line as a command. Close the connection on the first line that is not your protocol, and require a per-session secret. Headless `--script` runs have a 64×64 root window (mouse events outside it are ignored), and under Xvfb without a window manager a window resize does not resize the viewport; set the size at launch (`--resolution`). [PT1h-R7](../../tools/debug/README.md#how-it-works-and-limits).

- **The editor's tools work without the editor.** `-d --profiling --ignore-error-breaks` makes any debug build print per-function GDScript self/total times and call counts about once a second to stdout (a `Logger` sees them too); and `--editor --headless --lsp-port N` serves the compiler's own diagnostics for any opened script. Both avoid reimplementing the remote-debugger protocol or trusting a third-party parser that lags the language (gdlint 4.5.0 could not parse 9 of our scripts). Run the editor on a copy of the project. [PT1h-R8](../../tools/debug/README.md#hunting-stutter-leaks-and-bugs-pt1h-r8).

- **A smaller probe must retain the contract it tests.** A radio-menu probe without the project's InputMap passed because the unwanted bindings were absent. A minimal physics project at Godot's default 60 Hz rejected aircraft gear before reaching the intended mutation. Preserve relevant project settings, including the app's 240 Hz rate, and establish a valid positive control. [Menu investigations](../research/menu-investigations/README.md), [E0b1](../research/propwash/E0b1/README.md).

- **Test late recording metadata through the serialized artifact.** Weather and coupled-shaft traces freeze a separate physical header at the first sample; changing only the public metadata dictionary left later visual events absent from CSV. Keep physical headers frozen, explicitly carry the permitted visual event fields into serialization, and exercise every header variant after recording has already started. [TOD-08b](../research/time-of-day-investigations/TOD-08b/README.md).

## Radio input and menus

- **Default UI bindings include joystick axes.** Loading no explicit radio navigation does not isolate RC sticks from menus. Load the real project InputMap, demonstrate that a stick can move focus before isolation, then verify that removing joypad UI bindings preserves flight-axis reads. [UI-00/01 input tests](../../app/tests/test_ui_input.gd).

- **Startup zero is not a reported throttle position.** Raw zero maps to half throttle before any motion event, so require a fresh low-throttle event to arm. Disconnect must pause flight, idle the engine and center commands; reconnecting with retained high throttle must remain safe. Keep collecting axes after arming because calibration and diagnostics still need late/raw updates. [Radio tests](../../app/tests/test_e2e_radio.gd), [F3b1](../research/radio-input/F3b1/README.md).

- **Pause spans simulation, presentation and input.** Freezing ticks originally left the propeller turning and the engine audible. Disabling the entire session would also lose radio events needed for arming. Coordinate pause explicitly, including audio playback readiness, while retaining the required input path. [UI-02/03 tests](../../app/tests/test_ui_pause.gd), [menu investigations](../research/menu-investigations/README.md).

- **Audio queue duration does not describe the driver's consumption burst.** Godot's Dummy driver consumes 4096 output frames at once regardless of its latency setting, so a 50 ms target underruns there while a native device passes. Measure the driver period, reserve its burst, and qualify native response separately. Keep playback identity in the adapter; ensure a playback with a raw source pointer retains that source through asynchronous mixer retirement. Weak-reference tests must establish both survival and release without a cycle. [G3b measurements and lifecycle controls](../research/audio/G3b/README.md).

- **Audio import format is part of the playback contract.** Godot's default WAV compression can turn PCM bytes into QOA data. A loop endpoint is a sample-frame position, so compressed byte length cannot define it. Pin the intended import format, derive endpoints from duration and rate, and verify the exported resource from an empty project. Source-file tests alone missed this mismatch. [AUD-03](../research/audio/AUD-03/README.md), [pack check](../../tools/audio/check_pack.gd).

- **A launch choice is a reset recipe, not just an initial pose.** A one-shot runway reset left R, crash recovery and trace headers describing an airborne flight. Keep the choice in the session, reconstruct equilibrium and wheel anchors after each restart or valid reload, and retain launch identity separately from the recording-start snapshot. Preflight a reload before emitting reset signals, or a rejected candidate can close a valid recording. [UI-06a evidence](../research/menu-investigations/UI-06a/README.md). A physics-only checkpoint cannot establish the source flight’s launch history: invalidate inherited launch metadata on restoration, while retaining the exact recording boundary. [UI-06a-R1](../research/menu-investigations/UI-06a-R1/README.md).

- **GUI focus does not guarantee event consumption.** Enter/Space on a focused button reached flight `_unhandled_input`, and opening a pause menu during a focus notification hit a locked scene tree. Consume leftover menu keys and defer tree changes. Test focus loss through `SceneTree.notification()`: propagating only from the root does not reproduce key release. [UI-02/03 tests](../../app/tests/test_ui_pause.gd). Use recursive Control focus/mouse policies to suspend lower screens: they cover descendants rebuilt while a modal is open without overwriting each widget's own policy. The Input singleton remains live, so keep the session hold and held-key mask as separate responsibilities. [UI-21](../research/menu-investigations/UI-21/README.md).

- **Validate saved calibration independently of the wizard.** Old or edited profiles bypass wizard checks. Require unique integer axes, finite endpoints, ordered centers and typed device identity before changing live state; rejected writes must preserve existing profiles. A throttle center may equal an endpoint because its normalization does not use the center. [D6b-R1](../research/radio-input/D6b-R1/README.md).

- **Input latency claims need an observation point.** Godot callback spacing measures dispatch, not USB reports or RF latency; queued axes arrive in batches without hardware timestamps. Keep unseen/single-sample intervals unknown and reconnects separate. A visual marker must sample after the flight polls the same buffer, and its no-effect claim needs a simultaneous control flight. Hardware latency still requires a physical trial. [F1](../research/radio-input/F1/README.md), [F6a](../research/radio-input/F6a/README.md).

- **A first-visible video frame is an interval observation.** Subtracting two first-frame indices retains up to one acquisition frame of timing ambiguity in either direction even with exact picks. Carry annotation/cadence bounds through median and nearest-rank p95 with ranks allowed to change; these are not confidence intervals and do not shrink with trial count. A nominal median below a timing budget can still have bounds crossing it. [F6b](../research/radio-input/F6b/README.md).

- **A fixed-viewport UI only looks finished at its design resolution.** Home was always captured at 1280×720, which hid that `project.godot` sets no stretch mode: at 1920×1080 the same 440 px column and type sizes float in empty space, and the Spanish strings move the rows because spacers follow text height. Capture every new screen at a second resolution and in the second language before calling it done. [UI-20 audit](../research/menu-investigations/UI-20/README.md). Under Xvfb there is no window manager, so `Window.MODE_FULLSCREEN` leaves the window at its old size: a 1920×1080 case came out 1280×720. Instead, use an undecorated window at the Xvfb screen size, and assert the captured image size. For menu audits, set `scaling_3d_scale = 0.5`. With the full-scale backdrop, llvmpipe took about two minutes per 1080p capture; at half scale it took under 30 s, while the UI still renders at native resolution. [UI-30](../research/menu-investigations/UI-30/README.md).

- **An embedded dialog also takes focus from the main window.** In Godot 4.7.2, an embedded exclusive dialog grabbing focus sends `NOTIFICATION_WM_WINDOW_FOCUS_OUT` to the main window's nodes, exactly as a real OS focus loss does. A pause-on-window-focus-out handler therefore opened Pause under the quit-guard dialog. Confirm with a deferred `DisplayServer.window_is_focused()`, and keep the check injectable, because headless runs always report focus. [UI-31](../research/menu-investigations/UI-31/README.md).

## Preferences and localization

- **A Button's minimum width follows its text; a translation or a dynamic summary widens the column silently.** Home's Weather button grew to 478 px (516 px in Spanish) with the default conditions and the English Language/Help/Quit row needed 375 px of 360, so the panel widened under its fade; long aircraft notes pushed the keyboard legend off a 720p window. Wrap (`autowrap_mode`) or clip (`clip_text` + ellipsis) button texts, give a column that can overflow a `ScrollContainer`, and measure every aircraft × language × window size in a headless layout test (Home inside a window-sized frame Control, six frames to settle). Enable `follow_focus` only after those frames: following the first focus while wrapped labels settle scrolled the title away. [UI-06d-R1](../research/menu-investigations/UI-06d-R1/README.md).

- **Translation occurs at draw time.** `Label.text` retains the source string; inspect `atr(text)` for the displayed translation. Rebuild dynamic phrases on translation changes and test actual layout in both languages. Set the default locale explicitly: the OS locale otherwise changes a fresh launch. [UI-01d tests](../../app/tests/test_ui_language.gd), [UI-05 tests](../../app/tests/test_ui_aircraft.gd).

- **Widgets can change values without emitting signals.** `SpinBox.set_value_no_signal()` still quantizes to its step, and pending editor text may differ from `value` until applied. Keep a precise draft model and commit editors explicitly. Reading an absent ConfigFile key needs a default sentinel to avoid an engine error. [Wind UI investigations](../research/wind-investigations/README.md), [language tests](../../app/tests/test_ui_language.gd).

- **Atomic replacement does not prevent lost updates.** A stale aircraft-preference writer restored an old language after another writer changed it. Reconcile writers through one settings owner and preserve unknown future schemas; test alternating writes, not only individual save/load pairs. [DT-00-R1](../research/desktop-delivery-investigations/DT-00-R1/README.md).

- **Test hooks can have engine lifetime side effects.** A lambda stored in a static script variable caused repeatable exit aborts in the UI-04 probe. Passing the mapping as a parameter avoided that lifetime. Physical-key-label APIs also emit errors under the headless display server; exercise the supported fallback. [UI-04 record](../MENU-PLAN.md), [controls tests](../../app/tests/test_controls_reference.gd).

## Clean builds and desktop evidence

- **A Git archive can apply platform line endings.** On Windows, `git archive` with `core.autocrlf=true` produced CRLF shell scripts even though the tree blobs used LF; the fresh Linux verification then failed before testing runtime behavior. For a Linux validation archive, use `git -c core.autocrlf=false archive`, inspect an executable shell-script member, and preserve `-text` attributes for hash-bound source assets. Do not normalize downloaded assets to repair a shell-script transport problem. [Tree completion verification, L6c](../research/visual-quality-implementation/L6c/tree-completion/README.md).

- **Hashed data needs stable generation and checkout bytes.** Git newline conversion changed glow profile identities in a clean checkout; Python 3.12's revised float summation changed generated ballast digits. Pin text formats and the intended arithmetic order, then compare actual bytes under both checkout modes and supported Python versions. Equivalent parsed values do not preserve checkpoint or experiment hashes. [NITRO-02](../research/glow-engines/NITRO-02/README.md), [generator byte tests](../../research/glow-engines/test_installation_line_endings.py).

- **An update check reads the release list; it cannot ask for "latest".** GitHub's `/releases/latest` returns the newest non-prerelease release, so a project that only publishes prereleases gets 404: list the releases and order them locally, skipping drafts. A conditional request with the cached ETag answers 304 without a body but still counts against the anonymous 60/h limit, so throttle by time (once a day) rather than relying on 304. Godot 4.7's `HTTPRequest` reaches `api.github.com` from the engine's bundled CA set and decodes gzip; it must be inside the tree before `request()` (calling from `_initialize()` returns `ERR_UNCONFIGURED`), and `JSON.parse_string` prints an engine `ERROR:` on bad input that the test runner treats as a failure, so parse with a `JSON` instance. Never set `use_threads` on a desktop `HTTPRequest`: the worker reads in blocking mode, so a peer that accepts and then stays silent makes `timeout` and quitting the app wait forever on the thread join; unthreaded, the request works a little per frame and the timeout really fires. Do not rely on `HTTPRequest.timeout` for a request started at launch: it is wall clock, and a cold start's first frames (shader compilation, scenery) can spend it before the request runs; count processed frames with a per-frame cap instead. A test for a timeout needs a server that accepts and never answers, not a closed port. [UI-16](../research/menu-investigations/UI-16/README.md).

- **Local CI is not a fresh checkout.** `act` copied ignored/untracked folders, hiding a missing capture directory that failed on GitHub. System Pillow also masked a missing CI dependency. Create output directories explicitly, use the pinned isolated visual environment, and verify generated/imported assets from a fresh checkout. [VQ-01a](../research/visual-quality-implementation/VQ-01a/README.md), [capture runner](../../app/capture.sh). A disposable validation snapshot also needs a valid Git HEAD for build-identity tests; freeze generators and their inputs together with generated app data, or a mixed snapshot can falsely report stale artifacts. [CR-22a](../research/crash-damage-investigations/CR-22a/README.md).

- **Generated media can silently become imported assets.** Capture PNGs accumulated a second copy under `.godot/`. Create `.gdignore` in output directories before import, keep manifests and compact comparisons, and bound full-frame/log retention. A local clone can also retain Git alternates despite `--no-hardlinks`; use `--dissociate` if its parent snapshot will be removed. [L4b](../research/visual-quality-implementation/L4b/README.md), [SC-25](../research/scenery-implementation/SC-25/README.md).

- **Build cheap verification copies as a mirror root, and unlink before mutating.**
  - A hard-linked `app/` copy (`cp -al`, with a real copy of `.godot`) costs about 170 MB. But the app reads authoring sources through `res://..`, so the copy must sit in a mirror root whose other top-level entries link to the repository. Without them, model contracts fail for reasons unrelated to the change.
  - Never link `.git` into a copy: a test running git there would act on the real index.
  - Hard links share inodes. An in-place write (Python `open(path, "w")`) changes both trees, so remove the link before writing a mutation.
  - The copy also lets you verify against a fixed upstream file when the shared tree's `HEAD` does not compile (here `field.gd` called a `Windsock` API that only `origin/main` had). The owner merges; you don't pull into a tree that others are using. ([FW-MOON-06](../research/field-world/FW-MOON-06/README.md#4-fw-moon-06d-the-slow-sky-between-the-steps))

- **Run the exported program to test resource packaging.** The early claim that JSON required an include filter was contradicted by a real 4.7.2 `all_resources` export. Verify the final binary with its data, and use a deliberate exclusion to prove the missing-data check. First-import and standalone-builder tests must also recreate globals and resources normally supplied by the app shell. Mounting a pack in an empty project does not apply its project settings: a physics probe must set the app tick rate in both Engine and ProjectSettings before loading aircraft data. [UI-06c-R1](../research/menu-investigations/UI-06c-R1/README.md). [Export runner](../../app/export.sh), [L15b](../research/visual-quality-implementation/L15b/README.md).

- **Editor test flags are not release-template capabilities.** The pinned Linux release binary omits `--script`; passing an external harness instead launched the normal app indefinitely. Check the target binary's `--help` and drive its real window when proving a packaged menu route. Native keyboard input also exposed a 4.7.2 release-only embedded-popup disconnect failure absent from the editor executable; reduce such failures to a minimal exported scene before choosing a scoped workaround. [TOD-08b](../research/time-of-day-investigations/TOD-08b/popup-repro/README.md). Wait for the rendered Home screen and derive elapsed simulation time from traces: under llvmpipe, a wall-clock key hold can advance far fewer ticks than expected. [UI-06c native-input smoke](../research/menu-investigations/UI-06c/README.md).

- **Artifact inspection and native acceptance answer different questions.** A universal Mach-O and an ad-hoc signature flag prove package structure, not native launch, signing trust, fullscreen, DPI, radio or sustained performance. Record actual renderer, backing pixels, OS floor and executable identity on each target. Process-loop percentiles are not display-presentation latency. [DT-00](../research/desktop-delivery-investigations/DT-00/README.md), [DT-00-R2](../research/desktop-delivery-investigations/DT-00-R2/README.md).

- **Build names do not identify all release inputs.** `git describe --dirty` ignores new untracked files, and different prereleases may share a numeric Windows version. Inventory build inputs and verify the tested artifact's bytes and actual replacement during upgrades; promote those bytes without rebuilding. [DT-00-R1](../research/desktop-delivery-investigations/DT-00-R1/README.md).
