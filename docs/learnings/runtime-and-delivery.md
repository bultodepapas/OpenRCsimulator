# Runtime, input and delivery lessons

Observed failures that affect application behavior or its verification. The linked reports retain reproduction and measurement details; [LEARNINGS](../LEARNINGS.md) covers shared lessons and [TOOLS](../TOOLS.md) owns current commands. Engine-specific observations are scoped to the named version and backend; verify them against the current pin before applying an old workaround.

## Godot execution and test isolation

- **Exit status and a printed PASS do not prove a completed check.** Godot script errors have exited zero, aborted preflight after printing PASS, or prevented a `SceneTree` script from reaching `quit()`. Bound execution, inspect engine/script/shader diagnostics and require the intended completion and failure reason, including negative tests. [F4U-02](../research/f4u-corsair/F4U-02/README.md), [CR-09f](../research/crash-damage-investigations/CR-09e/README.md), [checked runner](../../tools/godot/README.md).

- **A small probe must retain the contract it tests.** An isolated radio probe passed without the project's InputMap, a physics probe at Godot's default tick rate rejected gear before reaching its mutation, and a `--headless --script` probe's 64 × 64 root viewport distorted camera measurements. Reproduce the relevant settings, viewport and lifecycle and first show a valid positive control. A node added during `SceneTree._initialize()` is not yet inside the tree, so reading its global transform can return identity with an engine error. [E0b1](../research/propwash/E0b1/README.md), [SC-HUM-00](../research/scenery-implementation/SC-HUM-00/README.md#camera-census-2026-10-24), [F4U-05](../research/f4u-corsair/F4U-05/README.md).

- **Wait for completed work, not a timer.** A radio assertion ran before its first physics update; `physics_frame` itself precedes the tick and presentation follows separately. Wait for completed ticks and a process/render frame as needed, and inject input events when testing real routing. [Radio tests](../../app/tests/test_e2e_radio.gd), [input tests](../../app/tests/test_e2e_input.gd).

- **Isolate concurrent Godot preferences.** Suites using the same project name raced through `user://` and restored each other's settings. Give runs separate settings directories and UI tests their own preference paths. [H13/H14](../research/simulation-state/H13/README.md), [language tests](../../app/tests/test_ui_language.gd).

- **Check what a copy actually isolates.** In Godot 4.7.2, casting a packed array before appending modified a temporary copy; tests that checked only acceptance missed empty bird color tables. In another 4.7.2 case, a GDScript Dictionary cycle remained allocated after its nodes were freed. Check consumer values and both resource survival and release; use one-way records or keys where cycles are unnecessary. [SC-BIRD-08](../research/scenery-implementation/SC-BIRD-08/README.md), [F4U-16](../research/f4u-corsair/F4U-16/README.md).

- **Check input processing after tree entry.** In the HUD-13-R9 Godot 4.7.2 investigation, Godot automatically enabled `_input` on inserted widgets after their constructors had disabled it, so every idle instrument received global events. Set the initial processing policy in `_ready` and test the actual idle, drag and release lifecycle; recheck on other engine versions. [HUD-13-R9](../research/flight-overlays/HUD-01-10/README.md#widget-runtime-audit-2026-10-24-hud-13-r9).

- **A frozen subclass fixture can pin runtime signatures.** In the Godot version used by EX-14c, adding an optional argument broke an overriding fixture at parse time. Search dependent fixtures before changing a public signature and test their actual import and override behavior. [EX-14c](../research/extra-300-realism/EX-14/README.md).

- **Reproduce loader lifetime separately from app ownership.** Godot 4.7.2's threaded-load fixture retained engine LoadTokens after requests were collected; its Windows thread-priority hint also did not prevent menu stutter. A loader can require main-thread deferred work, so joining a still-live worker during cancellation may deadlock. Recheck the pinned engine and platform, keep the main loop available, and measure real cancellation and frame latency before adopting a workaround. [UI-34c-R5](../research/menu-investigations/UI-34c-R5/README.md), [Windows finding](../research/menu-investigations/UI-34c-R5/menu-preparation-2026-10-25/README.md).

- **A localhost debug protocol is reachable from a browser page.** A server that skipped malformed lines could execute a command in an HTTP request body. Reject the first non-protocol line and authenticate each session; use the existing debug bridge and its documented limits. [PT1h-R7](../../tools/debug/README.md#how-it-works-and-limits).

## Radio input and menus

- **An unreported throttle is not an idle command.** Startup zero mapped to half throttle before an axis event. Require a fresh low-throttle event and verify the current polled position before arming; disconnect pauses, idles and centers flight, and retained high throttle must not rearm on reconnect. Keep connection-wide diagnostics while resetting arming evidence after a calibration/profile change. [F3b1](../research/radio-input/F3b1/README.md), [D6b-R2](../research/radio-input/D6b-R2/README.md), [radio tests](../../app/tests/test_e2e_radio.gd).

- **Calibration files can bypass the wizard.** Validate axis uniqueness, finite ordered endpoints and device identity before changing live state, and preserve the old profile after a rejected write. Throttle normalization does not use its center, so a center at an endpoint can be valid. [D6b-R1](../research/radio-input/D6b-R1/README.md).

- **Menu focus and flight input are separate paths.** Default UI bindings included joystick axes, and Enter/Space on a focused button reached flight input; opening Pause directly during a focus notification hit a locked tree. Demonstrate the unwanted route before isolating it, preserve flight-axis reads, consume remaining menu keys, defer tree changes, and coordinate pause across ticks, visuals, audio and input. The live Input singleton and held-key masking remain separate from Control focus policies. [UI-00/01](../../app/tests/test_ui_input.gd), [UI-02/03](../../app/tests/test_ui_pause.gd), [UI-21](../research/menu-investigations/UI-21/README.md).

- **A focus notification does not always mean the OS window lost focus.** Godot 4.7.2 sent the same focus-out notification when an embedded exclusive dialog took focus, opening Pause beneath the quit guard. Distinguish actual window focus after deferred processing and test the native behavior; headless focus reporting is not a substitute. [UI-31](../research/menu-investigations/UI-31/README.md).

- **Input latency claims need the measured boundary and uncertainty.** Godot callback spacing measures dispatch rather than USB or RF latency, and queued axes lack hardware timestamps. A first-visible video frame is an interval, not an exact event time; carry frame and annotation bounds through reported statistics. Sample visual markers after flight consumes the same buffer, and use a simultaneous control to check that observation does not change the flight. [F1](../research/radio-input/F1/README.md), [F6a](../research/radio-input/F6a/README.md), [F6b](../research/radio-input/F6b/README.md).

- **A launch choice must survive reset and recording boundaries.** A one-shot runway reset left later restarts and trace headers describing an airborne launch. Retain the launch recipe in the session, rebuild equilibrium on valid reset/reload, and distinguish launch identity from the recording-start snapshot. A physics-only checkpoint cannot establish earlier launch history; reject invalid reloads before disrupting an active recording. [UI-06a](../research/menu-investigations/UI-06a/README.md), [UI-06a-R1](../research/menu-investigations/UI-06a-R1/README.md).

- **Visual history needs its own serialized lifecycle.** A clock's restart selection differs from its running instant, and rate edits must preserve fractional phase. A frozen physical trace header also dropped visual events added after recording began. Validate transitions against their predecessors and the simulation timestep, and verify late edits in the serialized artifact across header variants. [TOD-09c1](../research/time-of-day-investigations/TOD-09c1/README.md), [TOD-08b](../research/time-of-day-investigations/TOD-08b/README.md).

## Preferences and localization

- **Test layouts at the primary resolution, scale and languages.** A fixed 720p capture concealed a sparse 1080p Home screen; translated and dynamic button text also widened columns or pushed controls away. Check 1920×1080 first, then larger resolutions and the 720p fallback, with representative long content and actual focus reveal. Assert capture dimensions: Xvfb fullscreen can retain an older window size without a window manager. [UI-20](../research/menu-investigations/UI-20/README.md), [UI-30](../research/menu-investigations/UI-30/README.md), [resolution policy](../../AGENTS.md#display-resolution-priorities).

- **Measure displayed text and first appearance.** `Label.text` can retain the source while translation occurs at draw time; dynamic phrases need rebuilding on locale changes. A tooltip placed before its wrapped height was known appeared offscreen on first hover. Inspect translated output and settled layout, and measure both tooltip dimensions before placement. [UI-01d tests](../../app/tests/test_ui_language.gd), [HUD-13-R9](../research/flight-overlays/HUD-01-10/README.md#widget-runtime-audit-2026-10-24-hud-13-r9).

- **Font object identity does not prove atlas isolation.** On Godot 4.8-beta1, a shallow `FontFile.duplicate()` retained separate glyph placement state but shared atlas images; interleaved new glyphs corrupted visible labels while text and metrics remained correct. Deep-copy independently extended fonts and compare rendered glyph pixels against a fresh same-data font. [UI-01k](../research/release-readiness/PT1-v0.1.9/README.md#follow-up-stability-and-usability-pass-2026-10-28).

- **Theme lookup and container sizing can collapse text-fit bounds.** Godot 4.8-beta1 prioritized a control's theme variation even when a base type was requested, and an unconstrained container forced titles to their minimum. Pass explicit scaled body/title tokens, reserve preferred line height, and check intermediate fits and ellipsis at normal and enlarged scale. [GDU-11f](../research/engine-upgrade/GDU-11/implementation.md#gdu-11f--bounded-title-fitting).

- **Widgets and writers can change data without the expected signal.** A `SpinBox` silently quantized a value and pending editor text differed from the model; a stale settings writer atomically replaced a newer language choice. Keep an explicit draft, commit editors, reconcile through one settings owner and test alternating writers as well as individual saves. [Wind UI](../research/wind-investigations/README.md), [DT-00-R1](../research/desktop-delivery-investigations/DT-00-R1/README.md).

- **Verify display rollback at the native window.** A borderless window became fullscreen on Windows while Godot's reported state remained stale, so a successful settings signal did not mean the physical window had reverted. Test actual mode and dimensions after the deadline on the target OS. [UI-22–26-R1](../research/menu-investigations/UI-22-26-R1/README.md#native-display-recovery).

## Audio playback and measurement

- **Check the mixed output, not only the source file.** On Godot 4.7.2 a seamless PCM loop clicked when interpolation read beyond its endpoint, and mixer filter response differed from property names. Test actual loop wraps, filter transfer and changes over time on the intended backend. Historical guard-tail or filter settings must be rechecked on a newer engine. [AUD-07](../../research/audio/review-2026-10-13/README.md), [AUD-11b](../../research/audio/air-absorption-2026-10-17/README.md).

- **Limiter recovery alone does not establish clean limiting.** In Godot 4.7.2 the hard limiter stayed attenuated after an overload, but the alternative `AudioEffectLimiter` recovered because it was a stateless clipper that distorted near its knee. Measure both burst recovery and a level/distortion transfer sweep before choosing a mixer effect; do not treat either historical behavior as established for 4.8. [AUD-12](../../research/audio/master-limiter-2026-10-18/README.md).

- **A Dummy driver is not always silent and its burst is not its queue target.** In Godot 4.7.2 the G3b Dummy driver consumed frames in large bursts, so a short queue underran there even when a native device passed; Movie Maker also reported Dummy while mixing to a capture. Separate automated silent runs from capture and native listening, measure the driver period, and verify source/playback lifetimes through asynchronous retirement without reference cycles. [G3b](../research/audio/G3b/README.md), [AUD-12](../../research/audio/master-limiter-2026-10-18/README.md).

- **Audio import format is part of the playback contract.** Default WAV compression produced QOA data, so byte length could not define a sample-frame loop endpoint. Pin the intended import format, derive endpoints from duration and rate, and verify the exported resource rather than only its source. [AUD-03](../research/audio/AUD-03/README.md).

## Clean builds and desktop evidence

- **Generated identities depend on exact input bytes.** Python 3.12 changed floating-point `sum()` results and platform path ordering changed generated bytes; byte-bound descriptors also depended on checkout line endings. Check generator freshness before editing, preserve existing artifacts when unrelated drift is present, make arithmetic/order and text bytes deterministic, and compare fresh checkouts before updating outputs. [CR-01d](../research/crash-damage-investigations/CR-01d/README.md#timber-platform-drift), [PT1-rc9](../research/release-readiness/PT1-rc9/README.md#release-repairs), [NITRO-02](../research/glow-engines/NITRO-02/README.md).

- **Validate the complete generated dependency chain.** Model script changes also staled manifests, Workshop descriptors, customization data and parked-aircraft bakes; a builder could return an empty result when its manifest hash lagged. Follow the current generator order and check actual build results and engine logs, not just one generator's `--check`. [F4U-02](../research/f4u-corsair/F4U-02/README.md), [P51-V13](../research/p51-realism/P51-V13/README.md).

- **A local CI run is not a fresh checkout.** Ignored folders and system-installed packages masked a missing capture directory and dependency. Verify from a fresh checkout with the isolated pinned environment; output media must be excluded from Godot import. On Windows, a Git archive can convert shell scripts to CRLF even when repository blobs use LF: inspect the actual archive bytes before Linux validation. [VQ-01a](../research/visual-quality-implementation/VQ-01a/README.md), [L4b](../research/visual-quality-implementation/L4b/README.md), [L6c](../research/visual-quality-implementation/L6c/tree-completion/README.md).

- **A disposable copy must also be safe to mutate.** The app reads sources outside `app/`, so a reduced copy without its expected root dependencies produced false failures. Hard-linked files share inodes, and linking `.git` lets a test touch the real index; use a self-contained snapshot or unlink before any mutation. A build-identity test also needs a valid Git HEAD in its isolated copy. [FW-MOON-06](../research/field-world/FW-MOON-06/README.md#4-fw-moon-06d-the-slow-sky-between-the-steps), [CR-22a](../research/crash-damage-investigations/CR-22a/README.md).

- **Run the exported product with its real resources and input.** A Godot 4.7.2 export disproved the assumption that JSON always needed an include filter; a release template also lacked the editor's `--script` capability. Prove missing-resource rejection with a deliberate exclusion, inspect target-binary capabilities, and exercise the packaged window. A mounted pack does not automatically apply its source project's settings. [UI-06c-R1](../research/menu-investigations/UI-06c-R1/README.md), [TOD-08b](../research/time-of-day-investigations/TOD-08b/popup-repro/README.md).

- **Package structure and build names do not establish native acceptance or identity.** Mach-O architecture and an ad-hoc signature do not prove target launch, signing trust, DPI, radio or sustained performance. `git describe --dirty` can omit untracked inputs. Record source/data/engine and artifact bytes, test the actual replacement on each target, and promote those same bytes without rebuilding. [DT-00](../research/desktop-delivery-investigations/DT-00/README.md), [DT-00-R1](../research/desktop-delivery-investigations/DT-00-R1/README.md), [DT-00-R2](../research/desktop-delivery-investigations/DT-00-R2/README.md).

- **Test network cancellation with an accepted but silent connection.** In Godot 4.7, a threaded HTTP request could block during shutdown despite its timeout, and a cold launch could exhaust a wall-clock deadline before the request progressed. Test the pinned version with a peer that accepts and never replies, plus actual startup and shutdown. A prerelease-only project also cannot infer its newest release from GitHub's non-prerelease `latest` endpoint. [UI-16](../research/menu-investigations/UI-16/README.md).
