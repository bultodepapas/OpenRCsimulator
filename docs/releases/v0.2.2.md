# OpenRC Simulator v0.2.2

Early-alpha software release. Aircraft and other vehicle models remain experimental. Software checks, replay comparisons and game estimates do not establish physical accuracy, target-hardware performance or pilot acceptance.

## Changes since v0.2.0

### Aircraft and flight

- Added the experimental electric Ugly Stik 6S alongside the basic Stik in the player aircraft list, using estimated battery behavior. Normal flight uses the finite battery pack; Workshop labels its ideal-voltage configuration separately. Saved hidden finite-glow Stik selections resolve to basic with a notice, preserving the saved selection until an explicit stock choice or successful Fly save. Existing Workshop source identities retain their compatibility checks. [Stik integration and limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/research/propulsion/ugly-stik-implementation-2026-11-08.md)
- Corrected finite-fuel derivatives, battery ground-contact composition and helicopter terrain/contact handling. Updated companion qualification and protected companion state across rejected inputs, restore and session transitions. [Fuel evidence](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/research/fuel-systems/FUEL-12/README.md) · [Companion qualification](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/tools/companions/README.md)
- Improved controller calibration feedback and profile handling, including clearer input diagnostics and protected transitions between menus and flight.

### Menus, saved work and accident reports

- Improved startup text scaling, keyboard focus, localized navigation and helicopter launch-condition feedback. Conditions preserve independently authored weather fields and reveal the field that prevents Apply.
- Hardened recording saves, statistics deletion, Workshop draft recovery and Garage run replacement. Refused or interrupted operations preserve accepted data and offer recovery information.
- Weather saves preserve exact validated float64 values when the engine's numeric text cannot round-trip them. The Conditions editor preserves untouched values and checks displayed decimal spellings against the active parser.
- Expanded local accident-cost estimates for fixed-wing aircraft, with component-scoped assessment, DIY/shop labor choices, frozen purchase alternatives and validated saved-report archives. These are authored game estimates, not measured failure thresholds, repair quotations or certificates of serviceability. Older paired economics checkpoints are explicitly refused; legacy raw reports remain view-only and unverified. [Crash-cost behavior and compatibility](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/research/crash-damage-investigations/CR-40/README.md)

### Scenery, presentation and delivery

- Added a separate electric Stik paint kit and retained existing Stik and Extra skins through reviewed model-identity pairs. Kits preserve stock geometry and physics. [Skin compatibility](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/AIRCRAFT-SKINS.md)
- Updated woodland vegetation, fern and shrub cards, planting variation and backlighting. Added a scoped stock-Corsair shadow-mask proxy and reduced redundant controller, audio and presentation work. Hardware performance qualification remains specific to the recorded configurations.
- Hardened CI coverage receipts, native-runtime checks, exported-package smoke checks and release transfer verification. Added a reference identity receipt inside the macOS archive. [Release artifact contract](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/tools/release/README.md)

## Downloads and known limits

The release provides Windows x86_64, Linux x86_64 and macOS universal ZIP archives, `release-manifest.json`, `linux-abi.json` and `SHA256SUMS`. Use the checksums and manifest to verify the downloaded files. Archives are unsigned; the macOS app is ad-hoc signed, not notarized. Keep its sibling reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/FIRST-LAUNCH.md)

The engine remains official **Godot 4.8-beta2**, a prerelease. Linux x86_64 can use the native flight evaluator for qualified configurations; unsupported or unverified configurations fall back to the GDScript reference. Windows and macOS use the reference flight path. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/research/native-kernel/README.md#normal-flight-backend-selection)

The electric Stik 6S currently has no reviewed landing-statistics profile, so successful landings and touch-and-goes do not receive statistics credit. [Statistics scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/FLIGHT-STATISTICS.md#eligible-activities-and-classification)

Its elevator-moment models differ by about 18.7% at the reference trim. An explicit owner-authorized 30% software consistency band applies while both electric modes retain the donor's aerodynamics. This acceptance does not establish physical accuracy. [Stik model limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/UGLY-STIK-PLAN.md#limits-and-acceptance)

Exact weather saves can use settings schema 7. Older builds read its calm-weather fallback and keep the file read-only; they cannot restore its exact weather. [Settings recovery and compatibility](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/TOOLS.md#preference-file-recovery)

Native desktop/device acceptance, downloaded macOS quarantine behavior, physical radios, sustained target-GPU performance and pilot/readability qualification remain separate from automated software and export checks. Primary rendering and UI qualification targets 1920×1080. [Release gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/ROADMAP.md#execution-order-and-release-gates)

Aircraft, helicopter and RC ground-vehicle models remain experimental or under evaluation. Multirotor remains research groundwork, with no playable drone or racing activity. [Supported vehicle paths](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.2/docs/STACK.md#supported-vehicle-paths)
