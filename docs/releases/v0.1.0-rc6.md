# OpenRC Simulator v0.1.0-rc6

An experimental integration release covering the work since rc5: stronger flight/data checks, automated landing/circuit evidence, a richer field, crash diagnostics and tools for real-aircraft and radio measurements. Four aircraft fly: Ugly Stik 60, Extra 300S, P-51D and Avanti S. Extra, Mustang and Avanti remain experimental; pilot acceptance of the Stik is still open.

## Changes

- **Flight verification:** stronger trim, envelope, calibration, checkpoint and input-data checks; saved Stik approach/circuit/replay/sensitivity evidence. Automated landings use the real session, servos and ground contacts. Home still starts in the air.
- **Crash diagnostics:** typed impact snapshots, hull crossing reconstruction and a rendered crossing pose. Persistent structural damage and wreck effects remain future work.
- **Field:** distant forest/hills, cloud shadows, near grass, integrated ground surfaces, calm windsock, pilot station and flightline cues. Club scenery remains opt-in (`-- --scenery=on`). Trees and field props remain visual scenery.
- **Measurement tools:** standalone `-- --input-report=report.json --t=20`, filmed-latency marker (`-- --latency-patch`) and offline reducers for weight/CG, inertia, static propulsion, RPM steps and ground/roll video. Synthetic examples verify tools; they are not real-flight measurements.
- **Organization:** code-grounded roadmap, one ownership registry without duplicated step status, a practical tooling index, corrected Home/Help/player guides, offline tool regressions in CI and required tag-specific release notes.

## Verification and limits

The release workflow gates packaging on app, offline-tool, schema/generator and rendered-capture checks. Export checks run the Linux binary, inspect all three resource packs, verify build identity and inspect the universal/ad-hoc-signed macOS bundle. Native Windows/macOS sessions, physical radios, target GPUs and pilot/readability acceptance remain separate and open.

Production physics remains GDScript. The optional native wake experiments are not shipped dependencies; the enabled-wake performance budget and calibration remain open. Stik propeller inputs still include borrowed data and the production Stik wash is disabled. Automated circuit evidence is calm and wash-off; it does not close PT2 or validate handling. Physical wind, fuel burn, full engine operation, recorded engine audio, player-selectable runway scenarios and installers remain future work.
