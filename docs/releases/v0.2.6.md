# OpenRC Simulator v0.2.6

Unpublished candidate. The required integration gate rejected render-clock use in the race shaders; superseded by [v0.2.7](v0.2.7.md).

Early-alpha software release. Vehicle models remain experimental. Automated checks and replay agreement do not establish physical accuracy, target-hardware performance or pilot acceptance.

## Changes since v0.2.5

- Improved the experimental FPV quad's ground contact, friction and parked behavior, with revised substep handling and less repeated plant evaluation.
- Added local practice-race records and the Tower Sprint course; improved the countdown, race telemetry, gate/course presentation and FPV on-screen display settings.
- Added Home previews for non-aircraft vehicles in the RC Garage and staged startup/loading.
- Improved controller readiness checks, calibration/setup layouts and control assignment components.
- Added optional lens water drops and person-impact effects.
- Renewed AI-companion compatibility against the current solver using the retained input tapes, and requalified its Home-to-flight admission after the interface changes.
- Added the experimental local test queue and documented the configured Linux SSH connection for development checks.
- Included the generated Godot script UID sidecars needed for clean-checkout imports and release builds.

## Downloads and known limits

The release provides Windows x86_64, Linux x86_64 and macOS universal ZIP archives, `release-manifest.json`, `linux-abi.json` and `SHA256SUMS`. Verify the complete downloaded set with the manifest and checksums. Archives are unsigned; the macOS app is ad-hoc signed, not notarized. Keep its sibling reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/docs/FIRST-LAUNCH.md)

The engine remains official **Godot 4.8-beta2**, a prerelease. Qualified Linux fixed-wing/helicopter configurations can use the native evaluator; unsupported configurations retain the GDScript reference. Windows and macOS flight use the reference path. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/research/native-kernel/README.md#normal-flight-backend-selection)

The FPV quad, 5 m blimp and Aircraft Creator retain their experimental limits. The quad uses estimated plant data; race records are local practice results, not published-rule compliance. The Creator still lacks its numerical qualification gate. The electric Stik 6S has no reviewed landing-statistics profile. Existing weather schema 7 compatibility and recovery rules continue to apply. [Drone scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/docs/plans/drone-racing.md) · [Creator limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental) · [Settings recovery](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/docs/TOOLS.md#preference-file-recovery)

The Stik reference-doublet sideslip screen and R02 yaw comparison remain pending. Native desktop/device acceptance, downloaded macOS quarantine behavior, sustained target-GPU performance and physical flight validation remain separate from automated checks. Rendering and UI qualification prioritize 1920×1080. [Release gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.6/ROADMAP.md#execution-order-and-release-gates)
