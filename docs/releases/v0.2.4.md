# OpenRC Simulator v0.2.4

Early-alpha software release. Vehicle models remain experimental. Software checks and replay agreement do not establish physical accuracy, target-hardware performance or pilot acceptance.

## Changes since v0.2.3

- Added an experimental **5 m RC blimp** to the RC Garage, with three visual skins, vectored propulsion, a shared battery, ground and envelope contact, Workshop adjustments and dedicated flight recording/replay. Its parameters combine model geometry and authored estimates; no physical measurement validates this configuration. [Blimp evidence and limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/research/rc-airship/BL-12/README.md)
- Added an experimental **FPV quad** with Acro and Angle modes, low-throttle arming, FPV/chase/pilot cameras, adjustable camera tilt and throttle limit, battery/impact outcomes and flight recording/replay. Open it through **Home → RC Garage → Fly FPV quad**. The visual uses the downloaded OpenRacer frame with its bundled attribution and license. [Drone evidence and controls](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/research/drone-racing/M1-M3-2026-11-11/README.md)
- Added a **local three-lap practice race** on one six-gate oval. Press **G** in the FPV activity to enter it; the activity tracks gate order, invalid crossings, timing and results, with reset and race replay. Multiplayer and published race-rule compliance are not included. [Race scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/plans/drone-racing.md)
- Added the experimental **Aircraft Creator** inside the Workshop: import a model, describe a conventional airplane, preview an estimated electric configuration, save local drafts/versions and test-fly it. Saved aircraft currently reopen through the Creator; Home listing and export are pending. [Creator workflow and limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental)
- Made aircraft flap compensation ownership explicit and replayable, with supporting Avanti replay/native evidence, and renewed AI-companion compatibility against the current solver.
- Added wind-responsive flags with language-based country artwork and configurable animation quality, clearer localized calibration prompts, and improved controller profile/device refresh handling.
- Added bounded frame diagnostics and the GOD TEST development benchmark tool. Tracked the missing Godot script UIDs so clean imports preserve release source identity.

## Downloads and known limits

The release provides Windows x86_64, Linux x86_64 and macOS universal ZIP archives, `release-manifest.json`, `linux-abi.json` and `SHA256SUMS`. Verify downloaded files with the checksums and manifest. Archives are unsigned; the macOS app is ad-hoc signed, not notarized. Keep its sibling reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/FIRST-LAUNCH.md)

The engine remains official **Godot 4.8-beta2**, a prerelease. Qualified Linux fixed-wing/helicopter configurations can use the native evaluator; unsupported configurations retain the GDScript reference. Windows and macOS flight use the reference path. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/research/native-kernel/README.md#normal-flight-backend-selection)

The FPV plant uses estimated data and omits propwash, ground effect, sensor noise/delay, motor thermal state and ESC current limits. It is not equivalent to flight-controller firmware. Its whole-tick p95 development budget was not met on the measured development PC; native 1920×1080 frame pacing, radio latency and pilot qualification remain open. [Measured scope and omissions](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/research/drone-racing/M1-M3-2026-11-11/README.md)

The Creator has one conventional layout and one estimated electric package, no landing gear, and a choice of the imported appearance or one solid color; custom paint textures/patterns are pending. It has not passed its numerical qualification gate. The electric Stik 6S still has no reviewed landing-statistics profile. Existing weather schema 7 compatibility and recovery rules continue to apply. [Creator limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental) · [Statistics scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/FLIGHT-STATISTICS.md#eligible-activities-and-classification) · [Settings recovery](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/docs/TOOLS.md#preference-file-recovery)

Native desktop/device acceptance, downloaded macOS quarantine behavior, sustained target-GPU performance and physical flight validation remain separate from automated checks. Rendering and UI qualification prioritize 1920×1080. [Release gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.4/ROADMAP.md#execution-order-and-release-gates)
