# OpenRC Simulator v0.1.9 — preparation

**Not yet published.** These notes describe changes under review after v0.1.8. The latest preparation pass starts from source `96287766296b3fef6a37dcd4cc3847d7efbe9f19`; its fixes and bounded checks are recorded in the [preparation evidence](../research/release-readiness/PT1-v0.1.9/README.md). The final release commit, package contents and verification results remain to be established. This is an early-alpha simulator; software checks do not establish physical flight accuracy or pilot acceptance.

## Selected changes since v0.1.8

- The experimental F4U Corsair uses the g2.2 visual model with thirteen paint schemes. It adds folding wings, a sliding canopy and a tailhook; the canopy and tailhook are presentation mechanisms. Cowl flaps await a new model delivery, and the flight model remains unvalidated. [F4U plan](../F4U-PLAN.md) · [Paint evidence](../research/f4u-corsair/F4U-20/README.md) · [Mechanisms](../research/f4u-corsair/F4U-21/README.md)
- Current source adds an experimental X8 flying wing with elevons, electric pusher, a finite 6S battery and a hand-launch option. Its flight model and throw need physical and pilot validation. **Its inclusion in the release is pending a decision on the delivered asset's unset licence terms and working display name.** [X8 plan and decisions](../X8-PLAN.md) · [Asset terms](../../app/assets/aircraft/skywalker-x8/LICENSE.txt)
- Adds opt-in spatial wind, smooth gusts and optional kinematic thermal fields sampled at aircraft aerodynamic and propulsion locations. The existing uniform weather remains available and the interactive default is unchanged. Terrain effects, physical/spectral and pilot acceptance, target-hardware cost and companion operation with spatial weather remain open. [Wind guide](../WIND-PLAN.md)
- Adds local flight statistics for supported fixed-wing Home flights, with pilot and aircraft views, history, reset controls and an optional session overlay. Helicopter, ground-vehicle, replay and Workshop trial activities do not contribute. Large-history performance, packaged upgrade preservation and pilot comprehension remain unqualified. [Statistics guide](../FLIGHT-STATISTICS.md) · [Acceptance plan](../flight-statistics-plan.md)
- Adds configurable aircraft lighting profiles and Workshop controls for colors, patterns and bounded show effects. These are presentation features; the remaining night readability, motion, renderer lifecycle and performance gates are open. [Lighting implementation and qualification](../research/night-flight-lighting/implementation.md)
- Extends the interface from English and Spanish to nine selectable languages: English, Español, 简体中文, Português (Brasil), Deutsch, Français, Italiano, Русский and 日本語. English remains the first-run default. Translation and packaged-font checks must pass on the final candidate. [Interface languages](../../app/i18n/README.md)
- Changes the pinned development engine from Godot 4.7.2 to official **4.8-beta1**, a prerelease. Bounded comparisons and package checks exist for earlier frozen sources; the full merged-source CI, visual/audio review and release acceptance remain open. Compatibility remains the default renderer. [Upgrade evidence](../research/engine-upgrade/GDU-03/README.md) · [Remaining engine gates](../plans/godot-4.8-upgrade.md)

- Fixes found in pre-release checks: an aircraft that fails validation now shows the actual reason instead of "aircraft data is invalid"; weather preset lists fit small windows at large text; the X8 rests on its hull in the Home view instead of floating; Right from Home's Statistics button no longer jumps to the header. Practice fits English/Spanish at 1080p; its 720p fallback keeps actions reachable by keyboard and selected gamepad while scrolling within the rail.
- CI is configured to stage the exact native artifacts checked by its native jobs. Export identity now detects nonignored untracked project files, and F4U generation preserves its expected source bytes on Linux. Stale Vantage Jet and woodland provenance were regenerated without changing flight data or scenery placement.

## Intended downloads

Windows x86_64, Linux x86_64 and macOS universal ZIP archives and `SHA256SUMS` are planned. No v0.1.9 archives or checksums have been verified yet. Verify the final archives and hashes before updating the public website. See the [release procedure](../TOOLS.md#release-sequence) and [first-launch guide](../FIRST-LAUNCH.md); update the guide against the actual package before publication.

- The candidate needs matching `app/project.godot` version and annotated tag, reviewed release notes, applicable schema/generator, offline, full app and visual checks, and the three-platform package and checksum checks described in the [release procedure](../TOOLS.md#release-sequence). CI and package results must identify the final integrated commit.
- The [CI run for earlier source `f9e6dbe8`](https://github.com/bultodepapas/OpenRCsimulator/actions/runs/40430424732) failed its integration partition: the schema/loader test encountered missing imported Chinese and Japanese font resources. Multiple unit partitions and the visual job also failed during initial import; sampled unit logs report a timeout. Resolve and rerun the required checks; this is not a passing candidate result. Some jobs were still running when these notes were prepared.

The fixes are pending review and a new CI run; no candidate result exists yet.
- 2026-10-28: focused export, generator and offline checks pass, along with the 46-stage debug-bridge smoke and a bounded rendered Home/flight check at 1920×1080. The Stik sideslip and R02 yaw comparisons, Gate 2 and Gate P remain open. [Engine platform limits](../research/engine-upgrade/GDU-03/README.md#remaining-platform-scope) · [Roadmap](../../ROADMAP.md)
