# OpenRC Simulator v0.4.0

Early-alpha software release. Vehicle models remain experimental.

## Changes since v0.3.3

- **Faster flight on Windows and Linux.** More of each physics tick runs in the native flight evaluator: the substep plan, clear-air contact checks, ground and wheel queries, glow-engine stepping and the flight statistics. Results stay identical to the reference evaluator.
- **Native flight sound.** The soundscape, ground and mechanical sound cores, wheel and touchdown sounds near the ground, and the glow engine's voice now run in the native evaluator. Flight audio costs far less per frame, most of all on the runway and on low passes.
- **Smoother frames.** Shader-cache writes wait until no flight is running, and skyline and first-start graphics work run off the main thread. Controls and Settings open without rebuilding every row, and the aircraft shadow takes fewer per-frame steps.
- **Wind on Home.** A Wind row on Home cycles the wind presets in one press. Conditions names its preset selector and states that changes apply to the next flight. It also draws a runway compass with headwind, tailwind and crosswind. Pause's lighting dialog becomes **Time & sky**, and the scenery importer explains Phoenix RC.
- **FPV forest.** FPV quads collide with trees and gates using their frame and propeller shapes.
- **Graphics for slower GPUs.** Automatic setup can choose a lighter initial configuration on supported hardware, including a simplified ground. Eligible configurations can adjust the flight view's internal 3D resolution around a 30 FPS target. Existing profiles keep their saved graphics choices.
- **New liveries.** The Avanti S A200 gains JETI Ruby and ELAN 35, the Extra 300S gains Jumper RC T15, and the Turbo Lumber Evolution gains five wood and fabric finishes.
- **Ground driving.** The HUD measures height above the installed RC circuit. Failed recording exports keep their samples so you can retry.
- **Optional diagnostics.** Flight statistics handle pauses and context changes more consistently, and crash counts track each accident once.

## Downloads

Choose Windows x86_64, Linux x86_64 or macOS Universal (Apple Silicon and Intel). Compare the ZIP with `SHA256SUMS` from this release. Windows and Linux include the qualified native flight evaluator. The macOS package uses the reference evaluator and requires the supplied receipt beside the extracted app. The ZIPs are unsigned, and the macOS app is ad-hoc signed.
