# OpenRC Simulator v0.3.2

Early-alpha software release. Vehicle models remain experimental. Physical validation, pilot acceptance and target-hardware performance require separate checks.

## Changes since v0.3.0

- **Phoenix RC aircraft in Aircraft Creator.** Import aircraft from a local Phoenix installation and test-fly supported airplanes with OpenRC configurations derived from their source geometry and flight parameters. Supported fixed landing gear allows runway trials. [Aircraft Creator guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental)
- **Phoenix RC flying sites.** Import panoramas from a local installation, site folder, descriptor or ZIP. Five calibrated sites support runway starts for compatible airplanes. Other revisions remain available for preview. [Scenery guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/docs/LANDSCAPES.md#import-phoenix-scenery)
- **ClearView trials.** Aircraft Creator can suggest a setup automatically and test-fly supported airplane and helicopter imports through OpenRC models. Saved Creator aircraft are tested from the Workshop. [Aircraft Creator guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental)
- **Contact and crash fixes.** Propellers can strike the ground while coasting. Crash logs retain the complete incident when flight pauses. Quad and blimp contacts were corrected, and RC cars can collide with shared field scenery.
- **Physics evaluator and optional statistics.** Flights report when the native evaluator falls back to the reference evaluator. The revised opt-in usage notice includes the evaluator type in activity summaries. [Telemetry and privacy](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/docs/plans/telemetry/consent.md)

- **Translations.** The calibrated Phoenix runway and panorama prompts are available in all nine simulator languages.

## Downloads and known limits

Download the ZIP for Windows x86_64, Linux x86_64 or macOS (Apple Silicon and Intel). The release includes `SHA256SUMS`, `release-manifest.json` and `linux-abi.json`. The archives are unsigned. The macOS app is ad-hoc signed and requires its reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/docs/FIRST-LAUNCH.md)

The engine is Godot 4.8-beta2. Windows and Linux packages carry the qualified native flight evaluator. The macOS package uses the GDScript reference evaluator. Imports use OpenRC vehicle models and calibrated scenery approximations. The FPV quad, blimp and Aircraft Creator remain experimental. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.2/research/native-kernel/README.md#normal-flight-backend-selection)
