# OpenRC Simulator v0.1.0-rc3

This alpha adds a shared treeline to Home and flight, an aircraft selector, and menus in English and Spanish. It includes the changes since rc2, including the experimental Extra 300S and P-51D Mustang models.

## Highlights

- **A varied horizon:** 480 trees, three silhouettes and deliberate clearings. The runway and its approach corridor remain clear. The same saved layout appears on Home and in every flight.
- **Home and pause menus:** choose an aircraft, change language, open Help, start a flight, pause with Esc, restart or return Home. Losing focus pauses the flight. Your USB radio controls the airplane and does not navigate menus.
- **Four aircraft in the catalog:** Jensen Das Ugly Stik 60; Great Planes Extra 300S .60 (experimental); P-51D Mustang 1/4 (experimental); SebArt Avanti S (visual preview, Fly disabled).
- **Model refinements:** updated aircraft geometry and finishes, including silhouette-based work on the P-51D and Avanti S.
- **Build identification:** the app, trace headers and download filenames report the same release identity.

## Validation

The L6b implementation passed the full headless suite and exports from clean clones. Validation includes golden flights, trimmed flight for the three flyable aircraft, and matching simulation state at 30, 60 and 144 rendering fps.

The capture suite includes 112 existing views and 13 additional tree views repeated twice. All 480 shader identities are checked against the CPU, along with complete culling bounds and the Home-to-flight transition. The treeline measured 2–8 visible draws and zero shadow draws on the software renderer; these are draw counts, not performance results for your GPU.

Release packages are built from this tag by GitHub Actions. Export checks mount each platform's pack in an empty project, verify the tree assets and field data, and run the Linux binary's trimmed-flight smoke test. Windows and macOS still need native user testing.

## Known limitations

- Flights start in the air. Takeoff, landing and wind are not implemented; ground contact restarts the airplane.
- Trees are visual only and have no collisions. They use distant cards; close-range 3D trees are a later step.
- The Extra and Mustang use initial physics estimates and have not been validated against real flights. The Avanti's turbine propulsion is not simulated.
- Aircraft readability against the treeline still needs the L6c human playtest. Supported GPU performance and quality profiles remain unvalidated.

For testing, fly circuits and low passes, check whether you can identify attitude against the trees, and record your GPU, resolution and frame-time report. The in-app Help lists keyboard and radio controls.
