# OpenRC Simulator v0.2.9

Early-alpha software release. Vehicle models remain experimental. Automated checks and replay agreement do not establish physical accuracy, target-hardware performance or pilot acceptance.

## Changes since v0.2.8

- Windows packages now carry the qualified native flight kernel beside the executable, as Linux packages do. Supported configurations select it by default; unsupported configurations or a failed identity check fall back to the GDScript reference evaluator. The Windows gate covers the exported package; Windows native-flight performance is not qualified. [Windows packages](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/research/native-kernel/README.md#windows-release-packages-nk-4-owner-decision-2026-11-18-native-kernel-always)
- Added guided setup for EdgeTX radios in USB Joystick (Classic) mode: stick calibration, a switch check for gear, flaps, smoke and restart, and an in-flight guide that names the radio's switches. Optional simulator-side dual rates are off by default. No physical radio capture has been retained yet; channel mapping and Linux behaviour are inferred. [EdgeTX controls](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/plans/edgetx-airplane-controls.md)
- FPV quad: graded crashes (prop strikes and hard landings can damage props without ending the flight; a pause-menu option restores "every crash ends the flight"), turtle mode, preconfigured controls and fixes from a controls, physics and race-integrity audit. Thresholds are estimates. Airplane crash behaviour is unchanged. [Drone plan](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/plans/drone-racing.md#17-pilot-feedback-2026-11-17-preconfigured-controls-and-graded-crashes)
- Automatic graphics now uses one policy. Settings explains the chosen mode and how far its estimate is trusted, and capable High-tier machines (at least 8 GB VRAM and 8 CPU threads) can receive Automatic Extreme, falling back to High if it misses its budget. Calibration no longer raises scene detail on CPU-bound frames. The thresholds are provisional and the estimates rest on a small set of measured GPUs. [Automatic graphics](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/plans/automatic-graphics.md)
- New stock paint schemes, including SILVER ACE, NEON RONIN, BLACKBIRD and HONEYBEE, and refreshed collision for field shelters and bales.
- Aircraft Creator: an experimental adapter imports the supported visual part of ClearView aircraft archives for preview and drafts. Test flight and saving a flyable aircraft remain unavailable until the numerical gate is qualified. [Creator limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental)
- Reduced background controller-storage work in menus and rate-limited graphics-calibration timing reads.
- A telemetry client is included but unavailable: this build has no telemetry configuration, shows the Settings control disabled and sends nothing. [Telemetry status](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/plans/telemetry.md#merge-readiness-versus-activation)

## Downloads and known limits

The release provides Windows x86_64, Linux x86_64 and macOS universal ZIP archives, `release-manifest.json`, `linux-abi.json` and `SHA256SUMS`. Verify the complete downloaded set with the manifest and checksums. Archives are unsigned; the macOS app is ad-hoc signed, not notarized. Keep its sibling reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/FIRST-LAUNCH.md)

The engine remains official **Godot 4.8-beta2**, a prerelease. The public macOS download continues to use the GDScript reference flight evaluator; the Apple Silicon native route remains a source-editor development path. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/research/native-kernel/README.md#normal-flight-backend-selection)

The FPV quad, 5 m blimp and Aircraft Creator retain their experimental limits. The quad uses estimated plant data; race records are local practice results, not published-rule compliance. The electric Stik 6S has no reviewed landing-statistics profile. Existing weather schema 7 compatibility and recovery rules continue to apply. [Drone scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/plans/drone-racing.md) · [Settings recovery](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/docs/TOOLS.md#preference-file-recovery)

The Stik reference-doublet sideslip screen and R02 yaw comparison remain pending. Native desktop/device acceptance, downloaded macOS quarantine behavior, sustained target-GPU performance and physical flight validation remain separate from automated checks. Rendering and UI qualification prioritize 1920×1080. [Release gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.2.9/ROADMAP.md#execution-order-and-release-gates)
