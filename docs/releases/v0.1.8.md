# OpenRC Simulator v0.1.8

Stable software release of the early-alpha simulator. Aircraft and ground-vehicle models remain experimental and need independent measurements and pilot evaluation.

## Changes since v0.1.7

- Adds a Scene detail preset (Low, Medium, High, Extreme; Automatic by default) under Settings > Graphics. It selects the scenery tier, how many front field trees render in 3D and the mesh LOD threshold. Collision, simulation and replays do not read it.
- Adds an opt-in experimental High graphics profile (Forward+) from Home settings and `tools/graphics/launch.py`. The Compatibility renderer remains the default.
- Renders the front near-ring field trees as 3D trees, adds far woods (groves-v2), new downloaded beech and oak models, and close-range wind motion for downloaded trees.
- Refines field presentation: projected contact shadows, windsock fabric and support, flightline barrier, water, sky and ridge haze.
- Adds a retractable-taildragger option to the imported gear rig (left and right wheels with one steered nose or tail wheel).
- Speeds up the glow fuel-feed closure, P-51 substep preview, hull contacts and lake hull checks. Recorded outputs match the previous solver byte-for-byte; real-time backlog remains on slower machines.
- Extends Extra 300S post-stall work with a FASER-fitted polar and continues F4U Corsair and P-51 research. These changes do not establish physical accuracy.
- Re-binds the AI companion profile to the current solver identity after nine retained crossing and parallel-threat tapes replayed byte-identically against the previous identity. Companions remain experimental, narrowly qualified and off by default.
- Counts 3D field trees in the export pack check and the L7 horizon capture, so both again verify all 1,680 placed trees.
- Adds a repository large-file check to `app/test.sh` and the opt-in pre-push hook.

## Verification and limits

The tagged release workflow publishes these archives only after the complete app matrix, visual captures, native evaluator builds, frozen prototype checks, and three-platform export/package checks pass. The tag must match `app/project.godot` and a clean source commit.

Automated checks verify software behavior, not physical aircraft accuracy, pilot handling, radio compatibility, target-machine performance or native macOS gameplay. The Stik sideslip screen and R02 yaw-damping comparison remain open, alongside the [roadmap gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.8/ROADMAP.md). See the [tools and release procedure](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.8/docs/TOOLS.md#release-sequence) for reproducible checks.
