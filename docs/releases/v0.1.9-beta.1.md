# OpenRC Simulator v0.1.9-beta.1

**Beta preview of an early-alpha simulator.** Aircraft and other vehicle models are experimental; software checks do not establish physical flight accuracy or pilot acceptance. This draft describes the candidate based on source `e1e9bcf6c117823c2f4357e1d04bfe6de94eeb08`; the final tagged commit, package contents and verification results still need to be established.

## Selected changes since v0.1.8

- The experimental F4U Corsair uses the g2.2 visual model with thirteen paint schemes, folding wings, a sliding canopy and a tailhook. The canopy and tailhook are presentation mechanisms; cowl flaps await a new model delivery. The flight model remains unvalidated. [F4U plan](../F4U-PLAN.md) · [Paint evidence](../research/f4u-corsair/F4U-20/README.md) · [Mechanisms](../research/f4u-corsair/F4U-21/README.md)
- Current source includes the experimental MoonRunner X99 flying wing with elevons, electric pusher, a finite 6S battery and a hand-launch option. Its flight model and throw require physical and pilot validation. **Inclusion in a distributed package remains unresolved:** the delivered asset's licence terms are unset. [X8 plan and owner decisions](../X8-PLAN.md#4-owner-decisions) · [Asset terms](../../app/assets/aircraft/skywalker-x8/LICENSE.txt)
- Adds opt-in spatial wind, smooth gusts and optional kinematic thermal fields sampled at aerodynamic and propulsion locations. Uniform weather remains available and the interactive default is unchanged. Terrain effects, physical and pilot acceptance, target-hardware cost and companion operation with spatial weather remain open. [Wind guide](../WIND-PLAN.md)
- Adds local flight statistics for supported fixed-wing Home flights, including pilot and aircraft views, history, reset controls and an optional session overlay. Helicopter, ground-vehicle, replay and Workshop trial activities do not contribute. Large-history performance, packaged upgrade preservation and pilot comprehension remain unqualified. [Statistics guide](../FLIGHT-STATISTICS.md)
- Adds configurable aircraft lighting profiles and Workshop controls for colors, patterns and bounded show effects. Night readability, motion, renderer lifecycle and performance gates remain open. [Lighting implementation and qualification](../research/night-flight-lighting/implementation.md)
- Extends the interface from English and Spanish to nine selectable languages: English, Español, 简体中文, Português (Brasil), Deutsch, Français, Italiano, Русский and 日本語. English remains the first-run default. Translation and packaged-font checks need to pass on the final candidate. [Interface languages](../../app/i18n/README.md)
- Changes the pinned development engine from Godot 4.7.2 to official **4.8-beta1**, a prerelease. Compatibility remains the default renderer. Earlier source has bounded comparison and package evidence; final candidate acceptance is still required. [Upgrade evidence](../research/engine-upgrade/GDU-03/README.md) · [Remaining engine gates](../plans/godot-4.8-upgrade.md)
- Pre-release fixes improve aircraft validation messages, large-text weather preset lists, MoonRunner's Home-view resting position, and Home Statistics keyboard navigation. Practice fits English and Spanish at 1080p; its 720p fallback keeps actions reachable while scrolling within the rail.

## Downloads and verification

Windows x86_64, Linux x86_64 and macOS universal ZIP archives and `SHA256SUMS` are intended. No final beta archives or checksums have yet been verified. The release procedure requires a matching project version and tag, final-source checks, and package and checksum verification. [Release procedure](../TOOLS.md#release-sequence) · [First-launch guide](../FIRST-LAUNCH.md)

The [preparation evidence](../research/release-readiness/PT1-v0.1.9/README.md) records bounded checks on earlier source states, including a 1920×1080 Home/flight check and a local aggregate in which one strict fixed-gear brake reference remained unresolved. Those results are not final-candidate CI or package qualification. Final verification must identify the actual tagged commit.

Native Linux desktop X11/Wayland and macOS execution, physical radio/device behavior, target-GPU performance and pilot/readability acceptance remain separate from export and headless checks. The Stik sideslip and R02 yaw comparisons, Gate 2 and Gate P remain open. [Platform limits](../research/engine-upgrade/GDU-03/README.md#remaining-platform-scope) · [Roadmap](../../ROADMAP.md)

Aircraft, helicopter and RC ground-vehicle models remain experimental or under evaluation. Multirotor work is research groundwork, with no playable drone or racing activity. [Supported vehicle paths](../STACK.md#supported-vehicle-paths)
