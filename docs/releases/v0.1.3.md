# OpenRC Simulator v0.1.3

Stable software release of the early-alpha simulator. Aircraft models and experimental activities still require independent physical and pilot validation.

## Changes since v0.1.2

- Fixes pause/restart routing so resuming a flight preserves the accepted controls and a runway restart begins at idle. Adds explicit runway-start regression coverage across the fixed-wing fleet.
- Improves P-51 propeller slipstream integration and adds an explicit sidewash model. The strict ground, handling and envelope checks are enabled again. The aircraft remains experimental; powered trim and target-machine performance remain open. [P51-26 evidence](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.3/docs/research/p51-realism/P51-26/README.md).
- Updates the Extra 300 runway gear setup with retained baseline and candidate replay evidence. [Extra evidence](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.3/docs/research/extra-300-realism/README.md).
- Adds aircraft sound propagation delay and distance-dependent high-frequency absorption. Acoustic and listening qualification remain open.
- Routes thunder through its flight's environment mix and limiter, including scene suspension, reattachment and disposal.
- Repairs the P-51 Workshop descriptor after its aircraft data changed and regenerates the aircraft parameter reference.
- Improves crash-cost identity handling, contact-to-part inspection mapping, provisional replacement ceilings and cached catalog loading. Missing prices and incomplete dossiers remain explicit. [CR-39 evidence](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.3/docs/research/crash-damage-investigations/CR-39/README.md).
- Hardens release packaging: the triggering tag must identify the clean source commit and match the numeric application version; import errors stop export even if Godot returns zero. Adds disposable exporter regression checks.
- Gives the complete P-51 envelope test a measured-workload timeout of 180 seconds; all flight assertions remain mandatory.
- Makes UI test teardown wait for a real audio-mixer interval, using monotonic time instead of simulation frame delta. Engine-error and resource-leak checks remain enabled.
- Adds a reproducible developer flight-test battery and refreshes the source documentation and aircraft imagery.

## Verification and limits

Publication requires the complete application test matrix, visual captures, both native evaluator builds, prototype checks and three-platform export checks. Focused Windows checks cover soundscape, thunder lifecycle, Settings, Workshop and the strict P-51 envelope. Exporter regressions cover tag selection, clean-source identity, version mismatch and import failure.

The known Stik rudder-recovery and R02 yaw-damping comparisons remain reported as pending, separately from software failures. P-51 flight assertions pass but do not establish physical accuracy. Helicopter, ground vehicles, glow installations, weather, audio and aircraft handling retain their documented experimental limits. Automated checks do not establish radio compatibility, target-GPU performance or native macOS gameplay acceptance.
