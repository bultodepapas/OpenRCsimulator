# OpenRC Simulator v0.1.6

Stable software release of the early-alpha simulator. Aircraft models and experimental activities still require independent physical and pilot validation.

The v0.1.4 and v0.1.5 tags were not published. Release checks identified incorrectly aggregated expected CLI failures and insufficient time allowance for long tests on shared CI runners. This release preserves those tags, validates expected rejections separately and gives measured long tests bounded execution time without changing their assertions or physical tolerances.

## Changes since v0.1.3

- Adds finite liquid fuel to supported fixed-wing installations, with launch fill, depletion and changing mass properties. Turbo Lumber uses a finite battery by default and retains an ideal-supply comparison; battery telemetry now shows pack state and warnings. The base Stik keeps its prescribed-fuel reference. Fuel and installation data remain estimates. [Fuel contract](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/FUEL-SYSTEM.md).
- Adds level-trimmed 50% airborne starts for fixed-wing aircraft, preserves the selected start on restart and refits runway trim for the selected atmosphere.
- Fixes simulation faults in P-51 power-off flight when the propeller is at rest or near the engine's RPM cutoff, including fuel-exhaustion transitions. [Regression and recorded-flight evidence](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/research/propulsion/G2a-RK4/README.md).
- Aligns Natural Random briefing identity with the aircraft supply used by the launch route.
- Updates experimental glow-engine throttle response and the Stik's lateral-directional model.
- Adds a normal/full dual-rate switch for keyboard and gamepad flight controls; radios retain their own rates.
- Adds selectable, remembered Club and Green landscapes, with vegetation and scenery updates.
- Improves twilight, moon phases and eclipses, and automatic aircraft lighting with manual override.
- Improves Workshop editing, preview and recovery; Home layout at 1280×720 in English and Spanish; flight audio and smoke handling.
- Extends visual checkpoint handling to finite-fuel flights and preserves historical aircraft-data compatibility.

## Verification and limits

Publication requires the complete application test matrix, rendered visual captures, both native evaluator builds, prototype checks and Windows, Linux and macOS export/package checks. The release tag must match the application version and a clean source commit. The tagged workflow publishes the downloads only after every required job passes.

Focused regression evidence is recorded in the [Natural Random report](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/research/natural-random/README.md), [power-climb and trim report](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/research/flight-dynamics/power-climb-2026-10-19/README.md), [sun visual report](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/research/sun/SUN-01-05/README.md) and [landscape/export report](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/docs/research/landscape-upgrade/L21-24/README.md).

Automated tests and captures verify software behavior; they do not establish physical accuracy, pilot handling, radio compatibility, target-machine performance or native macOS gameplay acceptance. The Stik sideslip screen and R02 yaw-damping comparison remain open, alongside the other gates in the [roadmap](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.1.6/ROADMAP.md).
