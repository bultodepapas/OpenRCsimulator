# OpenRC Simulator v0.3.4

Early-alpha software release. Vehicle models remain experimental.

## Changes since v0.3.3

- **Graphics for slower GPUs.** Automatic setup can select a lighter initial configuration on supported hardware. Eligible configurations can adjust the flight view’s internal 3D resolution around a 30 FPS target. Existing profiles retain their saved graphics choices.
- **New liveries.** The Avanti S A200 gains JETI Ruby and ELAN 35, the Extra 300S gains Jumper RC T15, and the Turbo Lumber Evolution gains five wood and fabric finishes.
- **Ground driving.** The HUD measures height above the installed RC circuit, and failed recording exports retain their samples so you can retry.
- **Optional diagnostics.** Flight statistics handle pauses and context changes more consistently. Crash counts track each accident once.

## Downloads

Choose Windows x86_64, Linux x86_64 or macOS Universal (Apple Silicon and Intel). Compare the ZIP with `SHA256SUMS` from this release. Windows and Linux include the qualified native flight evaluator. The macOS package uses the reference evaluator and requires the supplied receipt beside the extracted app. The ZIPs are unsigned, and the macOS app is ad-hoc signed.
