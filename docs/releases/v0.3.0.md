# OpenRC Simulator v0.3.0

Early-alpha software release. Vehicle models remain experimental. Automated checks and replay agreement do not establish physical accuracy, target-hardware performance or pilot acceptance.

## Changes since v0.2.9

- **Optional usage statistics.** This is the first release that can send telemetry. The first launch explains what is collected and recommends enabling it, but nothing is collected or sent until you choose **Enable**. You can turn it off at any time in Settings → Interface, and `OPENRC_TELEMETRY_DISABLE=1` forces it off for a launch. Reports carry no permanent player, device or account identifier; they help us see which hardware, settings and vehicles need work. The receiver is run by the project maintainers and relayed by Tailscale Funnel. [Telemetry and privacy](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/docs/plans/telemetry/consent.md)
- **Aircraft Creator: ClearView import.** ClearView aircraft ZIPs now import more completely, including older parameter formats, GIF and JPEG textures with metadata, very detailed models and texture paths pointing to the author's PC. After you confirm an estimated OpenRC configuration, an imported airplane can be test-flown and saved like an STL or GLB model. The flown physics are the OpenRC configuration, never the ClearView flight model. Helicopters import for preview, moving parts and drafts only. Saved Creator aircraft still cannot be flown from Home. [Creator limits](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/docs/AIRCRAFT-WORKSHOP.md#aircraft-creator-experimental) · [ClearView import guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/site/clearview-import-en.md)
- **Fixes from a CPU/GPU audit.** Fuel and battery events that occur close together are now resolved in the correct order, and an earlier crossing is no longer skipped. Collision ties no longer depend on discovery order. Blimp flight logs, cloud-shadow ordering and automatic graphics calibration were also corrected. Ordinary airplane flights are unchanged: the AI-companion qualification flights replay byte for byte.
- **Lower CPU cost.** The procedural engine sound costs about half as much to synthesize, with identical audio, and landing-gear ground checks are skipped high above the ground.
- Updated translations.

## Downloads and known limits

The release provides Windows x86_64, Linux x86_64 and macOS universal ZIP archives, `release-manifest.json`, `linux-abi.json` and `SHA256SUMS`. Verify the complete downloaded set with the manifest and checksums. Archives are unsigned; the macOS app is ad-hoc signed, not notarized. Keep its sibling reference receipt beside the extracted app. [First-launch guide](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/docs/FIRST-LAUNCH.md)

The engine remains official **Godot 4.8-beta2**, a prerelease. Windows and Linux packages carry the qualified native flight kernel; the public macOS download continues to use the GDScript reference flight evaluator. [Backend scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/research/native-kernel/README.md#normal-flight-backend-selection)

The FPV quad, 5 m blimp and Aircraft Creator retain their experimental limits. The telemetry notice has been reviewed in English and Spanish; other languages do not offer telemetry yet. Its rendering on a Mac Retina panel and with a controller, and its frame-time overhead, are still to be checked on this build. [Drone scope](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/docs/plans/drone-racing.md) · [Settings recovery](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/docs/TOOLS.md#preference-file-recovery)

The Stik reference-doublet sideslip screen and R02 yaw comparison remain pending. Native desktop/device acceptance, downloaded macOS quarantine behavior, sustained target-GPU performance and physical flight validation remain separate from automated checks. Rendering and UI qualification prioritize 1920×1080. [Release gates](https://github.com/bultodepapas/OpenRCsimulator/blob/v0.3.0/ROADMAP.md#execution-order-and-release-gates)
