# OpenRC Simulator v0.3.3

Early-alpha software release. Vehicle models remain experimental.

## Changes since v0.3.2

- **Graphics setup.** Automatic graphics setup uses the display and GPU selected at startup. Settings shows the recommendation alongside manual overrides and allows you to restore automatic settings. An interrupted or incomplete calibration can be retried.
- **Avanti S livery.** The Avanti S A200 gains the REVOC Custom paint scheme, with separate wing, stabilizer, fin and fuselage textures.
- **Windows test tooling.** The process containment suite installs its pinned dependency so it can exercise Windows Job Object behavior in CI.

## Downloads

Choose Windows x86_64, Linux x86_64 or macOS Universal (Apple Silicon and Intel). Compare the ZIP with `SHA256SUMS` from this release. Windows and Linux include the qualified native flight evaluator. The macOS package uses the reference evaluator and requires the supplied receipt beside the extracted app. The ZIPs are unsigned, and the macOS app is ad-hoc signed.
