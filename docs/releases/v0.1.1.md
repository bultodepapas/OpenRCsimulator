# OpenRC Simulator v0.1.1

A patch update to the v0.1.0 desktop release. OpenRC Simulator remains an early-development project; these changes do not establish flight or vehicle validation.

## Changes since v0.1.0

- Adds an experimental O.S. MAX-61FX two-stroke Stik configuration. Its torque and propeller inputs include inferred or borrowed data.
- Configured glow installations now model carburetor feed pressure from tank geometry, fuel level, apparent acceleration, throttle and RPM; this affects mixture and engine output. Transport assumptions are inferred and need physical validation.
- Integrates the experimental helicopter research model as a hover trainer, using an X-Cell .60 SE flight reference and an HX-700 visual surrogate.
- Adds an experimental Bisonte MT8 RC truck activity with separate vehicle physics and replay. Its physical accuracy and target-machine performance remain unqualified.
- Adds optional fixed-wing emergency practice and improves failure/control handling.
- Adds moving-cloud and electrical-storm presentation, including lightning and rain effects. These are visual effects; storms do not add spatial weather forces.

## Verification and limits

Tagged CI gates publication on the app checks and Windows, Linux and macOS exports, including a Linux trimmed-flight smoke test and resource-pack probes. These software checks do not establish physical flight validation, radio compatibility, pilot acceptance or target-machine performance. Experimental labels and open measurement gates remain in force.

- Review fixes stabilize glow startup and trace handling, isolate Windows test data, and refresh documentation. The one-ULP trace guard, Timber no-compression import rule, Stik palette guard, and grass guard restore v0.1.0 guarantees rather than add features.
