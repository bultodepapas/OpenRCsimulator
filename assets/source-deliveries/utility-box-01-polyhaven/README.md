# Poly Haven Utility Box 01 source

[Utility Box 01](https://polyhaven.com/a/utility_box_01) by James Ray Cock is published by Poly Haven under [CC0](https://polyhaven.com/license). The official 1K glTF package was downloaded on 2026-10-20 from the URLs in [`source-manifest.json`](source-manifest.json). That manifest records the official API MD5 values and the downloaded SHA-256 values.

The package contains the original glTF 2.0 file, its shared geometry buffer, and the three 1K JPEG maps referenced by that file. The exact same files are copied into `app/assets/landscape/track-timing-cabinet/` for runtime import. No geometry, materials, orientation, or textures were modified; no export step was needed.
