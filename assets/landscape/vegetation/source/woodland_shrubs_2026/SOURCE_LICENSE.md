Shrub 03 by Rico Cilliers: https://polyhaven.com/a/shrub_03

CC0 1.0 legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode.en
Accessed: 2026-11-09. Supplier API snapshots and all glTF 1K dependencies are retained unchanged with download hashes. The supplier's separate 16-bit Alpha map is also retained.

The external-only derivatives select complete supplier mesh nodes shrub_03_a and shrub_03_b, remove their gallery node translations, preserve primitive/accessor/buffer, UV and normal bytes, and pack supplier diffuse RGB with alpha rounded from 16 to 8 bits. The supplied double-sided MASK mode and 0.5 cutoff are unchanged. No geometry or texture painting is performed. These are offline atlas sources, not runtime 3D assets.
