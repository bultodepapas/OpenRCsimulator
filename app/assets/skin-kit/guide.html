Disponible para Skywalker X8

Una idea se convierte en una skin

El resultado para el simulador es un archivo .orskin. La pintura cambia la apariencia del avión, no su forma ni su comportamiento de vuelo.

1. Descarga el kit

  1. En OpenRC abre Inicio → Aeronaves → Skywalker X8 → Elegir pintura → Crear una skin. En la ventana de herramientas selecciona Guardar plantilla de Blender… y guarda skywalker-x8.zip.
  2. Descomprime el ZIP en una carpeta propia. Contiene Skywalker-X8.blend, Export OpenRC Skin.py, README.txt y esta guía guide.html. Guarda una copia sin modificar.
  3. Instala Blender gratis desde su página oficial. La plantilla se guardó con Blender 5.2.2: utiliza esa versión o una versión posterior compatible. La descarga y los servicios de IA necesitan internet; esta guía no.

2. Elige tu idea y una forma de trabajar

Por ejemplo: «Hazme una skin inspirada en un tiburón blanco». Añade colores, dónde quieres las marcas y un nombre. Elige referencias propias o que tengas permiso de usar; guarda su origen y las condiciones de uso, especialmente si contienen logotipos o arte ajeno.

  • Codex en tu computador: abre la carpeta descomprimida en una sesión local de Codex, comparte la idea, las referencias y el texto de abajo. Pídele que localice y pruebe Blender instalado o que use un MCP de Blender ya configurado. Si tienes la CLI, puedes iniciar codex en la carpeta. Dale acceso de escritura a esa carpeta.
  • Claude Desktop + Blender: abre el .blend y configura e inicia el conector de Blender. Comparte el texto y las referencias en Claude Desktop. El conector trabaja con la escena abierta: después guarda el proyecto en Blender. El conector requiere Blender 4.2 o posterior, pero para esta plantilla utiliza la versión indicada arriba.
  • Claude en navegador u otra IA en la nube: sube el ZIP y las referencias si el servicio lo permite. Pide primero que compruebe ejecutando Blender o bpy que puede abrir la plantilla. Crear archivos en la nube no garantiza que Blender esté instalado; el conector local de Blender no funciona en Claude del navegador. Si no supera la prueba, usa una de las opciones locales. También puedes terminar en tu Blender local si recibes un .blend editado.

Una respuesta de texto o una imagen renombrada no es una skin terminada. Pide archivos reales y las comprobaciones que la IA sí pudo realizar.

3. Copia el encargo para la IA

Edita la primera frase con tu idea. Adjunta el kit y tus referencias, o indica la carpeta local. Puedes copiar el texto para Claude o Codex.

El kit utiliza una imagen de pintura de x8_livery; los demás materiales pueden usar su color base Principled. El exportador acepta el color base y una imagen conectada directamente, no combinaciones procedurales sin hornear. Mantén los demás canales del material como están. La transparencia no está garantizada.

Termina, exporta y vuela

4. Guarda y exporta en Blender

Tu asistente puede hacerlo. Si solo te devuelve el proyecto editado, sigue estos pasos:

  1. Abre el .blend editado. Revisa arriba, abajo y lados en Material Preview; comprueba uniones, zonas reflejadas, marcas y superficies móviles.
  2. En un Image Editor, selecciona la imagen pintada (inicialmente x8_abisal_base_color) y usa Image → Save. Para imágenes externas vinculadas nuevas, usa también File → External Data → Pack Resources. Luego guarda el .blend con otro nombre mediante File → Save As y ábrelo de nuevo para comprobar que la pintura se conservó. Empaquetar recursos por sí solo no guarda los cambios de la imagen ya empaquetada.
  3. Abre el espacio Scripting; en su editor de texto abre Export OpenRC Skin.py de la carpeta del kit y pulsa Run Script. En el diálogo elige una ubicación y guarda, por ejemplo, Mi diseño.orskin. El nombre del archivo será el nombre de la pintura: máximo 48 caracteres imprimibles.
  4. Para una vista previa, encuadra el avión en Material Preview, configura la salida a 1920 × 1080 al 100 % y usa View → Viewport Render Image en la vista 3D; guarda la imagen desde la ventana de imagen. Repite desde otro ángulo si hace falta. El kit no genera una vista previa automáticamente ni incluye cámara.

La imagen 1920 × 1080 sirve para revisar el diseño. La textura de pintura del kit es de 2048 × 2048. El archivo que se carga en OpenRC es el .orskin, no la imagen ni el .blend.

Para un asistente que use terminal, desde la carpeta del kit (reemplaza el nombre del proyecto si lo guardaste con otro nombre):

blender --background Skywalker-X8.blend --python "Export OpenRC Skin.py" -- --output my-design.orskin --label "My design"

Si blender no está en la ruta de comandos, utiliza la ruta completa al ejecutable. El exportador de la ventana también sirve.

5. Carga la pintura

  1. En OpenRC selecciona Inicio → Aeronaves → Skywalker X8 → Elegir pintura → Cargar nueva skin….
  2. En la ventana de herramientas pulsa Cargar nueva skin… y elige el .orskin. Si se importa correctamente, queda seleccionado. Compruébalo en Inicio y en vuelo.
  3. La skin importada y la selección se conservan al reiniciar. Para volver al aspecto original, elige una pintura incluida en la galería.

Si se rechaza el archivo, lee el mensaje y revisa que sea un .orskin exportado con el kit del X8 y para la versión actual del modelo. Para otro avión o una versión distinta, descarga un kit nuevo y vuelve a exportar. Un rechazo no cambia la pintura seleccionada. Se pueden instalar hasta 32 pinturas personalizadas para el X8; importar dos veces el mismo archivo no crea otra entrada.

Límites de importación: .orskin de hasta 32 MiB; PNG de hasta 16 MiB y 4096 × 4096 cada uno; máximo 16.777.216 píxeles decodificados sumando todas las imágenes y hasta nueve materiales/texturas. Una imagen de 4096 × 4096 consume todo el límite de píxeles. Comienza con una imagen de 2048 × 2048.

Conserva el .blend, las imágenes y sus referencias para futuras ediciones. Antes de compartir el archivo de skin, la plantilla del avión o arte de terceros, comprueba los permisos aplicables.

Available for Skywalker X8

Turn an idea into a skin

The simulator loads an .orskin file. A skin changes the aircraft's appearance, not its shape or flight behavior.

1. Get the kit

  1. In OpenRC open Home → Aircraft → Skywalker X8 → Choose paint → Create a skin. In Skin tools select Save Blender template… and save skywalker-x8.zip.
  2. Extract the ZIP into its own folder. It contains Skywalker-X8.blend, Export OpenRC Skin.py, README.txt and this guide.html. Keep a clean copy.
  3. Install free Blender from its official site. The template was saved with Blender 5.2.2; use that version or a compatible newer version. Downloads and AI services need internet; this guide does not.

2. Choose an idea and a way to work

For example: “Make me a skin inspired by a great white shark.” Add colors, placement and a name. Use references you own or have permission to use; keep their source and terms, especially for logos or someone else's artwork.

  • Codex on your computer: open the extracted folder in a local Codex session. Supply the prompt and references below. Ask it to find and test your installed Blender or use a configured Blender MCP. If you have the CLI, you can start codex in the folder. Give it write access to the folder.
  • Claude Desktop + Blender: open the .blend, set up and start the Blender connector, then supply the prompt and references in Claude Desktop. The connector works on the open scene; save the project in Blender afterwards. Its Blender 4.2 minimum does not replace the newer version needed by this kit.
  • Claude in a browser or another cloud assistant: upload the ZIP and references if accepted. First ask it to demonstrate that it can run Blender or bpy and open the template. Cloud file creation does not guarantee Blender is installed; Claude's browser cannot use the local Blender connector. If the check fails, use a local route. You may also finish the export locally if you receive an edited .blend.

A text answer or a renamed image is not a finished skin. Ask for actual files and an honest report of the checks performed.

3. Copy the AI brief

Change the first sentence to your idea. Attach the kit and references, or give the assistant the local folder. This prompt works for Claude or Codex.

The kit uses one x8_livery paint image; other materials can use their Principled Base Color. The exporter supports a base color and a directly connected image, not unbaked procedural mixes. Leave other material channels as they are. Transparency is not guaranteed.

Finish, export and fly

4. Save and export in Blender

Your assistant may do this. If it returns only the edited project, complete these steps:

  1. Open the edited .blend. Inspect the top, underside and sides in Material Preview, including seams, mirrored areas, markings and moving surfaces.
  2. In an Image Editor, select the painted image (initially x8_abisal_base_color) and choose Image → Save. For newly linked external images also use File → External Data → Pack Resources. Then File → Save As a new .blend and reopen it to check the paint survived. Packing resources alone does not save edits to the already packed paint image.
  3. Open the Scripting workspace. In its Text Editor open the kit's Export OpenRC Skin.py and choose Run Script. In the dialog choose a location and a name such as My design.orskin. The filename becomes the paint name, up to 48 printable characters.
  4. For a preview, frame the aircraft in Material Preview, set output to 1920 × 1080 at 100%, and choose View → Viewport Render Image in the 3D Viewport; save the image from the image window. Repeat from another angle if needed. The kit does not automatically create a preview or include a camera.

The 1920 × 1080 image is for review. The kit's paint texture is 2048 × 2048. Load the .orskin into OpenRC, not the image or the .blend.

For an assistant using a terminal, run this from the kit folder (replace the project name if you saved it under another name):

blender --background Skywalker-X8.blend --python "Export OpenRC Skin.py" -- --output my-design.orskin --label "My design"

If blender is not on the command path, use the full path to its executable. The GUI exporter works too.

5. Load the paint

  1. In OpenRC select Home → Aircraft → Skywalker X8 → Choose paint → Load new skin….
  2. In Skin tools choose Load new skin… and select the .orskin. A successful import selects it automatically. Inspect it on Home and in flight.
  3. Imported skins and the selection persist across restarts. To restore the original appearance, select a built-in paint in the gallery.

If import fails, read the message and check that the file is an .orskin exported from the X8 kit for the current model version. For another aircraft or version, download a fresh kit and export again. Rejection leaves the current selection unchanged. Up to 32 custom paints may be installed for the X8; importing identical bytes twice does not make a second entry.

Import limits: up to 32 MiB for the .orskin; up to 16 MiB and 4096 × 4096 per PNG; at most 16,777,216 decoded pixels across all images and nine materials/textures. One 4096 × 4096 image uses the full pixel allowance. Start with one 2048 × 2048 image.

Keep the .blend, images and references for future edits. Check the applicable permissions before sharing the skin file, aircraft template or third-party artwork.
