# Weather runtime notices

## Godot3DLightning algorithm reference

The bounded, event-seeded lightning channel construction in `app/render/weather/lightning.gd` was informed by the branching-path approach in [Godot3DLightning](https://github.com/AurelienCaille/Godot3DLightning) at commit `96b03587f6378ec50281a8ed959f40f2e160c261`. The runtime implementation is an independent minimal adapter; the upstream add-on and demo assets are not included.

Upstream repository archive SHA-256: `0A31E942707047655FA8D19198B83CEFFEB9517DE398993863B5A4B51630464E`.
