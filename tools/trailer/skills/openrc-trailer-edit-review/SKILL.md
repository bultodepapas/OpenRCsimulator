# OPEN RC SIMULATOR — editorial supervisor

## Required review evidence

Read the current V2 script and original v9.13 review. Work with whatever movie, timed frames, shot log and music stems the user actually supplied. If there is no MP4, do a **script-level editorial critique**, not a fictional playback report.

Separate source footage, licensed music, real in-game sound, graphics/title overlays, AI concept plates, and cinematic-only choreography. No final claims before full decode and inspected full-motion source.

## Four-pass editorial test

1. **Silent story:** By 5 s audience sees a recognizable action; within 20 s sees fleet variety. Drone gate purpose, jet inverted orientation, helicopter motion, mini/giant, skins and water reflection remain understandable with audio muted. Game is recognizable without technical captions.
2. **Visual cadence:** 13 quick roster clips are allowed, but return to coherent 3–12 s heroes. Use one held lake/Corsair beauty section as emotional reset. Avoid repeated drone chase, red Stick over same pond, or empty lightning cloud. Cut on actual subject motion and music cues.
3. **Audio story:** distinguish turbine, gas radial/prop, electric RC quad, nitro MONSTER CAR 2, electric Bisonte, helicopter rotors, water/dirt impact. Do not let rotor audio drown the score; previous v9.13 documented this issue. Reserve a controlled drop before the lake pass and a brief impact break. Choose exact music grid only after rights + actual audition.
4. **Finish / safety / delivery:** check dark-night aircraft against lights, precise skin/reflection matches, smoke source, widget readability, real FPV OSD values, camera contact effects, rights for imports/music, 16:9 1080p60 native source and optional vertical framing, release version of promised Creator features. False promises are a release blocker.

## Suggested editable review report

- Overall goal and audience.
- Sequence table: start/end, actual or estimated duration, purpose, strongest moment, weakest issue, alternative edit.
- Opening 5s test, 20s fleet test, 30s mute/phone test.
- One music-beat map with *measured* tempo/phase and sound effects (no invented timing).
- Visual/brand continuity note and feature authenticity pass.
- Proposed cuts/expansions and exact total runtime delta.
- Export checks (fps, size, codec, loudness, peak, language cards) based on inspected files, or mark **not tested**.
- Recommended revision and **who must approve**.

## Proven editing route

For a real film, recommend the existing OpenRC Godot capture + Python/FFmpeg assembly first. Remotion offers a different programmable option for titles, lower thirds and motion overlays, but do not auto-install a package or rewrite the existing pipeline just because a skill exists. External references: https://github.com/remotion-dev/skills and https://github.com/iamaanahmad/agents-video-editing-skills .

This is a skill for editorial thought and truthful QA. It is not a video-rendering tool or evidence of a completed movie.
