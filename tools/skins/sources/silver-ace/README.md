# SILVER ACE authoring sources (US-V20)

Downloaded 2026-11-14; exact URLs and SHA-256 hashes are in `sources.json`.
The generator verifies these bytes and uses no network access.

- `BlackOpsOne-Regular.ttf`: Black Ops One 1.004, Google Fonts commit
  `d50a0d29b`, unmodified. Copyright 2022 The Black-Ops Project Authors.
  SIL Open Font License 1.1, reproduced in `OFL-BlackOpsOne.txt`.
  Used only to bake stencil lettering; not installed as an interface font.
- `usaf-roundel.svg`: public-domain USAF national insignia, original by the
  United States Army Institute of Heraldry; vectorisation by Zscout370 and
  later Commons contributors. [File and provenance](https://commons.wikimedia.org/wiki/File:Roundel_of_the_USAF.svg).
  `usaf-roundel.png` is Commons' transparent 960-pixel rendering of that file,
  resized and rotated in the atlas. No official affiliation is implied.

The remaining panel layout, rivets, wear and fictional FU-604 / 52-0604 markings
are authored by `../../build_stik_silver_ace.py`. This is an RC tribute scheme,
not a reconstruction of a particular military aircraft.
