# Steampunk Cobre authoring sources

Downloaded 2026-11-14; exact URLs and SHA-256 hashes are in `sources.json`.
The generator (`../../build_vehicle_paints.py`) uses no network access.

- `IMFeENsc28P.ttf`: IM FELL English SC by Igino Marini, Google Fonts commit
  `d50a0d29b`, unmodified. SIL Open Font License 1.1 with Reserved Font Name
  "IM FELL English SC", reproduced in `OFL-IMFellEnglishSC.txt`. Used only to
  bake engraved plaque lettering; not installed as an interface font.

Gears, pipes, gauges, plates, rivets and wear are authored procedurally by the
generator. The design is original; no existing artwork is reproduced.
