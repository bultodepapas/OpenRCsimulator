# Landscape upgrade tools

Status: LU-06–14 native evidence tooling, updated 2026-10-12. Current target: official Godot 4.8-beta1 Compatibility. Historical LU evidence below remains scoped to its recorded engine.

LU-11–14 adds `gravel_close`, `gravel_far`, `twilight_aircraft`, and `twilight_background` views. `--gravel_detail=off` keeps the new shader but zeros its detail strength for pixel comparisons; `--gravel_detail=legacy` restores the original opaque material for a timing comparison. Run those performance pairs sequentially without competing engine/test jobs. `python tools/landscape/verify_materials.py --root <folder>` checks the `after-day`, `flat-day`, `before-aircraft`, and `after-sunset` reports and PNGs. The before-aircraft baseline was captured before the twilight change; keep it with the evidence. The checker measures encoded image contrast, not physical luminance or pilot recognition.

The 13-state twilight reference in `app/tests/fixtures/landscape_twilight_reference.json` records its baseline commit, source hash and engine. Its vector fields also retain little-endian float32 bytes: decimal JSON round trips in this engine did not preserve every tiny source-vector value. The regression compares exact unaffected vectors and a 2 ppm tolerance on affected linear luminance and scalar values. Do not regenerate this reference merely to make an unintended sky change pass.

Compatibility's viewport shadow-draw counter returned zero even in native shadow-enabled captures; those reports retain the raw values. Treat the reported visible/total counts conservatively as renderer counters, not independently measured shadow-pass accounting. [Material/architecture pass and complete raw evidence](../../docs/research/landscape-upgrade/LU-11/README.md).

LU-07–10 continuation (2026-10-12): additional views `pit_service`, `runway_west`, `runway_east_far`, `runway_inside`. Run native capture **without `--headless`**: it waits on `RenderingServer.frame_post_draw`, which a headless renderer does not supply. Always use an absolute `--out` path.

Use `--time_of_day=night --cases=runway_threshold,runway_inside,runway_east_far,marker_clear,marker_half,marker_off,marker_occluded` to check marker optics. The `marker_` cases deliberately hold the sky/exposure fixed and override only the lamp solar-elevation input to test full/half/off light and a real opaque blocker. They are controlled fixtures, not photographs of different solar times. `python tools/landscape/verify_markers.py <folder>` checks the native pixels and writes `marker-checks.json`.

The paired detector benchmark is `--headless --path app --script res://tests/benchmark_landscape_collision.gd`; its reference detector is pinned to the pre-refinement commit. Never run timing captures and benchmarks concurrently. [Refinement evidence](../../docs/research/landscape-upgrade/LU-07/README.md).

`app/tests/capture_landscape_upgrade.gd` builds the production world. Set `--out=<absolute-directory>`, `--cases=<comma-separated-postcard-or-glare-cases>`, `--frames=600`, `--width=1920`, and `--height=1080` after Godot's `--`. It captures raw PNGs and frame intervals after 60 warmup frames. Scenery audio is disabled; it measures rendering, not live flight physics. FW presets use `--time_of_day=night|sunset`; explicit TOD uses `--time-of-day=00:00`. The report retains actual engine, renderer, dimensions, arguments, memory, draws and primitives.

Glare cases: `glare_clear,glare_off,glare_blocked,glare_blocked_off,glare_partial,glare_partial_off,glare_aircraft,glare_aircraft_off,glare_aircraft_left,glare_aircraft_left_off,glare_aircraft_right,glare_aircraft_right_off,glare_side,glare_side_off,glare_night,glare_night_off,glare_cloud,glare_cloud_off,glare_low_exposure,glare_low_exposure_off,glare_half`.

Sun cases ([SUN plan](../../docs/plans/sun.md)): `glare_offset_<deg>` with `_off`, `_hidden` and `_hidden_off` (pilot view centred on the aircraft 60 m away, `<deg>` from the sun; aircraft removed or glare off), `glare_afterimage`/`_off` (1.33 s of simulation looking at the sun, then 40° away), `glare_lens`/`_off` (chase-camera optics). `"$(app/tests/visual-env.sh)" tools/landscape/glare_contrast.py <capture-folder>` turns each angle's four images into the aircraft's displayed contrast with and without glare and compares it with the model.

`python tools/landscape/verify_glare.py <capture-folder>` checks those matched images. Install the exact optional evidence dependency with `python -m pip install -r tools/landscape/requirements.txt`; it is not an application dependency. The checker writes `glare-checks.json` and fails if any present case violates its bound.

`python tools/landscape/make_validation_snapshot.py <new-directory>` preserves current tracked/untracked nonignored source in an isolated copy, records original SHA-256 hashes, normalizes text line endings only there, and copies the already-installed pinned Linux engine. A shallow clone retains the real source HEAD for replay/build provenance before the current working files are copied over it. It refuses an existing destination. For WSL, copy this snapshot to a new directory on the Linux filesystem (for example under `/var/tmp`) and run `bash app/test.sh` there: per-script engine startup is much slower on `/mnt/c`. This avoids changing concurrent developers' Windows source files during deterministic generator checks. Keep the copy and test command in one WSL invocation; this host discarded `/tmp` copies between invocations.

`app/tests/test_landscape_runtime.gd` exercises actual flight/scenery contact, crash presentation, secondary Godot shapes, pause and reset. `-- --out=<absolute-directory> --soundscape=off` additionally saves five native screenshots and a structured result. A headless run covers state behavior but is not visual evidence.

Production controls: `--sun-glare=0..2` (or `off`), `OPENRC_SUN_GLARE`; `--pilot-eyewear=none|cap|sunglasses|cap+sunglasses`, `OPENRC_PILOT_EYEWEAR` (SUN-06); `--landscape-upgrade=off`, `OPENRC_LANDSCAPE_UPGRADE=off`; existing scenery switches remain in [scenery tools](../scenery/README.md). The upgrade switch disables the new runtime integration, not the authored people/parking refinements.

Final proofs, screenshots and limits: [LU-06](../../docs/research/landscape-upgrade/LU-06/README.md).
